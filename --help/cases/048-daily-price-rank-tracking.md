# UC-048：每天自動查商品排名或價格，只在變動時通知

- 情境：省錢
- 標籤：每日、比價、電商、排程
- 網站標題：每天幫你盯商品排名或降價，有變動才通知
- 一句話用途：固定每天早上查一批商品在搜尋結果的排名或價格，存成表格並和前一天比較，只把有變動的項目通知你；退款或聯絡客服要你自己確認。
- 核心目標：把每天重複的手動查價、查排名，變成可抽查的每日紀錄與變動通知。
- 分類／標籤：電商監看／價格追蹤／排程
- 目標使用者：電商賣家（追蹤自家商品排名）、想在降價時申請價差退款的消費者
- 首次收錄／最近查證：2026-10-14／2026-10-14（台灣時間）
- 證據狀態：`author-demo`（X 作者自述＋公開 Bot 範本頁）＋ `designed`（本庫提示詞）
- 是否獨立重現：否

## 輸入與預期輸出

- 輸入：商品清單（賣家用 ASIN，消費者用訂單或商品網址）、關鍵字、檢查時間與時區、通知門檻。
- 輸出：每日一列一列的紀錄（日期、商品、關鍵字、排名或價格、來源網址）；和前一天的差異；只有超過門檻才發通知；查不到的項目另外列出，不當作「沒變」。

## 建議操作流程（本庫設計，未實跑）

1. 先挑 5–10 個商品手動跑一次，自己打開網頁核對排名或價格。
2. 決定存放位置（試算表），每天新增一列，不覆蓋舊資料。
3. 設定每天固定時間的排程，寫明時區。查不到時標「無法檢查」，不要沿用前一天的數字。
4. 只在超過門檻時通知（例如排名掉超過 10 名、價格降超過 5%）。
5. 降價退款：Bot 只整理「訂單、原價、現價、商家價差政策」給你，由你決定要不要聯絡客服。
6. 每週抽查 3 筆紀錄；平台改版時重新測試。

## 可複製提示詞（本庫原創，未測）

```
每天［時間、時區］檢查以下商品：［清單：商品網址或 ASIN＋關鍵字］。
每個項目記錄：日期、商品、關鍵字、排名或價格、來源網址，新增到［試算表］，不要覆蓋舊資料。
和前一天比較，只有［門檻］以上的變動才在這裡通知我；打不開或查不到就標「無法檢查」，不要沿用舊值。
不要登入我的購物帳號，不要聯絡任何商家或客服，不要購買、退貨或申請退款。若發現已購商品降價，列出訂單、價差和商家政策連結，等我決定。
```

## 所需連接、權限與限制

- 公開商品頁只需要讀取。查已購訂單需要購物帳號，屬敏感權限，先只用公開商品頁。
- 大量自動查詢可能違反平台條款或被封鎖，先小量測試。
- 費用：每天大量查詢會持續消耗代理用量；來源沒有可靠的費用數據。
- 聯絡客服、申請退款屬對外動作，必須當次核准。

## 驗收與可重現性

- 隨機抽 3 筆，與網頁實際排名或價格一致；「無法檢查」沒有被算成「沒變」。
- 通知只在超過門檻時出現；紀錄每天都有新的一列。
- 本庫未重現；兩個來源都是作者自述。
