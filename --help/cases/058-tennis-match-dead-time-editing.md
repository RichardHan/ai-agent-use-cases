# UC-058：把整場網球錄影剪成每一分，回看不用一直快轉

- 情境：創作
- 標籤：影片、運動、剪輯、驗收
- 網站標題：整場比賽太長？讓 Muse 先剪掉局間等待
- 一句話用途：從自己的比賽錄影找出有效比賽片段，保留可回查時間碼，再由人抽查有沒有漏球。
- 工具：Meta Muse／作者提供的網球錄影；具體剪輯工具未公開。
- 分類：既有影片整理與剪輯
- 查證日期：2026-10-15（台灣）
- 證據狀態：論壇作者自述使用，仍在調整；本庫未看成片、未重現。

## 來源與實際做到哪裡

[Reddit 原帖：26 use cases for Muse that I’ve implemented so far](https://www.reddit.com/r/MuseAgent/comments/1wv28e9/26_use_cases_for_muse_that_ive_implemented_so_far/)，作者 u/SpanglerBQ，英文。本次頁面顯示相對日期 13d ago，精確發布時間未核，不倒推成絕對日期。

作者說把 90 分鐘網球錄影交給 Muse，剪成只保留每一分、去掉等待的版本；同時明說仍在改善，距離 Swing Vision 的效果有差距。這是實際使用自述，不是完整命中率測試。本庫未取得原始錄影、輸出檔或人工標註，也沒有確認是否每分完整、耗時或使用了哪些程式。

作者對計算工作似乎較少耗用 token 的觀察帶有明確不確定性，本庫不將其當作免費剪輯或計費承諾。[作者附的影片](https://youtu.be/puGo_SI6Xro)尚未觀看，不據此增加功能細節。

## 怎麼試（整理者設計，未實跑）

1. 先拿有權處理、沒有不必要私人資訊的短片試剪，不一開始交整場。
2. 人先標一小段已知的發球、回合結束、重發與等待，說清希望保留的前後緩衝。
3. 先產出片段清單：原檔起訖時間、保留理由及不確定區間。畫面不明時保留待看，不直接丟掉。
4. 核准清單後才另存剪輯版，保留原檔；讓每段都能回到原始時間碼。
5. 對照人工樣本檢查漏球、切斷發球、誤留等待、聲畫同步；通過後才考慮擴大範圍。

## 可貼指令（本庫原創，未測）

請先檢查我指定且有權處理的網球錄影片段［檔案／範圍］。目標是保留每一分的完整過程，減少等待，不是只選精彩球。先不要剪出影片，請交一份候選片段表，含原片起訖時間、保留原因、信心不足處，以及你無法判斷的區間。以我給的人工標註樣本核對漏球和誤切，不用「畫面安靜」直接判為無效。列明工具、預估資源、是否需上傳第三方及權限；等我批准後才處理。保留原檔、另存輸出；不發布、不分享、不辨識球員身分。每個輸出片段須能追回原始時間碼。

## 權限、費用與限制

錄影中的其他人可能有隱私與肖像權；上傳給外部處理服務需確認範圍，不把私人錄影當公開素材。此研究沒有上傳或執行剪輯。Muse 的影片讀取、檔案大小、工具及帳號資格須以實際環境確認；原帖無可核對的單次成本。

固定機位、遮擋、雨天、重發球和跨局休息可能使規則失準，這些是本庫設計的測試條件，並非作者報告的失敗項目。剪成短片不等於正確的運動數據、比分或技術分析。

## 去重與驗收

與 UC002 的研究企劃／產品動畫不同：本例輸入是現成比賽錄影，輸出是保留原始時間對照的刪減剪輯；與 UC054 生成 MV 也不同。不因換成其他運動再建一個案例，後續同類證據併此頁。2026-10-15 首次收錄；未獨立重現。
