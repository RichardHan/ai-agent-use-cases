# AI Agent 實用案例庫

用繁體中文整理 AI Agent 的公開案例，從生活、工作、學習與創作中，找出你可以參考的做法。

**[前往案例網站 →](https://richardhan.github.io/ai-agent-use-cases/)**

在網站搜尋你想解決的問題，例如「旅遊」、「收件匣」、「比價」或「每日報表」，再閱讀案例的方法、結果、限制與原始來源。
若網站腳本或案例載入較慢，首頁可先開啟同一 GitHub Pages 版本的[完整案例索引](https://richardhan.github.io/ai-agent-use-cases/INDEX.html)，不依賴搜尋功能；亦保留 [GitHub 原始 Markdown](INDEX.md) 入口，後者可能比本站發布版本更新。索引不提供全文搜尋與篩選。

首頁與搜尋列也分別提供郵件、日報整理、會議整理、客服、代碼審查、比價及旅遊等任務入口；各入口只搜尋所標示的字詞，不保證所有結果都符合完整任務。可依「實作門檻」選擇免寫程式、需帳號或外掛、需本機環境或代碼的案例；重新選擇首頁情境會清除原有門檻與篩選。
首頁「論文資料」入口只搜尋「論文」，不把所有「研究」結果當成論文相關內容；仍可在搜尋框自行擴大查找。

搜尋結果預設包含全文與相關詞；輸入搜尋詞後，若只想先看字詞命中標題、用途或解決痛點的條目，可勾選結果上方的「只看標題、用途與痛點命中」。清空搜尋詞時此選項會收起並重設。這只縮小文字命中範圍，不代表內容已實作或驗證；分享搜尋連結會保留有效查詢的選擇。
「經驗與踩坑」快捷按鈕會保留搜尋與其他篩選；案例載入完成時，套用或取消後直接前往結果。載入中或失敗時先保留選擇，不在稍後強制移動焦點。

結果每次先顯示 24 筆；按「再看」後會接到第一張新案例，鍵盤可繼續閱讀、開啟詳情並返回原卡片。

案例詳情提供「怎麼開始」與「要注意什麼」入門建議與快速直達按鈕。這些是本庫的入門建議，不是實測結果；仍請核對原始研究與來源。
從案例選擇「探索更多」後，可用瀏覽器返回上一個案例與原搜尋條件，前進則回到情境結果。
回訪同一發布版本時，瀏覽器會在同源快取重用已核對版本的公開案例全文；版本更新、快取不可用或資料不符時仍由網路載入。這不縮短首次載入，也不儲存搜尋詞或個人資料。
