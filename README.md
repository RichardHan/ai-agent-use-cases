## 查證標記

- `official`：官方文件或官方示範，記錄版本與查證日；不代表本庫已重現。
- `author-demo`：作者公開示範或自述測試；清楚保留作者歸因。
- `designed`：本庫設計的可嘗試流程或提示詞；不宣稱工具一定支援。
- `unverified`：只取得網址、標題或零碎線索，尚不能提取完整案例。

## 情境與標籤

每個案例開頭有兩行，方便讀者依生活情境找用法；網站全文搜尋可直接搜到這些詞：

- `- 情境：`擇一為主
  - 生活：旅遊、家庭、學校、健康、二手買賣等個人日常
  - 工作：業務、客服、營運、行銷、求職等職場流程
  - 省錢：訂閱、帳單、比價、記帳、費用異常
  - 學習：自學、科研與資料查證
  - 創作：影片、社群內容、設計
  - 開發：程式、PR、代理協作、裝置、排程維運與故障診斷
- `- 標籤：`2–4 個自由短詞，以「、」分隔。先沿用已出現的詞，例如排程、收件匣、客服、多代理、旅遊、二手、帳單、比價、驗收、核准。
- `每日`：保留給「每天固定時間自動執行」的案例（晨報、每日檢查、每日提醒、每日報表等），讓讀者能一次找到所有每日例行用法；只是處理每日資料、但不是每天自動執行的案例不要加。

新增情境前，請先確認既有六類都不適用。原有的「分類」欄位保留給網站篩選使用，不要刪除。

## 收錄與去重

1. 記錄原始網址、作者、原文語言、發布日期、查證日期與可取得內容。
2. 用「目標／輸入／輸出／執行環境／授權邊界」比對既有案例；相同核心工作併入同頁。
3. 各工具和來源保留獨立版本、日期與限制，不能因去重刪掉來源，也不將不同作者的成功結果拼成一個已驗證流程。
4. 區分原文報告、整理者推論、自行設計提示詞與實際重現結果。
5. 只保存必要的簡短改寫與連結，不收錄完整文章、逐字稿或付費內容。
6. 每次更新記錄新增來源、版本差異、失效連結與狀態變化；未讀影片先列待查。
