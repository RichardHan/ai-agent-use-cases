# AI Agent 實用案例庫

用繁體中文整理 AI Agent 的公開案例，從生活、工作、學習與創作中，找出你可以參考的做法。

**[前往案例網站 →](https://richardhan.github.io/ai-agent-use-cases/)**

在網站搜尋你想解決的問題，例如「旅遊」、「收件匣」、「比價」或「每日報表」，再閱讀案例的方法、結果、限制與原始來源。

搜尋是字面比對，不是語意理解。沒有結果時，若你打的字裡有一段是站上收錄的詞，會先提供該詞的搜尋與實際筆數（例如「想學英文」→ 原問題包含「學英文」→ 32 筆文字命中），再列出全站共用的任務清單。

若網站腳本或案例載入較慢，首頁可先開啟同一 GitHub Pages 版本的[完整案例索引](https://richardhan.github.io/ai-agent-use-cases/INDEX.html)；案例載入失敗時，結果區也有本站索引入口及重試按鈕。亦保留 [GitHub 原始 Markdown](INDEX.md) 入口，後者可能比本站發布版本更新。索引不提供全文搜尋與篩選。

首頁與搜尋列也分別提供郵件、日報整理、會議整理、客服、代碼審查、發票對帳、出差報銷、合約審核、社群文案、員工排班、資料擷取、播客摘要、競品分析、代碼除錯、文件翻譯、網頁抓取、寫履歷、代碼重構、發票辨識、問卷調查、文獻回顧、機票比價、資料清理、日誌分析、法規遵循、筆記整理、客戶反饋、面試準備、行銷文案、效能分析、報帳審核、簡報製作、社群排程、專案進度、數據分析、音訊轉寫、市場調研、產品調研、讀書筆記、英語學習、漏洞掃描、隱私審查、成本分析、供應商評估、招募審查、合約比對、報表比對、電子報、庫存管理、安全防護、人工審批、比價及旅遊等任務入口；各入口只搜尋所標示的字詞，不保證所有結果都符合完整任務。可依「實作門檻」選擇免寫程式、需帳號或外掛、需本機環境或代碼的案例；重新選擇首頁情境會清除原有門檻與篩選。
首頁「論文資料」入口只搜尋「論文」，不把所有「研究」結果當成論文相關內容；仍可在搜尋框自行擴大查找。
手機版首頁的常見任務清單先顯示前 9 項，按「顯示全部 N 個任務」可展開其餘入口，再按一次收合；所有任務連結仍保留在同一頁，桌機版則一次顯示全部。

搜尋結果預設包含全文與相關詞；輸入搜尋詞後，可在結果上方選擇「主題」，只搜尋標題、用途、核心目標、分類、標籤及案例 ID，減少原文偶然提及的結果；也可選擇原有的「標題、用途與痛點」範圍。清空搜尋詞時選項會收起並重設。這只縮小文字命中範圍，可能漏掉相關案例，也不代表內容已實作或驗證；分享搜尋連結會保留有效查詢的選擇。
結果行下方會說明這些筆數的組成：當大部分結果只在正文或標籤提到你的字詞時，會寫出其中幾筆的標題、用途或痛點提到這些字或相關詞，並提供「只看那 N 筆」一鍵收斂；按下後命中範圍改為「標題、用途與痛點」，畫面顯示的筆數就是按鈕上寫的筆數，網址與可移除的條件也會保留；一般查詢原樣留在搜尋框，整句查詢則改寫成站上實際用來搜尋的詞（以「、」連接，確保同一個條件）。這個提示只在「正文或其他欄位命中」達到三分之二時出現，避免在查得到的情況下多說一句。若沒有任何案例的標題、用途或痛點同時包含你的字詞，則說明那些結果是全文或同義詞命中，並提供一個站上真的有的單字與實際筆數。兩者都只描述字詞在哪裡命中，不代表案例已實作或經過驗證。首頁隨機抽卡顯示的「N 張可抽案例卡」只算可抽的案例頁，可能少於結果筆數；差額（經驗補充、待查線索或模板）仍列在結果中，面板會寫出差幾筆。

鍵盤使用者不必先捲過整頁：按一次 Tab 會停在「跳到案例搜尋」，按 Enter 直接進入搜尋框；不在輸入框或案例視窗內時，按 `/` 也會跳到搜尋框。搜尋框在頁面下方，不必先看過公開案例區。打字時只有結果筆數會更新，抽卡狀態與另一處重複的筆數不再逐字播報給讀屏；改動情境或門檻而換卡時，讀屏會唸出新卡標題。
「經驗與踩坑」快捷按鈕會保留搜尋與其他篩選；案例載入完成時，套用或取消後直接前往結果。載入中或失敗時先保留選擇，不在稍後強制移動焦點。
查無完全符合的案例時，若原句包含站上已用過的任務詞（案例標籤或搜尋同義詞），會先列出該詞與實際筆數，例如「原問題包含「省錢」→ 搜尋 62 筆」；點選後才替換關鍵字並保留其他篩選。原句若沒有可用詞彙，才只顯示常見任務捷徑。
若整句是一個查無結果的中文複合詞，且能完整拆成站上既有的相鄰詞（例如「客戶抱怨」拆成「客戶」＋「抱怨」），會直接以這些詞同時符合搜尋，並在結果上方標明拆了哪些詞與實際筆數，可隨時切回「只找完整句子」。這只是字面拆詞，不是語意理解；已選篩選或含多個詞的查詢不適用。
若直接輸入一句完整問題（例如「怎麼讓 AI 幫我檢查合約有沒有問題」），或五個中文字以上的日常短句（例如「每月信用卡帳單整理」「整理履歷表」），整句查無結果時，會先找句中含有哪些站上既有的任務詞，再以其中最多兩個詞同時符合搜尋，並在結果上方列出採用哪些詞與實際筆數，可切回「只找完整句子」。這也是字面比對，不是語意理解；句中找不到站上詞彙、已選篩選、整句已命中或詞義等同同義詞組時不會替換。像「旅遊 xyz987」這種任務詞加上自訂字串的查詢仍視為精確查詢，不會被替換；五到九個中文字的短句若另外含工具名、年份、版本或金額等英數字，也維持精確查詢，不會為了湊出結果而忽略你打的字。

結果每次先顯示 24 筆；按「再看」後會接到第一張新案例，鍵盤可繼續閱讀、開啟詳情並返回原卡片。提交其他搜尋後使用瀏覽器返回，可還原先前搜尋已展開的結果；分享連結仍只包含搜尋條件。

案例詳情提供「怎麼開始」與「要注意什麼」入門建議與快速直達按鈕。案例自己的步驟或限制章節會直接顯示；沒有這類章節的案例，卡片顯示本庫的通用起步建議（先讀原始報告與限制，再以去敏資料小範圍試跑）。兩者都是本庫的入門建議，不是實測結果；仍請核對原始研究與來源。
詳情標題旁直接標示「成果主張」與「核讀」狀態，不必先捲到下方；按「核讀與安全建議 ↓」可跳到完整說明、成果主張者與安全採用邊界。
「實作門檻」以案例頁的 `實作門檻` 宣告為準（寫讀者要跟著做所需的環境，不是作者自己產出了什麼）；沒有宣告的案例由本庫依內文關鍵字推測，卡片標籤與詳情頁都會標明是宣告還是推測，避免把猜測當成案例事實。推測只看字面，像「未公開腳本」這種缺口說明仍可能被讀成需要寫程式；看到推測標記時請以案例的工具與步驟自行核對。
詳情的延伸閱讀只取目前搜尋結果：優先列出至少兩個共同標籤的其他主要案例，再列相同分類。標籤重合不保證任務或結果相同，請繼續核對來源與限制。
從案例選擇「探索更多」後，可用瀏覽器返回上一個案例與原搜尋條件，前進則回到情境結果。
回訪同一發布版本時，瀏覽器會在同源快取重用已核對版本的公開案例全文；版本更新、快取不可用或資料不符時仍由網路載入。這不縮短首次載入，也不儲存搜尋詞或個人資料。

## 閱讀前知道這件事

作者自述、官方示範與本庫設計的流程會分開標記；收錄不代表已獨立驗證，也不保證能重現成果。自行設計的提示詞不是原文或實測結果。
來源類型篩選依案例頁首的證據說明分類：以該行最先宣告的證據等級為準，例如頁首寫 `author-demo` 就看「作者報告／示範」，寫 `unverified` 就看「尚待查證」；後面才提到的模板頁或官方文件只算輔助材料，不會蓋掉前面的等級。廠商、原廠或官方員工的第一手自述歸在「官方自報」，不會被說成第三方分析。只有提示詞、沒有執行結果的 `designed` 會另列「設計／未實跑」，不與作者實跑紀錄混在一起。同一頁可能包含不同作者或來源版本，不能將頁首標籤套用到每項主張，請逐段核對。
「來源標籤怎麼看」的說明、卡片標籤、詳情憑據與篩選說明都引用同一份定義，並附上「成果主張來源」，讓你知道是誰提出這項成果。
首頁合格數是報告所列批次的歷史快照，不是目前全庫累計；統計卡會標示該批次當時有多少個主要案例頁，避免把它當成現有條目的合格比例。之後新增的條目未重新計數。
「待查線索」條目若沒有自己的核對日，詳情會標示來源檔的查證日期並說明那是檔案層級紀錄；已併入主案例的條目會先說明已結束，再呈現原帖的待查狀態。
