## 本庫建議流程

1. 定義受眾、主題、影片長度、交付格式及研究截止日。
2. 收集可訪問的第一手資料；將事實、個人經驗與留言意見分開。
3. 每個重要主張附來源及日期，找不到字幕就記錄缺口，不臆測影片內容。
4. 以使用者提供或允許查閱的公開作品分析語氣，先寫簡短風格摘要。
5. 產出選題理由、標題、開場與段落大綱。標註待驗證主張與圖片素材權利。
6. 用尺寸、構圖、文字可讀性及完整性驗收縮圖；草稿或構圖說明不算完成圖片。

## 可複製提示詞（本庫原創設計）

我要為［受眾］製作一支［主題］影片，預計［長度］。請查閱［指定公開來源範圍］及我提供的［風格參考連結］。產出一份企劃：可靠發現、爭議與缺口、三個有根據的切入角度、標題候選、開場與段落大綱，以及縮圖設計需求。重要主張附來源與查證日；無法讀取的影片不要假裝已看過。引用保持簡短，不複製逐字稿。未經確認不發布、不聯絡創作者、不上傳私人素材。交付前列出所有未完成或待查部分。

## 權限、限制與驗收

- 公開資訊不等於可任意重製；避免完整逐字稿、整篇改寫或無權使用的素材。
- 私人頻道分析、未公開腳本或登入來源需另行確認範圍。
- 用量、來源存取與圖片工具能力都可能限制成果。
- 驗收：來源可追溯、文字符合指定語氣、交付物齊全；設計需求與實際圖片分開標示。
- 本庫流程是整理者設計，不代表三款工具的官方保證。

### 自設延伸流程與指令（未實跑）

1. 先取得產品公開功能、介面狀態及素材授權依據。
2. 做逐鏡頭功能對照，標明實拍、截圖、重建動畫。
3. 人核定分鏡後才製作；將影音節奏、字型與依賴版本記錄。
4. 以實際輸出驗收時長、文字、聲畫同步及功能忠實性，不把 source build 宣稱為成片。

可貼指令：請先只讀［產品公開文件與程式碼］，為15秒產品動畫擬定分鏡。每個互動對照具體來源，分清真實截圖和示意重建，不畫不存在的功能。輸出鏡頭、畫面文字、狀態轉換、素材來源及待確認項目，並列製作所需依賴、授權、成本與驗收清單。此階段不要安裝、執行、渲染、上傳或發布；等我批准分鏡與環境後再做。禁止搬用參考影片音軌、未獲授權素材或私人畫面。不要把一個示意動畫稱為產品實際錄影。

### 成本與限制

公開專案列有 Node.js、Python、FFmpeg、Remotion 瀏覽器與中文字型等需求；本次未安裝或測試。沒有 dots 的單次實際用量、費用或製作工時。Remotion 商業使用條件與各項素材／依賴授權須另查；專案產品本身提及的模型 API 費用不是影片製作費用。公開原始碼不等於授權重用所有品牌與素材，不照抄環境回退設定。
