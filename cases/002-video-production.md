## 本庫建議流程

1. 定義受眾、主題、影片長度、交付格式及研究截止日。
2. 收集可訪問的第一手資料；將事實、個人經驗與留言意見分開。
3. 每個重要主張附來源及日期，找不到字幕就記錄缺口，不臆測影片內容。
4. 以使用者提供或允許查閱的公開作品分析語氣，先寫簡短風格摘要。
5. 產出選題理由、標題、開場與段落大綱。標註待驗證主張與圖片素材權利。
6. 用尺寸、構圖、文字可讀性及完整性驗收縮圖；草稿或構圖說明不算完成圖片。

## 可複製提示詞（本庫原創設計）

我要為［受眾］製作一支［主題］影片，預計［長度］。請查閱［指定公開來源範圍］及我提供的［風格參考連結］。產出一份企劃：可靠發現、爭議與缺口、三個有根據的切入角度、標題候選、開場與段落大綱，以及縮圖設計需求。重要主張附來源與查證日；無法讀取的影片不要假裝已看過。引用保持簡短，不複製逐字稿。未經確認不發布、不聯絡創作者、不上傳私人素材。交付前列出所有未完成或待查部分。

## 權限、限制與驗收

- 公開資訊不等於可任意重製；避免完整逐字稿、整篇改寫或無權使用的素材。
- 私人頻道分析、未公開腳本或登入來源需另行確認範圍。
- 用量、來源存取與圖片工具能力都可能限制成果。
- 驗收：來源可追溯、文字符合指定語氣、交付物齊全；設計需求與實際圖片分開標示。
- 本庫流程是整理者設計，不代表三款工具的官方保證。

## 中文Grok Bot版本：全程用手機，從產品GitHub倉庫做出宣傳片並沉澱成Skill（2026-10-20 14:44補充）

- 來源證據：`author-demo`（作者自述實測）；本庫已讀全文，文中截圖與成片未逐一核對，未重跑。

- 作者流程（翻譯改寫）：
  1. 先請總調度 Bot 上 X 調研「做宣傳片的 Skill」，要求附完整證據鏈與 GitHub 倉庫網址，作者看過 README 後讓 Bot 安裝其中一個（作者稱為 claude-motion-design）。
  2. 把自家產品 md2wechat 的倉庫丟給 Bot，要求面向中文使用者做有設計感的宣傳片；約 5 分鐘出第一版，截圖、文案與數字取自倉庫說明，作者覺得普通。
  3. 只說「高級、炫酷」沒用；改說「要適合放在 YouTube 廣告的頂級創意」後，Bot 提出 3D 牆與配樂方案，約半小時出第二版。
  4. Bot 主動要高清 logo 與產品截圖；作者給官網網址，Bot 自取 logo、品牌色、官方文案與截圖做第三版，配色改成官網的陶土紅＋暖黑。
  5. Bot 想要一段真實操作錄影；作者在手機上無法錄，就給 npm 安裝指令讓 Bot 在雲端電腦自己安裝並截圖，第四版換成終端操作回放。作者明說沒給 API Key，所以這段只是終端回放，**不算完整跑通排版與發布**。
  6. 配樂太機械、沒卡點；Bot 說接音樂生成工具需要登入作者帳號，作者改讓它自己找節拍清楚的電子樂。
  7. 滿意後請 Bot 把這幾輪做法沉澱成「卡點宣傳片」Skill，之後輸入主題、連結或文章即可產生同風格影片；再試了 Netflix 片頭風格，作者覺得與產品調性不太合。
- 與本頁 V2EX dots 版本的差異：同樣是「依產品真實資料做宣傳動畫」，但本版本全程手機操作、靠多輪口語回饋修正方向，由 Bot 自取官網品牌素材並在雲端電腦安裝產品做回放，最後存成可重用的 Skill；作者自己標出哪一段不是真實執行。
- 缺口：沒有各版本耗時以外的用量、費用與成片檔；配樂來源與授權未說明；第三方 Skill 的程式內容與授權本庫未審。安裝第三方 Skill 前應先讀程式與權限。
