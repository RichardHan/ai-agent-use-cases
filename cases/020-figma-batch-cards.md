# UC-020：用一張設計範本，做出整批一致的卡片

- 網站標題：用一張設計範本，做出整批一致的卡片
- 一句話用途：把描述清單套進既有 Figma 元件，減少每張卡片手動排版。
- 工具：Grok Bot／Figma MCP

## 來源說了什麼

作者報告以一個 auto-layout 元件製作20個入門 Bot 卡片，並整理工具圖示；以實際檔案尺寸和元件為準，而非目測。

## 怎麼開始（整理者設計，未實跑）

1. 指定可用元件和內容清單
2. 先做少量預覽
3. 核對來源與文字
4. 批准後在複本批次套用
5. 檢查溢位、間距、元件關聯。

## 可貼指令（自設未測）

請只讀［Figma範本］和［10筆內容］，先報告元件、字體、間距及缺少素材，並提出2筆卡片預覽計畫。不要重畫既有品牌，不下載授權不明照片。未批准前不要寫入。若我批准，僅在指定複本套用已確認內容，保留auto-layout及元件關聯；逐筆檢查截字、溢位、素材來源，回報失敗項目。
