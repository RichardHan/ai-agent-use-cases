# UC-041：多個排程誰真的跑完了？用 Bot 驗收輸出，晚上只報例外

- 情境：開發
- 標籤：每日、排程、巡檢、多代理
- 網站標題：晨間掃信與健康檢查，晚間只聽阻塞

## 與既有案例的差別

- 對 UC-014（客服收件匣與退款核准）：UC-014 重點是客服 playbook 與退款「提出請求、人核准」。本案收件匣步驟類似「只草稿」，但核心新增是**用另一個 Bot 驗收其他排程的真實產物**，以及**晚間例外制**。收件匣草稿規則可交叉參考 UC-014，不合併為同一成功案例頁。
- 對 UC-008／UC-015：晨報準時性與頁面監看排程驗收可共用「實際執行時間／沒跑≠沒變」觀念；本案新增「跨 routine 健康檢查」角色。

## 怎麼開始（本庫設計，未測）

1. 先只開一個「健康檢查」routine，目標限定為你已手動跑過、已知產物路徑的 1–2 個任務。
2. 定義何謂成功：必須指出可點開的產物（草稿連結、檔案、commit、關閉的任務），不能只讀狀態燈。
3. 分級升級：可自行重試的小錯 vs 必須找人的登入／付款／權限；連續失敗才開任務，避免吵鬧。
4. 收件匣若要試，全程 Draft only；與 UC-014 一樣，對外寄出與退款另批。
5. 晚報預設安靜；只有阻塞或未交付才通知。

## 可貼指令（本庫原創，未測；結構參考作者簡化版，非逐字複製）

請做「排程健康檢查」，範圍是我列出的 routine／任務名稱［清單］，時區［時區］。自你上次檢查以來：哪些有執行紀錄、哪些失敗或缺席。狀態為 enabled 或綠色不足以算成功；每一項成功必須指出實際產物（例如草稿、檔案路徑、commit、已關閉任務或報告連結）。小問題：嘗試一次安全修復並寫進日誌。涉及登入、金錢、權限或不可逆動作：不要自行處理，只給我一行現況與建議修復。同一項連續兩次失敗：開一筆待我處理的任務。全部正常：不要傳訊。不要寄信給別人、不要改付費設定、不要刪除 routine。

（可選、另開 routine）每早只讀我指定的商業信箱［帳號］，標出疑似商機與需要我決定的請求；只建草稿，永不寄出。

（可選、晚間）只檢查我指定的交付清單［清單］：今天交了什麼、什麼被擋住。只報例外；全數正常則保持安靜。

### 可加入巡檢的驗收（整理者設計，未實測）

先用虛構服務清單驗證看板：每個列入範圍的服務都要有自己的列，至少含重要性、最後確認時間、證據連結、未確認範圍與待處理人；零項發現也不能消失。把「確認過、沒有發現」與「沒權限／沒跑／資料過期」分開，不用問題總數代表風險或檢查完整度。

可貼指令：請用我提供的三個虛構服務檢查範例巡檢報告。逐一對照服務清單，不按警告數量排序；重要服務即使零項發現也要顯示。每列標最後核對時間、來源與未確認項目。刻意加入一個讀取失敗、一個停用服務，檢查前者不被標安全、後者不把重要服務擠掉。這次只檢查報告呈現，不掃描真實系統、不讀秘密或個資、不修復、部署或改權限。

- 權限／費用：以上練習只需虛構文字；接入真實服務須另限定可讀範圍。來源沒有單次費用、漏報率或第三方安全驗證；此流程不能替代專業安全評估。

## 2026-10-18 來源補充：專職巡檢 Bot 抓到「成功」六天卻沒寫入的同步

- 作者／來源：grovr（@grovr_au），[X 原帖](https://x.com/grovr_au/status/2111594375260111249)；英文，2026-10-17 23:05 UTC（台灣 2026-10-18 07:05）。本庫以 X API 讀到全文，無附圖。
- 工具：Grok Bot（多個 Bot＋共用技能）。
- 作者自述（翻譯改寫）：每個 Bot 只負責一件事，另附一張「絕對不做的事，以及這些事該交給哪個 Bot」短清單；實際做法寫在共用技能裡。一個 Bot 專門每週檢查這些技能有沒有過時或重複內容並刪減，作者說內容越少，越不會塞爆上下文、越省用量，也更清楚每個流程該怎麼跑。另一個 Bot 盯其他 Bot，檢查 routine **是否真的完成工作，而不是只說自己有跑**；它因此抓到一個連續六天回報「成功」、卻沒有寫入任何東西的同步。
- 證據界線：只有作者文字；沒有看到該同步的紀錄、修復方式或之後是否再犯，也沒有用量下降的數字。
- 合併理由：與本頁核心相同（另一個 Bot 驗收排程的真實產物、綠燈不算成功），補一個實際抓到「假成功」的作者自述，以及「每週整理共用技能」的維護角色；不另計案例。

### 可加入巡檢的檢查（本庫設計，未實測）

- 對每個會寫入資料的 routine，記錄「上次確實新增或變更了什麼、在哪裡」；連續兩次執行成功但寫入數為零，就標為待查，而不是正常。
- 每週一次只讀共用技能，列出重複段落、互相矛盾的指示與已不使用的步驟，交給人決定刪改；巡檢 Bot 自己不直接改技能。
