## 怎麼開始（本庫設計，未測）

1. 先寫清角色與交接：寫手產出 → 陪審只給反對理由與必須修改點 → 人裁定 → 發布角色只在核准後動作。
2. 需要登入的步驟，先確認產品是否提供安全憑證／連接器路徑；沒有就不要把密鑰貼進對話，改為人工登入或放棄該步。
3. 若使用雲端電腦：預先約定人如何介入、檔案備份位置，以及「回報進度但無產物」時如何驗收（要求可點開的草稿或 commit）。
4. 多 Bot 群組仍可能變成人肉調度（社群另有討論）；先從兩個角色（寫手＋一名反對者）小範圍試，再加監看／發布。
5. 看用量與額度；作者有額度耗盡導致整週停擺的自述。
