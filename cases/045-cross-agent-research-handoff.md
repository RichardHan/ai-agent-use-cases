# UC-045：讓另一個代理代查公開網頁，再把證據交回原任務

- 情境：開發
- 標籤：跨代理、研究交接
- 網站標題：Codex 想繼續工作？把網頁查證交給 Grok Bot，再收回結果
- 一句話用途：用第三方任務橋追蹤委派進度與來源，讓原本的任務依據結果接續，而不把「已送出」當完成。
- 工具：Codex、Grok Bot、第三方 MCP Task Bridge、Cloudflare；dots 與 Muse 版本未核。
- 分類：跨代理協作與研究
- 查證日期：2026-10-14
- 證據狀態：開源作者自報手動觸發完成；無人排程與本庫重現未完成。

## 怎麼試（本庫設計，未測）

1. 先只設計交接格式，不部署：輸入限定一個公開產品公告網址、問題及驗收條件。
2. 將任務分為已送出、已領取、進行中、需要人處理、完成或失敗；保存唯一任務ID，避免重試重複建立。
3. 執行端必須交來源、查閱時間、事實與未知項目；受阻不能改以猜測完成。
4. 原委派者讀回正式結果並抽查來源，再繼續自己的報告；收到成功狀態仍不等於內容正確。
5. 如日後批准實作，先測手動一件，再測重啟、重試、逾時及取消；無人排程另驗收。先核對安全、費用與最小存取。

## 可貼指令（本庫原創，未測）

請先設計一份跨代理交接單，不連接或呼叫任何其他代理。任務是只讀［公開產品公告網址］，回答［問題］。列任務ID、允許網址、最多查閱頁數、截止時間、回傳欄位及完成條件。結果格式需要原始連結、查閱時間、來源支持的事實、推測和讀不到的缺口。寫清已送出不算完成、終態後仍需原委派者核查，重試不得重複建任務。不得登入、下載不明程式、安裝、註冊、授權、發信或改外部資料。等我核准接收代理、資料及部署方案後再討論實作。

## 權限、費用與限制

此案例作者的呼叫端含本機工具；本頁不要求操作使用者電腦，也沒有證明所有雲端呼叫端均相容。Cloudflare資源、代理方案及MCP可用性可能產生費用，來源沒有可靠單次成本。新的OAuth、金鑰與持續存取要另取得適當批准；不要把憑證、私人工作區或完整聊天送進任務橋。跨代理分享需指定接收方及允許資料。橋接沒有替人核准後續行為的權力。

## 驗收與去重

檢查唯一ID、來源可開、失敗可見、重試無重複，以及原任務確實讀回結果。只讀研究一次完成不能外推付款、發布或無人長期運作。與UC005程式PR審查不同，本頁核心是研究任務的跨工具交接；與待查a2a-bridge也不同，兩個專案的證據不能互相移用。
