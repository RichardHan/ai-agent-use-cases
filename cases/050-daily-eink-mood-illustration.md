# UC-050：每天早上依筆記和天氣生成一張畫，推到桌上的墨水屏

- 情境：創作
- 標籤：每日、實體裝置、生成圖像、筆記
- 網站標題：每天醒來，桌上墨水屏換成一張依昨天筆記和天氣畫的圖
- 一句話用途：代理每天早上讀你的筆記，挑出當天的靈感，搭配天氣，用某位藝術家的風格生成一張圖，經樹莓派推到電子紙螢幕。這是作者自己的 DIY 作品，需要動手接硬體。
- 核心目標：把每日例行的「回顧筆記」變成一個不用打開手機、放在桌上就看得到的實體輸出。
- 分類／標籤：實體裝置／生成創作／排程
- 目標使用者：有 Obsidian 等筆記習慣、願意自己接樹莓派和電子紙的 DIY 玩家
- 首次收錄／最近查證：2026-10-14／2026-10-14（台灣時間）
- 證據狀態：`official`（Meta 員工公布的 Muse Gadgets SDK 貼文）＋ `author-demo`（作者自述＋截圖，本庫未看截圖）＋ `designed`
- 是否獨立重現：否

## 輸入與預期輸出

- 輸入：筆記庫（作者例：Obsidian）、天氣、要模仿的藝術家風格清單、電子紙裝置（作者例：BOOX）與樹莓派。
- 輸出：每天早上一張生成圖片顯示在電子紙上；建議另外留一份文字紀錄，寫明用了哪則筆記、哪種風格。

## 建議操作流程（本庫設計，未實跑）

1. 先只用一個專門的筆記資料夾，不讓代理讀整個筆記庫（避免私人內容外流到圖片或第三方服務）。
2. 先手動跑一次：讀筆記、選靈感、生成圖，在電腦上確認結果。
3. 再接電子紙：先推一張固定測試圖，確認顯示正常。
4. 設定每天早上的排程。失敗時保留昨天的圖，並在文字紀錄寫「今天失敗」。
5. 圖片只放在本機裝置；如果要分享，先檢查畫面裡有沒有筆記內容。
6. 藝術家風格只拿來當創作參考，不拿去商業使用或冒充原作。

## 可複製提示詞（本庫原創，未測）

```
每天［時間、時區］：
1) 只讀［筆記資料夾］裡過去 24 小時新增或修改的筆記，挑一則作為今天的主題，用一句話說明為什麼選它（不要引用筆記裡的私人細節）。
2) 取得［城市］今天的天氣。
3) 從［風格清單］選一種，生成一張適合電子紙的灰階圖（［解析度］）。
4) 送到［裝置］；成功或失敗都在這裡回報：用了哪則筆記的標題、天氣、風格、檔名。
沒有新筆記就用天氣當主題。不要修改或刪除任何筆記，不要把圖片或筆記傳到其他地方。
```

## 所需連接、權限與限制

- 需要筆記讀取權、天氣資料、圖像生成，以及連到本機硬體的通道（依 S-050B 的 SDK；細節未核）。
- 隱私：筆記可能包含私人內容；只開放指定資料夾。
- 可用性：依 UC-016 引用的資料，Muse 目前限美國，請以官方公告為準。硬體需要自己準備。
- 費用：每天生成一張圖會持續消耗用量；來源沒有說明。

## 驗收與可重現性

- 連續 7 天每天都有新圖，或明確的失敗紀錄；文字紀錄中的筆記標題對得上當天的筆記。
- 沒有修改過任何筆記；圖片裡沒有私人文字。
- 本庫未重現；S-050A 是單一作者的自述。
