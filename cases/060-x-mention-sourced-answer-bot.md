# UC-060：用有來源的公開知識庫，自動回覆 X 上的提問

- 情境：工作
- 標籤：每日、X、自動回覆、知識庫
- 網站標題：有人在 X 標記你就自動回答？先建好附出處的資料庫，敏感題留給人
- 一句話用途：讓 Bot 監看專用帳號被標記的貼文，只從整理好的公開資料庫找答案並附上出處；超出範圍就婉拒，敏感問題保留給人處理。
- 核心目標：把「大家常問、答案散在公開文件與影片裡」的問題，變成可追溯來源、有範圍限制、可停機的自動問答帳號。
- 工具：Grok Bot（作者自述整套跑在一個 Bot 內）／X／作者公開的 GitHub 資料庫
- 分類：社群問答與公開資料查證
- 目標使用者：要替產品、活動、社群或公開文件回答大量重複提問，又必須每句話都講得出出處的人
- 首次收錄／最近查證：2026-10-15／2026-10-15（台灣時間）
- 證據狀態：`author-demo`（作者自述＋公開帳號回覆與資料庫已讀）；Grok Bot 讀取 X 與 routine 另以官方文件查證；本庫流程與提示詞為 `designed`；X 自動回覆規範 `unverified`（官方規則頁本次被擋未讀）
- 是否獨立重現：否

## 輸入與預期輸出

- 輸入：一個標明「自動化、非官方」的專用 X 帳號；有權引用、每筆附來源網址與日期的知識庫；可以回答的主題範圍；需要轉人處理的問題類型。
- 輸出：對標記帳號的貼文，在短時間內回覆一則附出處（來源類型與日期）的答案；範圍外問題回固定婉拒句；敏感問題不回、留給人；每天更新資料庫並公開；每小時確認監看沒有停。

## 官方功能對照（`official`，2026-10-15 查證）

- [Use the computer and apps](https://docs.x.ai/grok-bot/computer-and-apps)：Bot 不必連 X 帳號，就能搜尋與讀取公開貼文、帳號貼文與提及；這種讀取是唯讀的，不會以你的身分登入。私訊、書籤、首頁時間線需另外安裝 X plugin 並登入。官方頁沒有說明「自動發回覆」怎麼設定，所以本庫不推定作者用哪一種方式發文。
- [Skills and routines](https://docs.x.ai/grok-bot/skills-routines-and-automations)：routine 間隔至少 5 分鐘；文件建議避開「每則新訊息都觸發」這種廣泛監聽，會增加噪音與用量；寄信、發布等動作建議要核准；並要寫好來源缺失或資料過舊時怎麼處理。作者說的「全天監看、約 2 分鐘回覆」是怎麼排程或觸發的，原帖沒有交代。

## 建議操作流程（本庫設計，未實跑）

1. 先選一個不敏感、你有權引用的範圍，例如自家產品 FAQ 或公開活動須知；不要一開始就做政治、醫療、法律或金融問答。
2. 建知識庫：每筆都要有來源網址、發布日期、說話者與是否自動轉錄；沒有日期就標「無日期」，不要用抓取日頂替。
3. 寫範圍與停止規則：範圍外的問題用固定婉拒句；涉及個資、指控、投資或健康建議、無法找到來源的問題，一律不回、改進人工佇列。
4. 先只產生「回覆草稿」，在私人對話中讓人逐則看，累積一週，抽查來源是否真的支持答案，再決定是否自動發出。
5. 帳號要標明自動化與管理人，並先查 X 現行自動化與 AI 回覆規則。
6. 每天更新資料庫、記錄新增筆數；監看停掉時要通知人，不要默默補發舊提問。

## 可複製提示詞（本庫原創，未實跑）

> 請每 15 分鐘讀一次公開 X 上標記 ［專用帳號］ 的新貼文，先讀被回覆的上一則貼文了解上下文。只能用 ［知識庫位置］ 中有來源網址與日期的資料回答，答案不超過兩句，句尾附來源類型與日期。找不到來源就說「資料庫沒有這項資訊」，不要推測。以下情況不要回覆，改列進給我的待處理清單：問題超出 ［範圍］、涉及個人資料、指控、醫療／法律／投資建議，或你不確定來源是否支持答案。前 7 天只把回覆草稿交給我，不要發文。每天回報：讀了幾則、草稿幾則、轉給我幾則、監看是否中斷過。

## 所需連接、權限與限制

- 讀取：公開 X 提及可用官方的公開讀取；發文需要另外的帳號連接，方式與費用需自己在介面確認。原帖沒有成本資料。
- 規範（待查證）：第三方整理稱 X 的自動化規則限制主動式自動回覆、要求標示自動帳號，並對 AI 自動回覆另設事前核准；X 官方規則頁本次被擋、未讀到原文，上線前必須自行讀官方條款，不以本頁當合規依據。
- 內容風險：自動轉錄未校對、問句與發言者混在一起，可能把別人的話當成當事人的立場；回覆前的數字核對應保留紀錄。
- 公共議題：政治或其他有爭議的帳號容易被誘導答題、截圖斷章取義；固定婉拒句與人工保留清單是必要條件，不是選配。
- 著作權與下架：只引用短句並附連結；提供更正與下架管道，像原作者那樣在資料庫寫明。

## 驗收與可重現性

- 抽 20 則回覆，逐則打開來源確認答案有被支持、日期正確、不是自動轉錄裡別人說的話。
- 試幾個範圍外、誘導性與敏感的問題，確認會婉拒或轉人，而不是硬答。
- 查每日更新紀錄與監看健康檢查是否真的有跑；中斷後恢復時不重複回覆舊貼文。
- 本庫只讀公開帳號與資料庫，沒有標記該帳號測試、沒有重現。

## 去重與版本紀錄
