# UC-078：社群廣告上的租屋物件太便宜？先查屋主、紀錄與仲介，再決定要不要匯訂金

- 情境：生活
- 標籤：詐騙、租屋、資料查證、檢舉
- 網站標題：租屋廣告看起來太划算？請 Bot 查產權、評價與仲介資格，再決定要不要付訂金
- 一句話用途：看到租金與押金不合理、又沒有掛名仲介公司的物件時，請 Bot 依地址查公開的產權、歷史、評價與執照紀錄，整理成可交給平台或主管機關的證據；付錢前由人親自向正牌公司確認。
- 核心目標：在家人付款前，用公開資料找出「假房東」常見破綻，並把查到的證據整理好。

## 輸入與預期輸出

- 輸入（作者自述）：Instagram 廣告上的物件地址、對方訊息內容；兩個疑點——月租 998 美元、押金 900 美元；廣告沒有寫仲介公司。

## 為什麼這個用法值得看

租屋詐騙常見手法是盜用真實物件的照片與地址，再用低價和「先付訂金」催人。光看廣告很難分辨，但地址可以對到公開的產權、房屋歷史與合法仲介。這個案例把 Bot 用在付款前的查證，最後的確認與檢舉仍由人做，分工清楚。

## 建議操作流程（本庫設計，未實測）

1. 先列疑點：租金或押金明顯低於附近行情、沒有仲介公司或執照號碼、要求先匯款、不給看屋。
2. 只提供物件地址與廣告內容給 Bot；不要提供家人的身分證號、銀行資料或對話以外的個資。
3. 請 Bot 查公開資料：產權登記或屋主是誰、房屋是否正在其他平台以不同價格出租或出售、仲介公司與執照是否真實存在、地址相關的評價或詐騙回報。每項附網址與查詢日期，查不到就寫「查不到」。
4. 請 Bot 比對：廣告上的聯絡人與公開紀錄的屋主或仲介是否一致；照片是否出現在別的刊登。
5. 你自己透過**官網上的公開電話**（不是廣告裡的電話）聯絡正牌公司或屋主確認。
6. 確認是詐騙後，把截圖與 Bot 整理的來源表交給平台檢舉；在台灣可撥 165 反詐騙諮詢專線，在美國可向 FTC 回報。不要再匯款，也不要讓 Bot 用你的名義聯絡對方。

## 可複製提示詞（原創設計，未實測）

我家人看到一則租屋廣告，地址是［地址］，月租［金額］、押金［金額］，廣告沒有寫仲介公司。請只用公開資料查證，不要聯絡廣告上的人、不要填任何表單、不要付款。請查：①公開產權登記或屋主資料；②這個地址是否在其他平台以不同價格或身分刊登；③廣告提到的仲介或公司是否存在、執照是否有效；④與這個地址或聯絡方式相關的詐騙回報或評價。每一項附來源網址與查詢日期，查不到就寫「查不到」，不要推測。最後列出廣告內容和公開紀錄不一致的地方，以及我應該親自打哪個官方電話確認。你的結論只能寫「疑點」與「待確認」，不要直接斷定。

## 所需連接、權限與限制

- 只需要網頁研究；不需要登入家人的社群帳號或信箱。若要把對話截圖交給 Bot，先遮掉電話、帳號與其他個資。
- 產權與執照資料在各國、各州的查法與公開程度不同；台灣可用的公開管道與美國不同，Bot 查不到不代表沒有。
- 公開資料可能過時，屋主也可能真的委託親友出租；最後要以官方電話確認為準。
- 檢舉、打電話給公司、寄 PDF 都是對外動作，作者是自己做的；本庫不建議讓代理自動代辦。
- 作者沒有提供費用或用量數字。本輪未找到 Meta Muse 或 ChatGPT dots 的同類實例，不推定可照搬。
