# UC-112：把角色圖變成能轉動眼睛的3D列印小物

- 網站標題：一張角色圖，做成眼睛會轉的實體小模型
- 一句話用途：作者讓 Grok Bot 的 Maker 助手設計可列印角色，交出本體與眼睛分件，並自述已印成實物。
- 情境：創作
- 標籤：3D列印、分件設計、實體驗收
- 工具：Grok Bot／Bambu Studio／Bambu X1C
- 分類／標籤：創作／3D列印／分件設計／實體驗收
- 證據狀態：B 級作者實際製作自述；未下載模型、未重現列印。
- 查證日期：2026-10-17（台灣時間）

## 作者做了什麼

David Naffis把角色圖交給自己的Maker Bot，要求能在X1C列印且眼睛可轉。作者回報取得球形本體、分離眼睛與數個Bambu專案檔，並稱已印出實物。後續另整理模型平台刊登素材。

這是一次實體設計／製作自述，並未取得尺寸公差、耐久性或機台操作紀錄。模型平台連結此次不可讀，不能說已核對平台上的檔案、授權或下載狀態。

## 建議流程（本庫設計，未實測）

1. 用自己有權使用的角色圖，列出尺寸、分件及可動部位目標。
2. 先產出設計說明與分件檔清單，標示接合方式、間隙與尚待試印處。
3. 在有權使用的切片環境檢查模型尺寸、朝向、支撐、材料和機台相容性。
4. 人工確認安全設定及操作範圍後才決定是否列印，先做小範圍試件；模型生成不等於可直接安全上機。
5. 檢查組裝、可動性、碰撞、鬆脫及表面問題，將觀察交回修改。
6. 分享檔案前另核角色權利、模型授權、預覽與公開範圍。

## 可貼指令（原創設計，未實測）

請根據這張自有角色圖，先提出一個桌面小模型的分件設計：本體、可動眼睛、接合方式、建議間隙與需試件驗證的部分。只交設計規格及檢查清單，不連線印表機、不啟動列印、不上傳模型平台。不得宣稱可安全列印；把機台、材料及尺寸未知項列出，待人工核對。
