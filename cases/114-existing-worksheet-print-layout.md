# UC-114：把既有教材重排得更省紙，先核對內容沒有被裁掉

- 網站標題：老師的PDF太鬆散？保留內容，重排成更省紙的版本
- 一句話用途：作者把約79頁既有教材交給 Grok Bot 重新排版，自述減少用紙；實際頁數與內容完整性未公開。
- 情境：學習
- 標籤：教材、排版、列印、內容核對
- 工具：Grok Bot／PDF
- 分類／標籤：學習／教材／排版／列印／內容核對
- 證據狀態：B級作者實作自述；未取得前後檔案、未獨立重現。

## 實際用法

Reddit作者u/Sufficient_Flower860描述一份老師要求列印、版面鬆散的PDF。作者請Grok Bot重排，稱因此節省紙張。沒有說明重排後頁數、具體省紙比例或最後檔案格式，不能自行補成數字成效。

## 建議步驟（本庫設計，未實測）

1. 只使用有權處理的教材副本，移除學生姓名、成績或其他個資。
2. 先盤點頁數、文字、圖表、題目編號與作答空間，保留原件。
3. 建議調整留白、分欄或頁面配置；不要重寫題目、刪除答案選項、壓縮至難閱讀。
4. 先輸出少量樣頁供人工檢查，再處理其餘頁面。
5. 逐項對照題目、圖表、頁序及作答空間，列明缺漏與未確認頁，確認後才決定列印。

## 可貼指令（原創設計，未實測）

請用這份虛構練習卷做省紙排版提案。保留所有文字、圖表、題號和必要作答空間；先產出兩頁樣稿及原頁到新頁的對照表，不列印、不刪原檔。若內容過密或辨識不完整，標示待人工確認。只報實際產出的頁數，不預先保證節省比例。

## 權限、費用與可用性

- 原作者沒有交代方案、費用或PDF處理工具；掃描品質、公式與圖表都可能造成漏失。
- 教材著作權與授權範圍需另確認；不把完整教材上傳公開案例庫。
- 檔案重排不代表教育內容已審校或適合所有學習需求。列印與公開散布需另由使用者決定。
