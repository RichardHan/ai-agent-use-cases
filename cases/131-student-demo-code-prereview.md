公開文只支持已產出初稿。不知道是否使用特定評分規準，也沒有自動評分、送交學生、改善成績或回饋正確性的證據。

## 操作步驟（本庫設計，未實測）

1. 先確認教學資料可交給此服務；示範採合成、去識別的成人練習，不包含未成年個資、成績或憑證。
2. 記錄影片版本、對應repo與commit；只給需要讀的範圍。
3. 轉錄保留時間戳，分開學生說法、實際畫面與程式碼能支持的事項。
4. 初稿列觀察、證據位置、疑問及無法判斷處，不自行推定抄襲、能力或分數。
5. 教師親自檢查重點，再依自己的準則給正式回饋。

## 可貼指令（原創設計，未實測）

請只依我提供的虛構示範逐字稿與程式片段，整理第一輪觀察。每點附時間戳或檔案行號，將「作者宣稱」「程式可支持」「待人工確認」分開。不安裝工具、不執行專案、不評分、不發訊息給學生。

## 權限、費用與限制

- 安裝軟體、連接私人repo及提交學生資料需要各自適當授權，讀取不授權修改或寄出。
- 作者的Whisper配置、運算成本及方案未核；不能保證每個帳號支援同一路徑。
- 教育判斷由教師負責；AI草稿可能誤解影片、專案版本或學生意圖。
- 本庫沒有安裝或執行影片／專案，也沒有讀取任何私人學生資料。
