# UC-133：把餐廳菜單改成螢幕閱讀器能按標題跳讀的頁面

- 網站標題：不用一路聽完整張菜單，按分類和菜名直接跳讀
- 一句話用途：AppleVis作者自述讓Muse將餐廳菜單整理成H2分類、H3品項的可分享頁，方便螢幕閱讀器瀏覽。
- 情境：生活
- 標籤：無障礙、菜單、螢幕閱讀器、網頁
- 工具：Meta Muse
- 證據狀態：B級原作者實際使用自述；未取得成品頁逐項驗證。
- 查證日期：2026-10-17（台灣時間）

## 作者用法

Mika Pyyhkala在AppleVis的使用報告中說，每次到餐廳會請Muse製作標題式菜單：分類用H2、各菜用H3，輸出可分享連結。這是瀏覽介面的轉換，沒有證據說同頁已完成點餐或付款。

作者同頁也記錄進度訊息可能打斷朗讀、回覆需移動焦點，以及遠端瀏覽器交接不適合部分螢幕閱讀器；是2026年9月觀察，不能概括所有版本。

## 操作步驟（本庫設計，未實測）

1. 提供允許處理的菜單或虛構資料，保留來源與更新日期。
2. 分類與品項用有層級的標題；價格、選項及備註要與正確品項相連。
3. 不自行補價格、配料或過敏原；不確定處明標並請餐廳確認。
4. 由使用者以實際螢幕閱讀器測標題跳轉、閱讀次序及連結文字。
5. 發布或分享前確認內容權利及範圍；點餐與付款另外核准。

## 可貼指令（原創設計，未實測）

請把這份虛構菜單設計成螢幕閱讀器易讀的結構草稿：分類H2、品項H3，價格與備註緊跟品項。不要新增未知內容、不要發布、不要點餐。附上標題導覽及閱讀順序的人工驗收清單。

## 權限、費用及限制

- 沒有取得作者實際頁面，不保證菜單完整、價格正確或符合所有無障礙標準。
- 不推定來源是圖片、使用OCR或有可靠過敏原辨識；飲食安全應向餐廳確認。
- 方案、地區可用性及費用未核。公開分享可能涉及菜單權利，不能任意複製發布。
- 本庫未操作裝置、建立網站或點餐。
