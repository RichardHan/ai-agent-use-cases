# UC-137：將PDF送到訪客列印佇列，留給本人現場取印

- 網站標題：到圖書館才發現還沒設定列印？先把PDF排進佇列
- 一句話用途：作者用Muse準備訪客列印帳號、PDF與上傳工作；官方流程仍須本人到印表機選擇放行，沒有已拿到紙本的證據。
- 情境：生活
- 標籤：列印、文件、交接、驗收
- 工具：Meta Muse／Stanford Cardinal Print
- 證據狀態：B級原作者完成上傳自述；原始列印工作、付款與紙本未獨立驗證。
- 查證日期：2026-10-17（台灣時間）

## 作者完成範圍

Benedikt Stroebl描述自己需要在Stanford圖書館列印PDF，Muse替他處理訪客帳號、加值、整理並上傳文件，然後告知可到樓下印表機。這是作者對實際任務的自述；沒有公開付款收據、列印選項、工作編號或領取紙本結果。

Stanford官方訪客說明確認：訪客自行支付列印費，建立或登入帳號、加值、上傳及選設定後，仍須到可供公眾使用的設備登入，選擇文件放行。校方受邀來賓的帳號與費用安排不同，不能混用。

## 操作步驟（本庫設計，未實測）

1. 先確認圖書館訪客資格、公開可用設備、營業時間與現行費率。
2. 在本機或受許可的安全環境核PDF頁數、順序、是否含機密、紙張／彩色／雙面設定；本庫未操作任何個人裝置。
3. 列出需本人完成的帳號、登入及付款步驟，不索取或保存密碼／卡號。
4. 只有文件外傳、目的服務及費用獲核准後，才交接上傳；保留工作名稱、頁數、選項與狀態供本人核對。
5. 將「已上傳」「待現場放行」「紙本已領取」分開；沒有讀回的狀態不可宣告完成。
6. 本人現場確認機器與文件，再放行及領取；不自動重送造成重複收費。

## 可貼指令（原創設計，未實測）

請依公開訪客列印說明，替一份虛構12頁PDF準備列印交接清單。列紙張、雙面、彩色、頁碼、費率待核及現場放行步驟。只整理清單，不註冊帳號、不輸入憑證、不加值、不上傳或送印。成功狀態要分已上傳、待放行、已領取。

## 權限、費用與限制

- 官方流程涉及付費及文件上傳；原作者做過不代表讀者已授權代理執行。不得把付款憑證寫入聊天或公開案例。
- 費率、登入權限、平台支援與個人方案未逐一驗證；官方頁面不保證Muse可全程操作。
- 沒有原始PDF、工作單或紙本驗收，不宣稱文件正確、列印成功或節省時間。
- 研究未建立帳號、加值、上傳或控制印表機。
