# UC-159：參考肖像繪製時，筆刷與填色工具反覆選錯的失敗驗收

- 網站標題：畫得不像就重來？先檢查筆刷、填色與工具模式
- 一句話用途：作者實際請Grok Bot用Krita／Paint參考頭像繪製，遇到同粗筆觸、填色模式誤判和重畫循環；不是全產品能力判定。

## 作者觀察到的失敗

Wanderson Ricardo以自己的頭像作參考，實際嘗試由Grok Bot操作Krita及Paint繪製肖像。作者稱Krita選過筆刷後仍只畫同粗細藍色筆觸；Paint停在多邊形工具，改了線色卻以為完成填色。核圖不符後整張擦掉再畫，進入循環。

這是一次具體任務的失敗報告；沒有證明工具普遍無法切換，也沒有完成肖像的可靠證據。附影片未看，本庫不以文字敘述冒充已逐畫面驗收。

## 操作步驟（本庫設計，未實測）

1. 用有權使用的虛構參考圖，另存初始畫布與版本，不覆寫原稿。
2. 先做小測試塊：確認當前工具、筆刷粗細、線色、填色及作用圖層。
3. 每一步對照實際畫布，不能只相信工具名稱或操作回報。
4. 將輪廓、色塊和細節分開驗收；不符合就指出單一步驟，而非整張刪除重畫。
5. 反覆出現相同錯誤時停止，保留畫布和操作差異供人工處理。
6. 未通過小測試不擴大到整張作品，不把生成圖像能力等同編輯軟體操作能力。

## 可貼指令（原創設計，未實測）

請設計一張虛構肖像練習的筆刷／填色驗收清單，列工具模式、線色、填色、粗細與圖層的可見結果。不要操作真軟體或刪除畫布。遇到重複錯誤就標停止點，不宣稱已完成作品。
