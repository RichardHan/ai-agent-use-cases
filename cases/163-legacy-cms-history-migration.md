# UC-163：網站搬家時，保留歷史日期、完整本文與舊連結

- 網站標題：舊文章搬家，別讓十年前的內容變成今天新發的
- 一句話用途：作者自述用Grok Bot搬移18篇舊文，保留日期與轉址、補回截斷本文；主機暫停與SSL由客服協助。
- 情境：工作
- 標籤：網站遷移、歷史內容、轉址、驗收
- 工具：Grok Bot／WordPress／EasyWP／既有匯出檔
- 證據狀態：B級作者實作及上線自述；未逐篇核對資料完整性。
- 查證日期：2026-10-17（台灣時間）

## 作者實際完成與未完成

Jonathan Brown（JDB Consulting）的英文原文發布於2026-08-22 18:00 UTC，頁面亦列8月25日更新。他稱先在staging搬移舊Azure／WordPress及後期站點文章，清理Word匯出雜碼、以較完整版本補正文，並由Wayback找回遺失舊文。18篇保留原日期及舊路徑轉址，作者審閱後切換上線，部分文字仍待改寫。

staging曾遭暫停，雙方同時編輯只是作者猜測；主機客服解除並處理SSL問題，不算代理獨立修復。本站沒有逐篇原文、附件或全轉址驗收報告，不採耗時自述作一般效率承諾。

## 可借用的驗收步驟（自設、未測）

1. 唯讀盤點舊文章網址、日期、正文摘要及附件清單。
2. 比對匯出資料與可授權取得的歷史版本，截斷或缺圖留待人判斷。
3. 建立舊路徑→新路徑對照與staging抽查表，保留原發表日、另列遷移日。
4. 切換需另核授權；切換後再測舊網址、圖片、內部連結和HTTPS，未過項不得寫全部完成。

## 可貼指令（自設、未測）

只讀我的已授權網站匯出檔及公開舊頁。列出文章數、原發表日期、正文疑似截斷、附件缺漏與舊網址對照。提出staging驗收清單，不登入、不匯入、不改DNS或憑證、不刪舊站。把已核與待核分開，日期衝突不要自行取今天日期。

## 權限、費用與官方限制

主機方案與外掛成本須以實際帳號確認，原文不是目前報價。匯入、DNS與公開發布均需相應權限，本庫沒有執行。

WordPress官方匯出程式含發表日期及附件網址欄；WXR不含完整站台設定或附件檔本身。遷移手冊要求檢查舊轉址、文章圖片與硬編碼連結。這些是驗收背景，不證明作者那次資料全數完整。
