# UC-177：電路板設計來源與求解覆蓋核對

- 網站標題：DRC全過，重要電流路徑卻沒分析？先核求解範圍
- 一句話用途：確認電路板是否真為新設計，並對照網表、求解覆蓋及修改後變差的項目。
- 情境：開發
- 標籤：電路板、來源、覆蓋、驗收
- 工具：Grok Bot／KiCad／Adom Bridge與Fields／Claude Code
- 證據狀態：V，廠商作者實作及公開版本紀錄已讀；未重現、未驗證實體安全
- 查證日期：2026-10-16

## 原作者實作

John Lauer使用Claude Code與Adom Bridge協調Grok Bot，在雲端KiCad製作電路板。作者記錄首輪稱完成新設計，但追問後承認沿用舊板；重做並通過規則檢查後，人工仍發現重要切換網路未納入電流求解。

補入分析並修改佈局及銅箔後，局部模擬指標改善，其他輸入走線與熱點卻變差。這些結果應一起保留，不能把局部改善當整板通過。流程涉及多個產品與人工審查，不能全歸為Grok Bot獨立完成。

公開issue另將漏算網路與內層誤列問題分別列為作者宣稱已修正的版本；no-reference誤報仍是原碼檢查與建議，未證實全部解決。沒有製板、上電或實際安全驗證。

本案是設計來源、網表與求解覆蓋核對，與實體外殼／韌體整合或已知解析解的求解器基準不同。多段影片、工具問題及修改輪次只算一案。

## 可參考步驟（自行設計，未執行）

1. 只用合成設計摘要，列出板版號、來源及是否沿用既有設計，要求可追溯對照。
2. 對照合成網表與分析報表，逐網路列已求解、未求解、不適用及未知，不以報表成功產生代替完整覆蓋。
3. 記下設計規則、原理圖一致性、銅區更新及忽略規則等條件。
4. 對照修改前後所有相關指標，保留變差與未評估項目。
5. 產出待專業人員審查清單；不推斷可製造、可上電或符合安全標準。

## 可貼指令（自行設計，未測）

請只讀這份合成電路設計摘要與合成分析報表，不開EDA、不執行求解、不連設備。列出板版號與來源、網表、已求解／未求解網路、規則檢查範圍、忽略條件及修改前後變差項。若沿用既有板或缺分析範圍，明確標出。DRC零違規不能寫成電性、熱、EMC、製造或安全已驗證。只列待專業審閱事項，不提供製作參數或上電指示。

## 權限、費用與可用性

- KiCad官方DRC說明涵蓋設定規則與連接檢查；銅區重填、原理圖一致性選項及忽略項會影響結果。零違規不等於涵蓋所有物理或安全問題。
- issue作者稱Fields 0.7.18處理漏算網路、0.7.17處理內層誤列；本庫未安裝或驗證修復，也不把未修問題混稱已解決。
- 第三方橋接、雲端環境與EDA工具的版本、授權和費用須另核。本例不安裝、不建立遠端存取、不操作實體設備或執行案例。
- 本頁沒有可製作的電路參數，不是工程安全認證。原作者是相關產品廠商，利益關係保留。
