# UC-180：相片庫標題與描述性中繼資料補齊

- 網站標題：相片沒有文字線索？先補描述，再核是否真的寫回
- 一句話用途：為既有相片整理非視覺描述，區分生成文字、成功寫回與仍待處理。
- 情境：生活
- 標籤：相片、描述、無障礙、部分完成
- 工具：Meta Muse／iCloud Photos
- 證據狀態：B，作者部分完成自述；無描述樣本或寫回紀錄，未重現
- 查證日期：2026-10-16

## 原作者實作

AppleVis作者Mika Pyyhkala說，曾要求Muse為iCloud最近100張相片建立標題與說明，以增加非視覺文字線索。作者表示約做了50張後遇到iCloud端問題，恢復連接後正在再試。

原文沒有實際標題／說明樣本、逐張狀態或寫回截圖。「約50張」只是部分處理自述，不能等同50張已驗證寫回，更不能稱100張完成。故障根因與恢復後結果均未核實。

本案是既有相片庫描述性中繼資料補齊，與製作紀念冊、分類參考圖或生成新圖片不同；每張照片不另算案例。

## 可參考步驟（自行設計，未執行）

1. 先以合成、無人物身分資訊的少量圖片，設計簡短標題與客觀可見內容描述。
2. 不推斷人物身分、健康、情緒或其他不可直接確認的敏感屬性；不確定內容明示不確定。
3. 分別記錄待生成、文字草稿、待本人核准、已寫回且讀回、未知及失敗。
4. 中斷後先比對既有狀態，避免同一相片重複覆寫或將生成文字誤當寫回完成。
5. 若未來另有修改授權，先確認圖庫是否共享與說明可見範圍，再由人核對少量結果；不直接批次處理私人圖庫。

## 可貼指令（自行設計，未測）

請只為這些合成圖片草擬客觀、簡短的標題與描述，不連任何相片庫、不下載私人照片、不寫入。只描述可見物件和構圖，不猜人物身分或敏感資訊。列出不確定處，另做狀態表區分生成、待核准、寫回及讀回驗證；沒有寫回證據一律不可標完成。最後列共享可見性和中斷後重複覆寫的人工檢查項。

## 權限、費用與可用性

- 私人相片可能包含本人、未成年人或其他人的敏感資訊；公開案例不授權存取或傳送照片。本頁不收錄作者私人相片或健康資料。
- Apple官方說明iCloud照片標題／說明可修改；共享圖庫中的說明會對參與者可見。這只支持功能與可見性限制，不證明原作者寫回成功。
- Muse、iCloud帳戶、儲存容量與地區可用性需另核。沒有證明任何設定可解決原故障，也未測費用。
- 描述文字存在不等於準確或符合無障礙標準，仍需本人及實際輔助工具使用者確認。本庫未連接或修改相片庫。
