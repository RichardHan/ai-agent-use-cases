# UC-182：依閱讀需求選書與圖書館預約

- 網站標題：想讀的書先幫你挑，再確認圖書館真的可以領
- 一句話用途：把閱讀需求轉成借書候選與預約，清楚區分排隊、到館通知及實際領取。
- 情境：生活
- 標籤：閱讀、圖書館、預約、驗收
- 工具：Meta Muse／作者未具名的圖書館帳戶
- 證據狀態：B，作者預約及收到可取通知自述；無館藏與通知紀錄，未重現
- 查證日期：2026-10-16

## 原作者實作

Eleanor Konik於2026-10-12文章的「Library books and a dead dishwasher」段描述：請Muse依閱讀需要找書、挑選書名並提出圖書館預約，幾天後收到郡方的可取書通知。原例是尋找適合較年幼讀者的西洋棋書。

可取通知是圖書館寄給作者，沒有證據是Muse監看或驗證通知。作者明說發文後才要去取書，因此不能寫成已領到、讀完或符合閱讀程度。文章未給館名、書名、版本、館藏紀錄或通知內容，也未核代理如何取得帳戶權限。

這是借閱候選到館藏預約的流程，與付費買書、教材製作、課程規劃或公共列印排隊不同。一本或多本書合計一例。

## 可參考步驟（自行設計，未執行）

1. 使用不含個人或孩童資訊的虛構閱讀需求，列主題、語言、難度及格式。
2. 在公開館藏資料中草擬候選，附書名、版本、作者與可見狀態；不能確認就保留未知。
3. 由本人確認借閱資格、取書地點、期限及預約限制，再另行決定是否登入和提交。
4. 分開記錄候選、待本人核准、預約成功、運送或排隊、可取、已領、過期；每一步需相應證據。
5. 收到通知後由本人確認來源與期限；不要用預約成功畫面宣稱已可領取。

## 可貼指令（自行設計，未測）

請依這份虛構閱讀需求整理公開館藏候選，不登入、不借閱、不預約、不聯絡圖書館。列出書名、作者、版本、來源及資料中的可借狀態，不推斷適讀性或庫存。另做預約到取書的狀態表，說明每一步要看到什麼證據；沒有通知不能標可取，沒有本人確認不能標已領。不要收集孩童資料或借閱卡號。

## 權限、費用與可用性

- 借閱帳戶、卡號與借閱歷史具有隱私性；案例不授權交給代理。帳戶存取、預約、取消或通知均須另核權限。
- 另一家圖書館的官方說明可用來理解排隊／運送／可取／過期不同，但不是作者的圖書館，不能套用其欄位、期限、費用或代理操作許可。
- 原作者未交代館方費用、地區限制、Muse方案或當前帳戶支援；沒有證明所有館藏系統都可用。公開館藏不等於可自由代理登入。
