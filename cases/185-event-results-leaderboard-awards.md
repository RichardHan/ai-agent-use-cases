# UC-185：活動成績自動整理成排行榜，再由人核對得獎名單

- 網站標題：活動成績出爐後，把排行榜和獎狀一起準備好
- 一句話用途：將定期匯出的活動資料整理成展示榜單，依人工核定的結果製作獎狀並保留得獎紀錄。

## 作者實際使用

Robert Mak描述公司的活動流程：另一個手機自動點擊工具在早上匯出StepUp前一天CSV並寄出；Grok Bot接手排序資料、更新Canva排行榜供電視展示，再依週結果準備獎狀。活動照片由人從WhatsApp整理評選，將決定交給Bot製作相應獎狀及保留獲獎類別紀錄。

匯出與寄送是外部自動化，不應全歸為Grok Bot自主取得。照片評選是人的工作，不是Bot判斷參與者。本庫只計「活動資料到經人核獎的展示產物」一個流程，不按日期、榜單或獎狀張數拆算。

## 可試流程（本庫設計，未執行）

1. 使用自行編造的成人代號與一般遊戲積分，完全不使用真步數、照片或員工資料。
2. 固定活動日期、時區、計分規則與有效參與名單；將重複列、缺資料、跨日資料列為例外。
3. 產生可回溯原始列的排行榜；並列名次及尚未決定的獎項留待人處理。
4. 只依另外提供的人工核定得獎表，產生離線獎狀文字與欄位清單。
5. 比對榜單、核定表和既有頒獎紀錄，防止錯名、重複頒發或把未核定項目印出；停止在預覽階段。

## 可貼指令（自設、未測）

請用這份合成活動積分CSV，依我提供的日期、時區和計分規則整理排行榜。先列缺漏、重複和並列名次，不猜缺分，也不自行評選任何人。再依人工核定得獎表準備獎狀文字，逐項附來源列與核定依據。沒有核定的獎項保持待確認，已有頒發紀錄的項目標示重複。只輸出離線草稿，不登入服務、不讀照片、不發信、不分享或發布。

## 驗收與去重

人工可從每個名次和獎狀返回原始合成資料及核定表，日期一致、並列未偷改、例外完整才算草稿可審。這不是健康評估或人員績效評分。不同於UC-025報名與通知核對、UC-083教材版面、UC-108個人高爾夫分析；各輸出同屬一次活動成果流程。
