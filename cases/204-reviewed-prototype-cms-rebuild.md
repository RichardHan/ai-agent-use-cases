# UC-204：審閱後的網站原型到既有後台重建

- 網站標題：新網站設計看好了，再逐區塊搬進真正後台
- 一句話用途：將已審閱原型落到既有網站編輯器，分開設計完成、後台寫入與公開結果驗收。
- 情境：工作
- 標籤：網站、原型、後台、驗收
- 工具：ChatGPT dots／未具名網站後台
- 證據狀態：B，媒體作者親自使用及完成自述；無逐區塊對照或回退紀錄，未獨立重現
- 查證日期：2026-10-16

## 作者實際結果

Allison Johnson先與dot多輪修訂個人網站原型，再讓它操作網站後台逐區塊重建。她目睹操作並回報網站更新完成。來源未指明CMS，沒有前後逐項驗收、回退紀錄或像素一致證據。本案只計原型到既有後台實作；同文影片剪輯不另計。

## 可參考步驟（自行設計，未執行）

1. 使用自己有權編輯的測試網站與已核准原型；先列每個頁面和區塊，不開始發布。
2. 保存目前內容與可用回退方式，核對原型版本、待變更欄位和必須保留的網址／表單。
3. 先在草稿環境重建一個區塊，對照文字、連結、圖片授權及手機版，再由人決定是否繼續。
4. 分別記下已編輯、已儲存、已發布與公開可見狀態。後台成功訊息不能代替公開頁檢查。
5. 有不同或缺件時交付差異報告，不自行替換重要內容、外掛或分享設定。
