# UC-221：人簽完文件後，讓Muse取回正確副本與完成回條

## 實際測到的範圍

服務商描述：Muse準備PDF及報價，測試者在服務網頁親自簽署，Muse之後取回已簽PDF及證書頁。這是本人自簽測試；傳給其他人簽尚未在Muse內測試。不能寫成Muse代簽，也不能因證書頁存在便保證法律效力或身分已核驗。

主頁標示9月24日檢查，但另含9月25日測試；因此日期只用於明載的自簽實驗。其郵寄、傳真與物流API測試不能算Muse已實作。

## 可借鑑的交接

1. 先固定待簽文件版本、簽署者角色及報價。
2. 把簽名與接受義務留給本人明確決定。
3. 簽後取回副本及服務回條，核對文件版本、狀態與缺件。
4. 未知或只收到中間頁時，不回報全部完成。
