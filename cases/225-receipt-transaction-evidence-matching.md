# UC-225：先補齊收據，再把每筆交易配回憑證

- 情境：工作
- 標籤：收據、對帳、缺件、核准
- 網站標題：月底不用翻遍網站：先列缺哪些收據，再配回交易
- 一句話用途：把已存憑證、待取得文件及交易候選分開，讓人工核准有明確依據。

## 小範圍試法（本庫設計，未執行）

1. 用十筆合成交易及七張虛構收據，先列哪些文件已存在；保留原始檔，不重複收集。
2. 分別比較交易日期與入帳日期、幣別、商戶及金額；同額同日不能單憑兩欄確認。
3. 將一對一候選、合併付款、分拆收據、退款及未找到分列，保留來源列號。
4. 人工確認後才另行討論正式寫回。報告顯示已讀期間與截止日；沒有新明細時不得沿用昨日數字稱今天已完成。
