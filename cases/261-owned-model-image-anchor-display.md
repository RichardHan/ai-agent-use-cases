# UC-261：既有3D模型的圖像錨定展示

- 網站標題：把自己的3D模型，疊到鏡頭裡的平面圖案上

## 作者做了什麼

Josephine Miller稱將自己在Blender製作的3D模型以.glb提供給Muse，建出AR image tracker app，並回報能運作。本庫讀到原貼文字及其海報幀：作者持胸牌，該處有3D圖像疊加。

單張畫面不證明連續追蹤穩定、尺度準確、遮擋處理或不同手機兼容。沒有觀看完整影片、取得模型或閱讀App程式，也不知道所用AR框架；不能補寫成MindAR、WebXR或其他特定實作。

## 可借鑑流程（驗收部分為本庫設計）

1. 選自己有權使用的模型與不含個資的平面測試圖。
2. 記錄模型來源、版本、材質外部依賴與預期錨點關係。
3. 將首次顯示、持續對位、移出畫面後重新取得錨點分開記錄。
4. 以固定角度、距離、光線及遮擋條件設計人工測試表。
5. 保留失敗畫面及裝置條件，不把一次展示擴張成通用兼容保證。
