# UC-269：一台不想自己顧的 VPS，交給「系統管理 Bot」：白話下指令、每小時看內容、每週更新後確認

- 情境：開發
- 標籤：伺服器維運、排程、驗收、權限
- 網站標題：自己架的小網站主機，讓 Bot 幫你顧：重啟、更新、防火牆都用白話講，改完要它證明網站還活著
- 一句話用途：把舊的設定筆記、設定檔與網站原始碼交給一個專責 Bot，之後用白話要它重啟服務、鎖版本、開防火牆、加憑證；再排定每小時檢查首頁關鍵字、每週固定時間更新並確認網站在線，必要時回滾。
- 核心目標：讓不常碰 Linux 的人，也能對一台「只有一台、不值得寫完整基礎架構程式」的主機做可驗證的維運：每個指令都要附「確認網站正常」的結果。
- 分類／標籤：開發維運／單機伺服器／排程健康檢查
- 適用工具：Grok Bot（作者自建 sysadmin Bot，手機 App 下指令）；作者自己的 VPS、monorepo（設定筆記、設定檔、網站根目錄）
- 目標使用者：自架個人網站、社團或小型非營利網站，主機重要但沒有專職維運的人
- 首次收錄／最近查證：2026-10-17（台灣時間）
- 證據狀態：author-demo。作者在 Hacker News 留言的第一人稱使用自述；無日誌、截圖或設定快照。
- 是否獨立重現：否。本庫未連任何主機。

## 輸入與預期輸出

- 輸入：歷史設定筆記、設定檔與網站根目錄（作者放在 monorepo）；給 Bot 的 SSH 存取（作者給的是 root 金鑰）。
- 白話指令（作者列舉，翻譯改寫）：「現在重啟 nginx 並確認網站正常」「把 mariadb 鎖在 12.3.*」「還有哪些安全建議沒做」「開防火牆，只留 22、80、443；確認 ssh 有 fail2ban、不接受密碼登入」「把某網域加進 Let's Encrypt」。
- 排程（作者列舉）：每小時檢查首頁是否含指定字串（作者例子是 `Products`），不含就登入修復；每週一早上 6 點跑更新、需要就重啟，之後確認網站在線，必要時可回滾更新。
- 預期輸出：每個動作的執行結果＋事後確認（服務狀態、網頁回應、字串比對）。

## 建議操作流程

以下為本庫設計，未實跑：

1. 先把主機現況整理成一份「設定筆記」：服務清單、版本、對外埠、憑證網域、備份位置。沒有備份前不要讓 Bot 執行更新。
2. 不要直接給 root 金鑰：先建專用帳號，只允許必要的 sudo 指令；金鑰放在 Bot 的安全憑證輸入，不貼進聊天或 repo。
3. 每個指令都要求三段回報：要執行什麼（完整命令）、執行輸出、事後驗證（例如 `systemctl is-active`、HTTP 狀態碼、首頁字串）。
4. 防火牆與 SSH 設定變更前，先確認還有主機商的主控台可救援；變更後立刻用新連線測試，舊連線保持開著。
5. 排程：每小時只讀檢查（狀態碼＋關鍵字），不符時先通知，不要一開始就授權自動修；每週更新前先快照或備份，更新後驗證，失敗才依事先寫好的回滾步驟處理並通知。
6. 每次變更寫進 repo 的變更紀錄，方便下次換機或追查。

## 可複製提示詞

本庫原創設計，未實跑：

> 你是我這台主機的維運助手，但這次只做規劃，不連線、不執行任何命令。請根據我貼的設定筆記（已去除密碼與金鑰），列出：1）目前服務與對外埠清單；2）我要求的變更（防火牆只開 22/80/443、SSH 禁止密碼登入、fail2ban、為某網域申請憑證）各自的完整命令、風險、事前檢查與事後驗證命令；3）每小時健康檢查規格（網址、預期狀態碼、預期字串、失敗時只通知我）；4）每週更新的步驟、備份點與回滾條件。把「可能把我鎖在門外」的步驟標成高風險並放最後。不要建立排程或連線，等我逐項核准。

## 所需連接、權限與限制

- 權限：作者給了 root SSH 金鑰，這等同把整台主機交出去；本庫建議最小權限帳號與 sudo 白名單，並保留主機商救援主控台。
- 對外動作：修改防火牆、SSH、資料庫版本與網站程式都可能造成停機；「必要時回滾」要事先定義條件與步驟，不能交給 Bot 臨場判斷。
- 排程：官方 [skills and routines](https://docs.x.ai/grok-bot/skills-routines-and-automations) 文件說 routine 可依時間表（或支援的事件）執行，並建議先把一次性任務做穩、存成技能後才自動化。這只說明排程功能存在，不保證準時或修復成功。
- 資料：設定筆記與 repo 不要含密碼、API 金鑰或使用者資料；若網站有會員資料，需另評估讓 Bot 讀取的範圍。
- 費用：每小時檢查與每週更新都會耗用 Bot 用量；純只讀的關鍵字檢查也可用傳統監控工具處理。

## 驗收與可重現性

- 在測試機上先跑一次「重啟服務＋確認首頁字串」，比對 Bot 回報與自己用瀏覽器看到的結果。
- 故意讓首頁字串消失，確認排程只通知、不亂改。
- 防火牆變更後用新終端機連線，確認沒有被鎖在門外。
- 本庫只讀作者公開留言與官方文件，未重現任何操作。
