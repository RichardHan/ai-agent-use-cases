# UC-273：睡覺時讓個人代理接力指揮程式代理：任務邊界清空上下文、額度恢復準時續跑

- 情境：開發
- 標籤：跨代理、排程、額度、多代理
- 網站標題：晚上不想守著 Codex 或 Claude Code？讓個人代理在對的時間點替你下下一步
- 一句話用途：大目標交給個人代理（dots 或 Grok Bot）保管，由它在程式代理完成一小段時清空對話、再派下一段，或在用量額度恢復時準時把未完成的任務送回去，早上再驗收。
- 核心目標：把「等額度恢復」「每段做完要手動清上下文」這類必須有人守在螢幕前的小動作交給代理，讓長時間的開發任務能在夜間繼續推進。
- 分類／標籤：開發協作／跨代理排程／用量管理
- 適用工具：ChatGPT dots＋Claude Code（經使用者 Windows 電腦 SSH 到 Linux 機器）；Grok Bot＋使用者 Mac 上的 Codex（命令列）
- 目標使用者：已經用 Codex 或 Claude Code 跑長任務、常卡在用量上限或上下文膨脹的開發者
- 首次收錄／最近查證：2026-10-17（台灣時間）
- 證據狀態：author-demo。兩位作者各自實際操作的自述；Zenn 長文（含官方文件對照）與 X 貼文＋對話截圖。
- 是否獨立重現：否。

## 輸入與預期輸出

- 輸入：一個較大的開發目標或一個做到一半的任務；程式代理所在的電腦（需保持開機、App 在線）；額度恢復時間（版本 B）。
- 輸出：程式代理在夜間持續完成小段任務；個人代理在聊天中回報「已送出／成功與否」；早上可在程式代理的執行緒或檔案中驗收成果。

## 建議操作流程

以下為本庫設計，未實跑：

1. 先把目標拆成可獨立驗收的小段，每段寫清楚完成條件（測試通過、檔案存在、指令輸出）。
2. 讓個人代理保存「目標、已完成段落、下一段」的進度表；每段結束時先寫進度，再清程式代理的上下文。
3. 額度接力用「單次排程」：寫明時區與時間、要送的完整指令、完成後刪除排程，避免每天半夜重跑。
4. 要求回報實際執行位置（介面執行緒或命令列）與產出路徑，早上依路徑驗收，而不是只看「已完成」。
5. 遇到登入、權限彈窗、刪除檔案、推送或部署時一律停下等你確認。

## 所需連接、權限與限制

- 個人代理需要能操作程式代理所在的電腦（dots 的電腦連接、Grok Bot 的本機連接等），屬高權限；只開必要資料夾與指令。
- 電腦與 App 必須整夜在線；斷線或彈出登入視窗時任務會卡住。
- 額度與計費依各產品方案，代理開出的程式任務仍會用掉程式代理的額度。
- 個人代理只轉述「已送出」並不代表程式任務正確完成；仍需人工驗收。
