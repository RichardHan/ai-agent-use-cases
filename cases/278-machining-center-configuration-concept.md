## 實際做了什麼

作者在自己節目的逐字稿約08:18段落說，建立名為「設計君」的 Grok Bot，來回討論數次後做出想用的加工中心構型網頁，並請它製作展示影片、於當天早上發到X。這是作者實際開發回報，不是單純列出想做的App。

輸入包括立式／臥式、3／4／5軸，以及五軸的旋轉軸放在工作台或主軸頭；輸出是相應機台的簡易3D概念。公開倉庫 README 明確稱為試作，index.html可讀到上述選項，另有混合轉軸配置、行程、主軸數與構架參數。程式存在支持產物可追查，但本庫沒有執行來驗證每個組合或動畫。

## 實作與限制

1. 作者先定義自己想探索的機台構型，再與專責Bot反覆調整網頁。
2. 選擇參數後，以3D外觀比較配置；不是從掃描逆向還原，也不是組裝既有零件圖。
3. 作者製作展示內容後公開程式；原始完整對話、精確提示詞、修改輪數、耗時與費用未取得。
4. 這只證明概念工具已做出並公開，不能推論機構可製造、剛性足夠、軸行程正確、無碰撞或可產生安全加工程式。

公開[10月12日修正提交](https://github.com/tsunezoworks/mc-builder/commit/b3a4ab5f85c84ff89155c09e25c46b86e8b8d669)另記錄：立式五軸的A軸有滑桿卻沒有對應驅動物件，補上搖籃傾斜軸註冊。這是可讀的修正紀錄，提醒「選項存在」不等於動作已接通；本庫未重跑，也不能僅憑提交判定這次修正由Bot完成。

## 可借鑑流程（本庫設計，未實跑）

- 先列有限的構型及參數，標出哪些組合僅是概念。
- 每個選項都保留文字結構說明，讓工程師核對圖形與參數是否一致。
- 用少量基準配置逐項驗收，再增加主軸數、行程與混合軸等變體。
