# UC-291：賽季先用暫定時間排進日曆，比賽當天早上核對正式開球時間並問要不要改

- 情境：生活
- 標籤：日曆、運動、提醒、核准
- 網站標題：球賽先排「暫定18:00」？比賽當天讓 Bot 查正式開球時間、算好出門時間，再問你要不要改日曆
- 一句話用途：作者賽季初把球隊全部賽程以暫定的晚上6點寫進日曆，沒設任何更新流程；比賽當天早上Grok Bot主動提醒實際下午3點開球、建議提早出門並附場邊資訊，再詢問是否修正日曆。
- 核心目標：讓先用佔位時間建立的行程，在正式時間公布後被發現並修正，且改日曆前先徵得本人同意。
- 工具：Grok Bot（作者對話標為 sport-analyst）；建立原始日曆事件的代理作者稱為 Hermes，產品身分本庫未查證
- 分類／標籤：個人行程／日曆校正
- 目標使用者：追蹤球隊、演出或任何「時間晚點才公布」活動的人
- 首次收錄／最近查證：2026-10-17（台灣時間）
- 證據狀態：author-demo，作者兩則串文自述＋一張Bot訊息截圖（捷克文）；日曆是否實際修正未見。
- 是否獨立重現：否

## 輸入與預期輸出

- 輸入：日曆中已存在、時間為佔位值（18:00）的比賽事件；公開的正式賽程資訊。
- 輸出：一則提醒訊息：正式開球時間、與日曆的差異、建議出門時間（由16:30改為13:30左右）、場邊資訊（餐飲攤位中午開、2號門球迷區12:30開），最後詢問「要我幫你改日曆裡的時間嗎？」

## 建議操作流程

本庫依來源整理，未實跑：

1. 建立暫定時間的事件時，在標題或備註標明「時間暫定」，方便日後篩出需要核對的事件。
2. 設一個只讀檢查：每天早上（或賽前兩天）找出今天與近期標為暫定的事件，查官方賽程的正式時間。
3. 時間不同時，回報日曆時間、官方時間、來源連結與建議出門時間；先問再改。
4. 本人同意後才修改該筆事件，改完讀回日曆確認時間與提醒都已更新，並移除「暫定」標記。

## 可複製提示詞

## 所需連接、權限與限制

- 需要讀取日曆；修改日曆屬寫入權限，應每次先取得同意（來源Bot也是先詢問）。
- 賽程資訊以官方來源為準；轉載網站可能延遲或錯誤。
- 建議出門時間依賴交通假設，需要本人確認。
