# UC-306：素材圖批次製作、關鍵字檔與圖庫上傳

- 網站標題：把素材圖、標題與關鍵字整理成可提交的一批
- 一句話用途：從圖庫題材到成套圖片、標題關鍵字CSV及品質檢查，追蹤批次上傳狀態，不把上傳等同審核通過。
- 情境：創作
- 標籤：素材圖、批次、中繼資料、品質、提交
- 分類／標籤：素材圖、批次、中繼資料、品質、提交
- 工具：Grok Bot／Upscayl／Adobe Stock

## 可參考流程

以下為本庫設計的離線驗收，未實跑：
1. 用自有合成測試圖與題材清單，指定用途、構圖及留白條件。
2. 建立唯一檔名與批次ID，將每張圖對應到標題、關鍵字及人工覆核欄位。
3. 分開檢查圖像瑕疵、描述是否相符、CSV漏列與重複檔名；放大不代表品質提升。
4. 將權利、生成內容標示及其他必填條件列待核，依當時官方規則和本人權利文件覆核；不憑模型判定合法。
5. 最終提交前核准圖片、說明與目的帳號。分開記錄未上傳、已上傳、待審、通過及退件；不能把代理回報代替平台狀態。
