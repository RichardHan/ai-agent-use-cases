# UC-311：新模型一上線，讓 Bot 跑完整批測試提示，存下作品並發布成公開展示頁

- 情境：開發
- 標籤：模型評估、批次、網站、驗收
- 網站標題：測新模型不用自己一個個貼：Bot 跑提示、存成品、做成展示頁
- 一句話用途：把一組固定的測試提示交給 Bot，對新模型逐一執行、保存每個產出的可執行示範，再發布成一個可瀏覽的展示頁，方便比較與分享。
- 分類：模型評估／批次執行
- 工具：Grok Bot／DeepSeek V4.1 Flash（受測模型）／ChatGPT Sites（作者稱用來發布展示頁）
- 證據狀態：`author-demo`（作者自述實測＋公開展示頁本庫已讀）；本庫流程與提示詞為 `designed`（自行設計未實測）
- 查證日期：2026-10-18（台灣時間）
- 獨立重現：否

## 輸入與預期輸出

- 輸入：受測模型與存取方式；一組固定測試提示（本例為 WebGL／Three.js 視覺效果題）；每題要保存的產物格式。
- 輸出：每題一個可開啟的示範頁與縮圖；一個彙整展示頁（標示題目、實作方式）；可選的失敗清單。

## 建議操作流程（本庫設計，未實跑）

1. 先固定測試集：題目、評分重點（能否執行、視覺正確、效能）、每題允許的重試次數。測試集要在看到結果前定好。
2. 讓 Bot 對受測模型逐題執行，原樣保存第一次輸出與錯誤訊息；若允許修正，另存修正版並記錄次數。
3. 每題用瀏覽器實際開啟並截圖，記錄能否執行、主控台錯誤。
4. 產生展示頁時，失敗題也要列出（標「失敗」），避免只展示成功作品。
5. 發布到公開網址前由本人確認：不含 API 金鑰、內部路徑或授權受限內容。
