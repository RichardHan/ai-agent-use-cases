# UC-337：每天早上從收藏的參考照隨機挑一張，換成自己的臉和髮型送來

- 情境：創作
- 標籤：每日、生成圖像、隨機不重複、排程
- 網站標題：每天醒來收到一張「自己在不同場景」的氛圍照
- 一句話用途：作者用Grok Bot設定每天早上的例行任務：從收藏的氛圍參考照裡隨機挑一張、避開用過的，交給ChatGPT只把臉和髮型改成作者本人，再把成品和原圖連結送到對話。
- 核心目標：把「找參考照→寫提示詞→生成→回傳」這串小事變成每天自動送達的驚喜，同時不重複、能追回原圖。
- 分類：個人收藏的隨機不重複抽選＋生成編修＋每日送達
- 工具：Grok Bot（例行任務）／ChatGPT（圖像編修）／參考照來源（作者文字寫Google Drive；設定截圖寫「ボード」與「ピン」，見下方）

- 目標使用者：有自己的照片收藏、想每天收到一張個人化生成圖的人

## 為什麼這個用法值得看

這是「非效率型」的每日例行任務，但結構很實用：隨機抽選＋已用紀錄避免重複、成品附原圖連結可追溯、登入失效時只通知而不索取密碼。同樣的骨架可用在每日一張收藏插畫、每日一首歌或每日一則筆記回顧。

## 建議操作流程（本庫設計，未實測）

1. 先確定參考照來源只包含你有權使用的圖片（自己拍的、已授權的）；把來源範圍限定在單一資料夾或收藏。
2. 讓代理維護一份「已使用清單」（檔名或連結），每次抽選前先排除；清單用完時通知而不是重複。
3. 生成前寫清楚可改與不可改：只改臉和髮型、保留構圖；被遮住的部分不要補畫成露臉。
4. 每次送達都附原圖連結與日期，方便事後追查；登入失效時只通知，不在對話裡輸入密碼。
5. 先手動跑一次確認成品與隱私，再開每日排程。

## 可貼指令（本庫原創、未測）

請每天早上［時間］從［我自己的相簿資料夾名稱］隨機挑一張照片，先排除「已使用清單」中的項目；挑完把它加入清單。用我提供的本人參考照，只調整臉和髮型，保留原圖構圖、服裝與背景，被遮住的部位維持遮住。送給我：抽到的檔名或連結、一句說明、成品。清單用完、找不到來源或登入失效時，只通知我原因並停止；不要向我索取密碼，不要公開或分享任何圖片，不要使用資料夾以外的圖片。

## 所需連接、權限與限制

- 參考照若是他人的照片，把自己的臉換進去可能涉及肖像權、著作權或平台條款；本庫建議只用自有或已授權素材。生成的本人圖像也不宜公開冒用他人場景。
- 需要讀取照片來源、使用圖像生成服務；作者如何讓Grok Bot呼叫ChatGPT（瀏覽器登入或其他方式）未說明。共用雲端電腦上的登入狀態可能被其他Bot共用。
