# UC-342：每天早上 6:30 自動替兩個孩子各印一張著色頁

- 情境：生活
- 標籤：家庭、每日、列印、生成圖像
- 網站標題：孩子起床前，印表機已經吐出今天的著色頁：讓 Bot 每天挑主題、各印一張
- 一句話用途：作者設定Grok Bot每天早上產生著色頁，並在6:30透過已連接的家用印表機印出兩個版本、兩個孩子各一張；主題由Bot挑，起床才知道。作者附一張孩子已上色的成品照片，本庫未重現。
- 核心目標：把「每天準備一份小驚喜給孩子」交給排程：生成線稿、分人版本、準時送到實體印表機，家長只需要補紙與檢查內容。
- 工具：Grok Bot（routine）／家用印表機（連接方式作者未說明）
- 分類／標籤：家庭活動／每日排程列印
- 目標使用者：家有幼兒、想每天早上準備一張不重複著色頁，又不想每天自己找圖列印的家長
- 首次收錄／最近查證：2026-10-19（台灣時間）
- 證據狀態：`author-demo`，作者貼文自述＋一張已上色著色頁的實拍照片；未見設定畫面、列印紀錄或連續多日成果。下方流程與提示詞為 `designed`。
- 是否獨立重現：否

## 輸入與預期輸出

- 輸入：孩子人數與大致年齡（作者為兩個孩子）、列印時間（作者為早上6:30）、已連上Bot電腦或網路的印表機。
- 輸出：每天兩張不同版本的黑白線稿著色頁，在孩子起床前已印好放在印表機上。

## 建議操作流程

本庫設計，未實跑：

1. 先手動做一次：請Bot依兩個孩子的年齡各產生一張線稿，看線條粗細、留白與主題是否適合，再確認能從Bot使用的環境送到你的印表機。
2. 寫清楚版本規則（例如大的孩子細節多一些、小的孩子大塊面），以及禁用主題（恐怖、品牌角色、真人肖像）。
3. 手動成功兩三次後才排成每天固定時間的routine；列印時間留些緩衝，避免生成慢而錯過起床時間。
4. 每次執行記一行：日期、主題、兩個版本是否都送出列印、失敗原因；連續兩天失敗就停下通知本人，不反覆重送。
5. 每週看一次紀錄，確認主題沒有一直重複、紙張與墨水夠用。

## 所需連接、權限與限制

- 需要Bot可以把檔案送到你的印表機；連接方式依你的環境而定，作者未公開。讓代理控制家中裝置前，先確認它只能列印、不能改印表機設定。
- 生成圖像可能出現不適合幼兒的細節，或與受版權保護的角色相似；建議先由家長看過幾天再完全放手。
- 每天執行會消耗用量額度；紙張墨水是實體成本。
- 不提供孩子姓名、照片或學校資訊給代理；本案不需要這些資料。
