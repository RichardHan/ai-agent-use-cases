# UC-354：每天早上從 X 書籤挑一個點子，讓代理做成可互動的網頁 demo、用瀏覽器實測後上線

- 本次增補查證：2026-10-20 22:30（台灣時間）；只核新增來源，未重驗全案。
- 情境：創作
- 標籤：每日、書籤、互動網頁、部署
- 網站標題：收藏一堆數學、物理貼文卻沒空細看？讓 Bot 每天挑一則，做成能玩的網頁小實驗並公開
- 一句話用途：英文作者 @jxwalker 的例行流程：每天早上代理讀他的 X 書籤、挑一個點子，做成可以操作的網頁 demo，在真的瀏覽器裡檢查過，再部署到 Cloudflare，並在 X 發一則附原作者致謝與來源的介紹。作品集網站列出 2026-09-28 到 10-19 共 21 個 demo；本庫未重現，也未核對每一則是否全自動完成。
- 核心目標：把「書籤收了就忘」變成每天一個看得到、點得開的小作品，順便替原貼文作者標出處。
- 工具：Grok Bot（作者 10-18、10-19 兩則寫明「All the work is by Grok Bot」）／較早的貼文寫「an AI agent」讀書籤，實作交給 Cursor 雲端代理（10-11、10-12、10-14、10-15、10-17）或 Claude Code（10-13）／Cloudflare（託管，回應標頭為 cloudflare）／X 書籤
- 分類／標籤：每日創作／書籤轉作品／互動教學網頁
- 目標使用者：常在 X 收藏數學、物理、機器學習等解說貼文，想把它們變成可操作的小作品或教材的人
- 首次收錄／最近查證：2026-10-19（台灣時間）
- 證據狀態：`author-demo`（作者自述實測）：多日貼文＋公開可開啟的 demo 網站（本庫只開啟首頁與一頁、未逐一操作）；「每天早上自動」「在瀏覽器實測」為作者描述，未見執行紀錄。
- 是否獨立重現：否

## 輸入與預期輸出

- 輸入：作者自己的 X 書籤（被選中的貼文，例如 @mathemetica 的「Four equations」、費曼物理講義第三卷第一章）。
- 輸出：一個部署在作者網域下的互動網頁（例如 10-19 的雙縫電子「量子漣漪槽」：可發射電子、量測讓波塌縮、切換穿隧牆、調能量看條紋寬窄）；作品集首頁自動加上一張卡片與日期；X 上一則「Today's Interesting X demo」介紹＋一則「How it's made」回覆列出來源與致謝。

## 建議操作流程

本庫依來源整理，未實跑：

1. 先把「可以做成 demo」的書籤標出來（例如加一個關鍵字或另存清單），不要讓代理從全部書籤自由挑。
2. 例行任務每天固定時間：挑一則 → 寫一句「這個 demo 要讓人看懂什麼」→ 做成單頁網頁 → 用瀏覽器開啟、點過主要按鈕、截圖 → 部署到你自己的靜態網站。
3. 介紹貼文一定附原貼文連結與作者，寫明是「受某貼文啟發」，不要轉貼原文全文或圖。
4. 前一兩週發布前先讓你看截圖再上線；穩定後才考慮直接發布。

## 所需連接、權限與限制

- 讀書籤需要 X 帳號授權；發文、部署都是對外公開動作，建議先保留人工確認。
- 部署需要網站託管帳號的權限，金鑰用密鑰機制存放；不要讓代理開新的付費服務。
- 引用他人貼文要附出處；涉及他人圖片、程式或課本內容時注意授權。
- 每天建置與瀏覽器測試會耗用量；可改成每週數次。
