# UC-355：設一個只負責督促你在 X 發原創內容的教練 Bot，每天盤點、給明天的具體功課，兩週後看數據

- 情境：創作
- 標籤：每日、社群、教練、發文
- 網站標題：在 X 上只會按轉發？讓 Bot 當教練，每天數你寫了幾則自己的內容、指出哪種互動最有效，再交代明天要做什麼
- 一句話用途：英文作者 @aurelcorp 建了一個「唯一工作是在 X 上教練他」的 Grok Bot：第一天盤點他最近 20 則貼文（20 則都是轉發），之後每天回報前 24 小時原創、引用、回覆與單純轉發各幾則，指出哪一類帶來最多瀏覽，給隔天的具體行動與一則草稿。作者承諾照做 30 天，兩週後公開 X 分析截圖；本庫未重現。
- 核心目標：把「想經營個人帳號卻只會轉發」變成每天有量化回饋與明確下一步的習慣，並誠實記錄做不到的日子。
- 工具：Grok Bot（專責教練 Bot；讀取 X 的方式作者未說明）／X 內建分析
- 分類／標籤：社群經營／每日檢討／行為教練
- 目標使用者：想在 X 建立個人品牌、但平常只轉發或很少發文的上班族與創作者
- 首次收錄／最近查證：2026-10-19（台灣時間）
- 證據狀態：`author-demo`（作者自述實測）：三則貼文＋Bot 第二天檢討訊息截圖＋兩週 X 分析截圖；Bot 如何排程、讀取哪些資料未見。
- 是否獨立重現：否

## 輸入與預期輸出

- 輸入：作者自己的 X 帳號近期貼文、引用、回覆與轉發，以及各則的瀏覽與互動數（Bot 訊息中引用了具體數字）。
- 輸出：每天一則「Daily check-in」：前 24 小時各類內容數量與前一天比較、哪一類效果最好的觀察、隔天的具體功課（例如在指定帳號發文後一小時內留兩則有內容的回覆，再寫自己的貼文），以及一則可直接修改使用的草稿。

  - [30 天承諾＋第二天檢討截圖](https://x.com/aurelcorp/status/2108918374118080998)（2026-10-10 13:51 UTC，台灣時間 21:51）。
  - [兩週結果](https://x.com/aurelcorp/status/2112090254945788384)（2026-10-19 07:55 UTC，台灣時間 15:55）。
- 原文語言：英文。
- 取得內容：以 X API 讀到三則全文並看過兩張附圖。
  - 第二天截圖（Bot 訊息，改寫）：過去 24 小時寫了 9 則自己的內容（4 則貼文、3 則引用、2 則回覆），另有 8 則單純轉發；前一天盤點是 20 則全轉發。數字顯示效果最好的是和大帳號互動：一則引用約 121 次瀏覽、3 個讚並獲得回覆，一則回覆約 58 次瀏覽；自己的貼文每則約 1–13 次瀏覽，以約 247 位追蹤者來說屬正常，代表「回覆是別人找到你的方式」。隔天功課：在三個指定帳號發文後一小時內留兩則有想法的回覆，再寫自己的東西；並附一則延續前一天主題的草稿。
  - 兩週結果（作者文字＋X 分析截圖，2W 區間）：之前每天約 0 次曝光、100% 轉發；兩週約 3.6K 曝光、47 次互動、25 個讚、互動率 1.2%；追蹤者 249 → 263。截圖的每日曝光在 10-09 至 10-16 間有數百次，10-17 之後明顯下降。
- 作者報告結果：數字有上升；也坦言「每天發文很難，白天工作會吃掉所有時間」，第二週的每日功課已經落後，但不打算放棄。
- 失敗點／缺口：Bot 是怎麼讀到他的貼文與數據（X 連接、公開讀取或作者貼給它）沒說明；「Daily check-in」是否為定時例行任務未明說；成長不能全歸功於 Bot（作者同時也更常發文與回覆），且第二週已出現執行下滑。

## 建議操作流程

本庫依來源整理，未實跑：

1. 先請 Bot 做一次盤點：最近 20–30 則裡原創、引用、回覆、轉發各幾則，各自的瀏覽與互動。
2. 和 Bot 約定一個簡單目標（例如每天至少 2 則原創或有內容的回覆），以及每天回報的時間。
3. 每天的回報只要三段：昨天的數字、哪一則效果最好與可能原因、明天一到兩件具體功課＋一則草稿。
4. 發文永遠由你自己按；Bot 只給草稿與提醒。
5. 每兩週用 X 分析頁對照一次，記下沒做到的日子，調整目標而不是硬撐。

## 可複製提示詞

本庫原創設計，非作者原文：

> 你是我的 X 發文教練，只做這件事。每天晚上 9:00（台北時間）看我過去 24 小時在 X 的公開活動：原創貼文、引用、回覆、單純轉發各幾則，各自的瀏覽與互動數；和前一天比較。用三段回報：①數字；②哪一則效果最好、你認為的原因（說明是推測）；③明天一到兩件具體可做的功課，外加一則我可以自己修改的草稿。不要替我發文、按讚、轉發、追蹤或傳私訊；草稿不要捏造經歷或數字。讀不到資料時就說讀不到，不要估。

## 所需連接、權限與限制

- 只需要讀取自己帳號的公開活動與數據；不要給 Bot 發文或互動權限，避免帳號出現自動化行為。
- 教練建議（例如去大帳號底下回覆）要自己判斷，避免變成灌水或騷擾式回覆。
- X 分析數字會隨演算法與時段變動，兩週資料只能看趨勢，不能證明因果。

## 驗收與可重現性

- 連續 7 天每天都有回報，數字可以和 X 分析頁對上。
- Bot 從未自行發文或互動。
- 兩週後有前後對照，也記下沒做到的日子。
- 本庫未重現；只有作者三則貼文與兩張截圖。
