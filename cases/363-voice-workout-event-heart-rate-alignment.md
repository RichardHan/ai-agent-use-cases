# UC-363：語音組別事件與心率時間序列對齊

- 網站標題：說出開始與結束，把運動組別對齊心率圖
- 一句話用途：保留語音事件時間與量測來源，將組別紀錄和心率對齊，同時檢查漏記與計時未送達。
- 情境：生活
- 分類／標籤：運動紀錄／時間序列對帳
- 標籤：語音、時間戳、心率、資料對齊、失敗驗收
- 工具：ChatGPT dots／作者自建Polar連接／Notion／HTML報告
- 證據狀態：B，作者實作自述及圖表解說；未取得原始資料、未獨立重現
- 查證日期：2026-10-20（Asia/Taipei）

## 問題、作者實作與結果

UZUMAKI工藤以通話記下運動組別開始、結束、重量與次數，事後取Polar心率，按時間對齊並產出Notion紀錄及HTML圖表。作者具體說明一組開始於21:04:56，圖中對應91bpm；本庫未核原始樣本或時鐘精度。這是紀錄整合，不是運動處方或醫療效果證據。

反例同樣重要：休息計時有時沒啟動，倒數有時未送達，運動中回話過多。作者提出改用確定性程式控制計時，但明說仍是構想，不能當已修復。[原文](https://note.com/uzumaki_inc/n/n8ba75a8cdd85)

## 參考步驟（本庫自行設計，未測）

1. 先用合成的組別事件與心率CSV；保留事件時間、接收時間、時區、來源、修正紀錄。
2. 對齊前核對時區與時間格式；不知道設備誤差時，標記對齊精度未確認。
3. 將缺開始、缺結束、重複事件及取樣缺口另列，不補造觀測值。
4. 將「說要計時」「計時器已啟動」「提醒已送達」分開驗收。
5. 產出一頁合成圖表及差異清單，人工確認後才討論任何真實資料連接。
