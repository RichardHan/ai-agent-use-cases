# UC-368：雲端代理量產 3D 場景素材，本機代理匯入遊戲引擎並驗證

- 情境：創作
- 標籤：遊戲素材、3D、跨代理、驗收
- 網站標題：想用 AI 蓋遊戲世界？讓 dots 在雲端做建築與街區模型，再交本機代理放進 Unreal Engine
- 一句話用途：日本作者自述用手機指示 ChatGPT dots 在 Linux 雲端環境先做建築內裝、再擴到街區的 3D 模型，交給 Claude 重現檢查並在桌機上實作進 Unreal Engine；另一位作者讓 dots 做 3,000 個低多邊形街景物件，卡在配置規格太自由。
- 核心目標：把「量產素材」與「在引擎裡實作」拆給不同代理：雲端代理負責大量產出，本機代理負責在有引擎的電腦上匯入與確認，人只看預覽與成品。
- 工具：ChatGPT dots（雲端 Linux 環境）／Claude（作者桌機）／Unreal Engine；來源B 僅 dots
- 分類／標籤：創作／遊戲開發／素材管線／跨代理交接
- 目標使用者：獨立遊戲開發者、想快速做場景原型的 3D 創作者
- 首次收錄／最近查證：2026-10-20／2026-10-20（台灣時間）
- 證據狀態：`author-demo`（兩位作者自述實測；來源A 兩則貼文各附影片，本庫只看影片縮圖未播放；來源B 一則貼文＋一張成品圖）；本庫提示詞為 `designed`

## 建議操作流程

以下為本庫設計，未實測；不是作者原文步驟。

1. 先定規格再量產：格線大小、物件尺寸範圍、原點位置、命名規則、檔案格式、多邊形上限（來源B 的教訓）。
2. 雲端代理每批只做一類物件（例如內裝家具），交付「模型檔＋規格對照表＋預覽圖」，預覽圖標明「非實際遊玩畫面」。
3. 本機代理匯入前先檢查：檔案能開、尺寸符合規格、命名不衝突；不符就退回，不在引擎裡手動修補。
4. 匯入後由人在引擎裡走一遍，記錄比例錯誤、穿模、缺貼圖；把觀察回寫成下一批的規格。
5. 素材授權與來源：只用代理自己生成或你有權使用的素材，記錄生成工具與日期。
