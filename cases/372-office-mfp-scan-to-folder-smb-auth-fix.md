# UC-372：新事務機「掃描到資料夾」一直認證失敗，讓 Bot 同時查電腦與事務機設定找出 SMB 問題

- 情境：開發
- 標籤：裝置、故障診斷、檔案分享、驗收
- 網站標題：辦公室新印表機掃描老是失敗？讓 Bot 從錯誤訊息一路查到電腦的檔案分享設定，最後實際掃一張驗證
- 一句話用途：英文作者 @RoseSte75977276 自述：辦公室新來的 Ricoh 多功能事務機列印不穩、「掃描到資料夾」一直顯示「Destination authentication has failed」，她沒等 IT，交給 Grok Bot 在自己的 Mac 與事務機兩端處理：建立 SMB 共用資料夾、判斷是登入失敗而非網路斷線、開啟 Mac 帳號的 Windows 檔案共享（SMB-NT）雜湊、確認帳密可寫入、設定通訊錄路徑，最後實際掃描一頁成功。本庫未重現。
- 核心目標：把「錯誤訊息 → 判斷是哪一層出錯 → 改設定 → 實際掃一頁驗證」的裝置排障交給 Bot，而不是只給一份檢查清單。
- 工具：Grok Bot／macOS 檔案共享（SMB）／Ricoh 多功能事務機
- 分類／標籤：開發／裝置設定／故障診斷／實體驗收
- 目標使用者：辦公室沒有即時 IT 支援、要自己把新事務機的列印與掃描接上電腦的人
- 首次收錄／最近查證：2026-10-20（台灣時間）
- 證據狀態：`author-demo`（作者自述實測）：X 單則文字，附圖是宣傳風格示意圖（「Grok Bot fixed print + scan」），**不是**設定畫面或 Bot 對話截圖；官方本機執行與核准說明另列 `official`；本庫提示詞為 `designed`。
- 是否獨立重現：否

## 輸入與預期輸出

- 輸入：事務機顯示的錯誤訊息（Destination authentication has failed）、使用者自己的 Mac、事務機的掃描目的地（通訊錄）設定。
- 作者自述的輸出：Mac 上的 SMB 共用資料夾 `ScanInbox` 連到桌面的掃描資料夾；事務機通訊錄填入 `\\IP\ScanInbox` 與帳號；掃一頁後檔案出現在桌面掃描資料夾；列印也恢復正常。
- 原文第 5 步在「with user」後就結束，帳號欄位怎麼填、Bot 如何連到事務機（網頁管理介面、面板或其他方式）作者沒有說明，本庫不推測。

## 來源版本

### 來源A：@RoseSte75977276（X，英文）

- 原始網址：[原帖](https://x.com/RoseSte75977276/status/2112369179542389053)（2026-10-20 02:23 UTC，台灣時間 10:23）。
- 原文語言：英文。
- 取得內容（翻譯改寫，非逐字）：
  1. 設好 SMB 共用資料夾 `ScanInbox`，並連到桌面的掃描資料夾。
  2. 追出 Ricoh 的錯誤是 SMB 登入失敗，不是網路斷了。
  3. 開啟 Mac 帳號的「Windows 檔案共享」（SMB-NT）雜湊——作者稱這是 Mac 配 Ricoh 常見的坑。
  4. 驗證 Mac 的帳號密碼真的能寫入這個共用資料夾。
  5. 把事務機通訊錄的路徑設成 `\\IP\ScanInbox` 並填入帳號。
- 作者報告結果：掃了一頁，成功，檔案落在桌面掃描資料夾；列印也正常。作者強調 Bot 不是貼一份清單，而是「在我的 Mac 和事務機兩端動手」。
- 失敗點／缺口：沒有設定畫面、沒有 Bot 對話紀錄；列印不穩的原因與修法沒有說明；「在 Mac 上動手」是否使用 Grok Bot 的本機執行功能未說明；附圖為示意圖。

## 建議操作流程

本庫依來源整理並加上安全關卡，未實跑：

1. 先只讀：請 Bot 收集錯誤訊息原文、事務機型號、電腦作業系統版本、事務機與電腦是否在同一網段，列出「網路不通／名稱解析／認證／共用權限／路徑格式」各層的檢查方式與目前證據。
2. 每改一項設定前，Bot 先說明要改什麼、改在哪台機器、怎麼還原，由你核准。開啟檔案分享或密碼雜湊這類會改變電腦安全面的設定，優先用專用的掃描帳號，不用你的主帳號。
3. 用最小範圍的共用資料夾（只給掃描用帳號寫入權）。
4. 驗收：實際從事務機掃一頁，到資料夾讀回檔名與時間；再測一次列印。
5. 收尾：列出所有改過的設定與還原方式，存成一頁維護紀錄交給 IT。

## 所需連接、權限與限制

- 需要能操作你的電腦（本機執行）以及事務機的設定介面；Grok Bot [官方核准與安全說明](https://docs.x.ai/grok-bot/approvals-security-and-privacy)指出本機電腦執行是獨立能力、預設「每次詢問」，並建議沒有特定理由時設為不允許；改權限屬於應先設邊界、經核准的動作。
- 開啟 SMB 共用與相容雜湊會擴大電腦的攻擊面；在公司網路上操作前，應確認公司 IT 政策是否允許，作者的「不等 IT」做法不一定適用於你的組織。
- 密碼請在接管畫面自行輸入，不要在聊天中貼出（同上官方說明）。
- 作者只說明了一台 Ricoh 與一台 Mac 的情況；其他品牌、Windows 電腦或有網域帳號的環境不能直接照搬。
