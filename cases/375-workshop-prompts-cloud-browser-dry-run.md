# UC-375：準備企業工作坊時，讓 Bot 在自己的雲端瀏覽器以學員身分把每條指令跑一遍

- 情境：工作
- 標籤：教材、測試、雲端電腦、驗收
- 網站標題：講師備課：讓 Bot 像學員一樣在網頁版工具裡實際跑過每一條練習指令，你的電腦照常能用
- 一句話用途：繁體中文作者 @freeshiuan 自述：接到一場只能用「網頁版 Copilot」的企業工作坊，以往會用 Codex 的 Computer Use 在自己電腦上測試，但測試期間電腦無法使用。這次改讓 Grok Bot 在它自己的雲端電腦裡開網頁版 Copilot，像真實學員一樣把寫好的指令與產出完整跑過一遍；作者說用最低方案、耗用不到 10% 額度。本庫未重現。
- 核心目標：在不佔用自己電腦的前提下，先替學員走過一次練習流程，找出指令在指定環境中跑不通的地方。
- 工具：Grok Bot（雲端電腦瀏覽器）／Microsoft 365 Copilot 網頁版
- 分類／標籤：工作／教育訓練／教材驗證／雲端電腦
- 目標使用者：要為客戶或公司內部開 AI 工具課、需要事先驗證每條練習指令的講師
- 首次收錄／最近查證：2026-10-20（台灣時間）
- 證據狀態：`author-demo`（作者自述實測）：X 串文附一張 Bot「電腦」分頁截圖，畫面為雲端瀏覽器開著 m365.cloud.microsoft 的 Copilot 對話頁；官方雲端電腦說明另列 `official`；本庫提示詞為 `designed`。
- 是否獨立重現：否

## 輸入與預期輸出

- 輸入：工作坊預先寫好的練習指令與預期產出；客戶指定的環境限制（只能用網頁版 Copilot）。
- 作者自述的輸出：所有寫好的指令與產出都在雲端瀏覽器裡測試過；作者未公開測試報告的格式、發現了哪些問題或改了哪些指令。

## 建議操作流程

本庫設計，未實跑：

1. 準備一個專門給練習用的測試帳號（不要用含客戶真實資料的帳號），並在接管畫面自己登入。
2. 把練習指令整理成編號清單，每題寫明「學員輸入」「預期看到什麼」「通過條件」。
3. 請 Bot 逐題在網頁版工具中操作，記錄實際輸出摘要、是否符合預期、耗時、遇到的錯誤或介面差異，必要時截圖。
4. 不通過的題目只回報、不自行改寫；由你決定怎麼改，再請 Bot 只重跑那幾題。
5. 開課前一兩天再跑一次（網頁版介面與功能可能更新），結束後登出測試帳號。

## 所需連接、權限與限制

- Grok Bot [官方核准與安全說明](https://docs.x.ai/grok-bot/approvals-security-and-privacy)說明 Bot 共用一台雲端電腦，同帳號所有 Bot 共用其中的檔案與瀏覽器登入，任務結束、不再需要時應登出；登入與驗證碼應由你接管畫面自己輸入。官方說明不證明作者的測試結果。
- 雲端瀏覽器的地區、語言與網路位置可能與學員實際環境不同；企業帳號可能有條件式存取或裝置限制，測試結果不一定等於學員當天看到的畫面。
- 在雲端電腦登入公司或客戶的 Microsoft 帳號前，先確認對方的資安政策是否允許。
- 生成式工具每次輸出不同，「通過」應以是否達成練習目標判斷，而不是逐字相同。
