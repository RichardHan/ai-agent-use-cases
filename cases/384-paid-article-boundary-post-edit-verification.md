# UC-384：更新付費文章後，重新核對免費／付費界線與正文

- 情境：創作
- 標籤：付費文章、發布、讀回、失敗紀錄
- 網站標題：補文章連結後，付費區域跑掉了嗎？
- 一句話用途：Grok Bot 的日文公開營運紀錄報告更新後付費界線位移；把文章內容與讀者可見範圍分開驗收，而非只看儲存成功。
- 核心目標：避免修訂已發布文章時，免費預覽與付費正文的分界意外改動。
- 分類／標籤：創作／發布驗收
- 目標使用者：維護付費長文的創作者。
- 首次收錄／最近查證：2026-10-20（Asia/Taipei）。
- 證據狀態：unverified；AI第一人稱營運敘述，未取得帳號持有人確認或操作產物，待驗、不計入1000。
- 是否獨立重現：否。未登入、未購買、未修改任何來源文章。

## 官方支持與證據邊界

[note官方：付費界線設定與檢查](https://www.help-note.com/hc/ja/articles/360008882894)（本輪查閱）說明分界設在段落之間；作者登入時會看見全文，應用未登入或私密瀏覽視角確認購買者看到的範圍。這支持驗收方法，不證明上述故障原因。

[Grok Bot官方概覽](https://docs.x.ai/grok-bot/overview)支持雲端電腦／瀏覽器的一般能力，不表示note有官方專用整合，更不保證文章格式無損。

## 建議操作流程（本庫設計，未實測）

1. 使用本人有權編輯的測試文章，保存核准正文、標題與分界前後各一段作為基準；不要拿他人的付費內容測試。
2. 列出本次只改哪些連結或段落，先留草稿，確認目標文章、價格與可見範圍均未改動。
3. 取得對此文章發布或更新的明確授權才送出；儲存提示不算驗收。
4. 分別比較編輯內容與未登入公開預覽。只看合法免費預覽及付費入口，不繞過付費牆。若預覽與基準不同，停止其餘文章，不自行改價格或擴大公開內容。
5. 報告文章直鏈、核對時間、哪個段落位置不符及是否已恢復；需要修正公開範圍時交作者確認。保留原因未知與未核項目。

## 權限、費用與可用性限制

- 私有草稿與編輯需要文章所有者的既有登入；憑證、驗證碼和帳戶設定不寫入案例或操作紀錄。

- 作者登入視角不等於一般讀者視角。未登入只能驗免費預覽，不能聲稱驗完整付費正文；不為驗證購買或啟用服務。
