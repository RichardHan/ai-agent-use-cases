## 可重用操作設計（本庫原創、未執行）

1. 私下保留原任務識別，以匿名代號記錄最後成功時間、工作環境及一項無副作用讀取的結果。
2. 在自然接續後，逐項分開記錄「連線可達、工具清單可見、指定讀取成功、內容身份正確」。不要用shell可用代替目標工具可用。
3. 只在原授權範圍內採集正常介面提供的狀態；沒有安全讀取路徑就停止，不猜私人端點、不改權限、設定或憑證。
4. 需要其他任務作對照時先確認授權，保留原任務；對照成功不能把原任務改記成功。已有不確定執行先核結果，不重送可能有副作用的請求。
5. 恢復驗收需對同一原任務執行真正獲准的讀取；再觀察後續自然接續是否維持。分開「單次可用、復發、長期未測」，不主動製造斷線或強制重啟。
