# UC-402：讓 Bot 只用最小權限帳號連回家用伺服器，每天回報車況與居家狀態，並把建置對話整理成文件

- 情境：生活
- 標籤：每日、居家、本機執行、權限邊界
- 網站標題：家裡有一台小主機跑智慧家庭和行車紀錄？讓 Bot 只用一個權限很小的帳號連進去，每天早上報告車況，還把架設過程整理成文件
- 一句話用途：韓文作者把 Grok Bot 擴充成約10個分工 Bot，其中「家用伺服器 Bot」經 Tailscale 只用專用、最小權限的 SSH 帳號登入家中 Ubuntu 小主機；每天早上 8 點報告車輛軟體推送、電池與保養時程，另有 06:00 晨報與「沒變化就不出聲」的監看；過去 88 段建置對話則由伺服器 Bot 讀、Notion Bot 整理成文件。作者自述，本庫未重現。
- 核心目標：讓雲端 Bot 能讀到只在家裡那台機器上的資料（智慧家庭、行車紀錄），又不把整台機器的管理權交出去。
- 分類／標籤：居家自動化／遠端存取／每日報告／多 Bot 交接
- 目標使用者：已經自己架家用伺服器（Home Assistant、行車紀錄等），想讓 Bot 每天幫忙看狀態、但不想給它管理員權限的人
- 工具：Grok Bot（主 Bot 分派給行程／郵件、Notion、文件、家用伺服器、旅遊、升學等專責 Bot）；家中 Ubuntu 小主機（Ryzen 5、12GB）上的 Home Assistant、TeslaMate、Grafana、MQTT、Matter、WireGuard、Tailscale；Tesla Fleet API（唯讀）；Telegram；Notion。作者另在同一台主機跑一個「OpenClaw＋Grok」的 Telegram 助理，與 Grok Bot 是不同工具，本頁不混為一談。
- 首次收錄／最近查證：2026-10-21 11:47（台灣時間）
- 證據狀態：`author-demo`（作者自述實際在用；附圖為概念插畫，不是實際畫面）；本頁可複製提示詞為 `designed`
- 是否獨立重現：否

## 輸入與預期輸出

- 輸入：家用伺服器上既有的服務與資料（TeslaMate 行車／充電紀錄、Home Assistant 狀態）；一個給 Bot 專用、權限最小的 SSH 帳號；Tailscale 私有網路；作者過去用 Grok Build 架伺服器的 88 段對話。
- 輸出：每天 08:00 的車況報告（韓國 FSD 推送現況、電池、保養時機）；每天 06:00 經 Telegram 送出的晨報；每 5 分鐘依下一個行程地點的交通狀況提醒何時出發；票券開賣、缺貨補貨的監看，沒變化就不通知；一份由 Notion Bot 整理的伺服器建置文件。

## 建議操作流程（依作者描述整理，安全細節為本庫補充）

1. 先在家用伺服器建一個 Bot 專用帳號：不給 sudo，只開需要讀的資料或唯讀 API（本庫補充：可只允許特定指令）；以私有網路（作者用 Tailscale）連線，不把 SSH 開到公網。
2. 讓專責的「家用伺服器 Bot」只做讀取與彙整；車輛 API 用唯讀權限（作者自述 Tesla Fleet API 唯讀）。
3. 設每天固定時間的報告 routine：車況、電池、保養；先手動跑一次，確認數字與 TeslaMate／Home Assistant 畫面一致。
4. 監看類 routine 寫明「沒有變化就不通知」。
5. 把過去的建置對話交給伺服器 Bot 摘要，再交給 Notion Bot 寫成文件；對照實際設定抽查，不把對話內容直接當成現況。

## 所需連接、權限與限制

- 家用伺服器的帳號權限是最重要的邊界：Grok Bot 的雲端電腦可被同帳號下其他 Bot 共用，任何放在上面的 SSH 金鑰都應視為可被所有 Bot 使用。
- 不要把伺服器私鑰、Tailscale 金鑰或車輛 API 權杖貼進聊天；車輛控制（解鎖、開空調等）不在本案範圍。
- 居家自動化（開燈、熱水器、外出模式）屬實體設備控制，作者描述的是 Home Assistant 規則；若要讓 Bot 修改規則，另見 [UC-170](170-home-scene-automation-review.md) 的逐項驗收做法。
- 本庫未查證 Grok Bot 能否穩定透過 Tailscale 長期連線；另見 [UC-067](067-agent-app-rebuild-manual.md) 變體 A 對雲端電腦重置後 Tailscale 身分保留的做法。

## 驗收與可重現性

- 第一次報告與 TeslaMate／Home Assistant 原畫面逐項對照；故意讓伺服器離線一次，確認報告寫「讀不到」而不是沿用昨天的數字。
- 用 Bot 的專用帳號嘗試一次需要 sudo 的指令，確認會被拒絕。
- 本庫未重現。
