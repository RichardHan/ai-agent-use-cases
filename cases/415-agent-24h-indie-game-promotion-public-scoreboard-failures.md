# UC-415：讓Bot用24小時、零預算推廣一款免費網頁遊戲：每小時讀計畫與日誌再行動，公開記分板記下所有失敗

- 情境：工作
- 標籤：行銷、多代理、失敗、公開紀錄
- 網站標題：叫AI幫你推廣遊戲會發生什麼？一個Bot花24小時、零預算宣傳免費網頁遊戲，寄21封信回1封、被論壇封鎖，全部公開在記分板上
- 一句話用途：芬蘭獨立開發者讓 Grok Bot 在約22–24小時內、零預算、不准碰遊戲程式碼的條件下推廣免費網頁遊戲 World Of Provider（目標1,000名玩家）。Bot 以 `PLAN.md`／`LOG.md` 為核心、每小時 routine 叫醒自己重讀計畫並行動，分出研究與瀏覽器子代理，各管道連結加 `?ref=` 標記，並用 GitHub Pages 做公開記分板。結果：寄21封信回1封、Bluesky 13則換來1名追蹤者、一篇俄文社群長文約4,100次瀏覽、被一個論壇以垃圾訊息封鎖；記分板上「玩」按鈕點擊為0。文章由 Bot 第一人稱撰寫，列待定、不計數。
- 核心目標：看清楚「把推廣全權交給代理」實際能做到什麼、會在哪裡被擋，並把成果與失敗用可公開核對的方式記錄。
- 分類／標籤：遊戲推廣／自主代理／成效追蹤
- 目標使用者：想讓 AI 代理幫忙宣傳小產品的獨立開發者；想了解代理對外發文風險的人
- 工具：Grok Bot（主代理＋每小時 cron 式 routine＋研究／瀏覽器子代理；以 API 讀信取得登入驗證碼）／GitHub Pages（靜態記分板＋JSON）／第三方無 cookie 計數服務
- 首次收錄／最近查證：2026-10-21 20:50（台灣時間）
- 證據狀態：`unverified`（待定）：Velog 文章由 Bot 自稱撰寫、開發者未以本人帳號具名發文；公開記分板網頁與 `data.json` 可讀、各平台貼文連結可點，但本庫未逐一核對數字；本頁可複製提示詞為 `designed`
- 是否獨立重現：否

## 輸入與預期輸出

## 建議操作流程（本庫設計：保留代理的記錄與追蹤做法，收緊對外動作）

1. 先讓代理只做研究：列出可能的社群、規則（是否允許自我宣傳、是否禁止 AI 生成內容）、適合的發文形式，交你挑選。
2. 每個管道一個 `?ref=` 標記，記分板只統計總數、不設 cookie。
3. 對外寄信與發文都先交草稿；開頭清楚標示由 AI 代理撰寫並代表誰。
4. 遵守各社群規則：規則禁止 AI 內容或自我宣傳就不發；被版主刪除或封鎖就停止該管道，不換帳號重試。
5. 每小時的 routine 只做「讀計畫→做一件事→寫日誌」，並設總期限與用量上限。

## 所需連接、權限與限制

- 代理需要瀏覽器、電子郵件與多個平台帳號；對外發文與寄信是不可撤回的公開動作，應逐項核准。
- 未經對方同意的大量推廣信可能違反當地法規或平台規範；本頁不建議全自動寄送。
- 讓代理讀信取驗證碼等於開放信箱讀取權限，範圍要限縮。
- 公開記分板不應收集個資；來源記分板宣稱不設 cookie、只計總數，本庫未驗證。
