# UC-424：喜歡別人的主視覺？讓Bot讀網頁原始碼拆出用了哪些圖、每個元素在表達什麼，再用可商用的公有領域素材做自己的版本

- 情境：創作
- 標籤：設計、主視覺、授權、品牌
- 網站標題：看到很喜歡的網站橫幅，想做一張同樣感覺的？讓Bot先拆解原圖的構成與用意，再換成你能合法使用的素材重做
- 一句話用途：英文作者 Yifei Zhou（@YifeiZhou）喜歡 Claude Opus 5.5 發布頁的橫幅，和 Grok Bot 一起拆解：Bot 讀發布頁程式碼找出組成主視覺的三張原圖，兩人逐項討論每個元素想傳達什麼；作者原想用米開朗基羅、拉斐爾的畫作，Bot 提醒義大利對博物館館藏畫作的商業使用有授權要求，改用 NASA 公有領域衛星影像（河流三角洲），加底片顆粒、置中標誌，產出有／無顆粒多個版本，作者挑兩張公開。作者自述＋兩張成品圖，本庫未重現。

- 工具：Grok Bot（讀網頁程式碼、討論、影像後製：加顆粒、放標誌、出多版本）／NASA 公有領域衛星影像

## 輸入與預期輸出

- 輸入：參考網頁網址；自己品牌想傳達的概念（作者：人與代理一起工作）；標誌檔。
- 輸出：參考主視覺的構成拆解（原圖有哪些、如何裁切組合、字體與色調、每個元素的可能寓意）；候選素材與授權說明；多個版本的成品（作者版本：衛星拍攝的河流三角洲，多條水道匯流又分開，保留原色、加底片顆粒、標誌置中）。

## 來源版本

### S-424A：Yifei Zhou（@YifeiZhou，X，英文）

- 網址：https://x.com/YifeiZhou/status/2113130388705124733 ，2026-10-22 04:48 UTC（台灣時間 12:48），英文，附成品圖兩張（本庫已看：兩張都是河流三角洲衛星影像加中央標誌）。
- 作者報告（翻譯改寫）：
  1. 參考對象是 Claude Opus 5.5 發布頁的橫幅，由三張靜態照片疊成：中間是太空看地球邊緣的日出，左右是橘紅色菇褶與綠葉紋理，頁面把每張裁成弧形，合起來像一顆球；照片都柔和、有底片顆粒。
  2. 作者的解讀：用自然而非科技感（沒有藍紫光暈、粒子、電路），配暖色與襯線字，感覺平靜有人味；日出代表新的一天與新疆域；菇褶與葉脈層層重複，暗示神經網路與思考——「複雜，但是長出來的，不是造出來的」；一邊是太空、一邊是微小紋理，代表既看全局也看細節；底片顆粒讓它像印刷海報。
  3. 套用到自己的產品：產品主題是人與代理一起工作，所以選河流三角洲衛星影像——許多水流匯合再散開。
  4. 全程用 Bot：先讓它讀發布頁程式碼，找到三張原圖；再一起討論每部分的意思；作者原想用米開朗基羅與拉斐爾的畫，Bot 指出義大利對博物館畫作的商業使用要授權，於是改用 NASA 的公有領域衛星影像；最後 Bot 加顆粒、放標誌，做了有／無顆粒的幾個版本，作者挑了兩張。
- 缺口：Bot 的拆解文字、授權說明的原話與依據、使用的影像出處頁都未公開；義大利文化資產影像商用規定的細節本庫未查證，只記為作者轉述 Bot 的提醒。

## 建議操作流程（本庫設計，未實跑）

1. 給 Bot 參考網址，請它只列出主視覺由哪些素材、如何組合（裁切、疊放、字體、色調、質感），不要下載或重用原圖。
2. 請它對每個元素提出「可能想表達什麼」，標明這是推測。
3. 寫下自己品牌要傳達的一兩個概念，請 Bot 提三到五個「同樣手法、不同素材」的方向。
4. 選定素材前，請 Bot 列出每個候選的出處頁、授權條款與是否可商用、是否需標示；不確定的就排除或請本人確認。
5. 後製出多個版本（例如有／無顆粒），本人挑選；保存素材出處與授權紀錄。

## 可複製提示詞（本庫原創設計，未實跑）

> 讀這個網頁 {網址} 的主視覺（可以看原始碼），告訴我它由哪些素材組成、怎麼裁切組合、用了什麼字體風格、色調與質感。每個元素你覺得想表達什麼，請標明是推測。不要下載或重用它的任何素材。接著根據我的品牌概念「{概念}」，提三到五個用相同手法、不同素材的方向。每個方向列出候選素材的出處網址、授權類型、能否商用、是否要標示出處；不確定能否商用的就標「需確認」。我選定後，再用素材加{質感／標誌位置}做{N}個版本給我挑。

## 所需連接、權限與限制

- 參考別人的設計要避免照抄：原圖、字體、版面組合都可能受著作權或商標保護；學手法、換素材、換構圖。
- 「公有領域」與「可免費下載」不同；NASA 影像多數可用，但涉及標誌、人物、第三方內容時另有規定，請以出處頁說明為準。
- 博物館館藏或文化資產影像的商業使用，各國規定不同；本庫未核作者所述義大利規定，請自行查證或改用確定可用的素材。
- 字體授權也要確認（網頁字體不一定能用在圖片或印刷品）。

## 驗收與可重現性

- 每張成品都附素材出處與授權紀錄；隨機抽一個出處頁核對條款。
- 與參考橫幅並排看，確認沒有沿用原素材或幾乎相同的構圖。
- 本庫未重現；只有作者成品圖。
