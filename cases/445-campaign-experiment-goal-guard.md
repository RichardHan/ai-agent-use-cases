# UC-445：外聯實驗先鎖商業目標，再比較每日版本結果

- 網站標題：別讓更多回覆掩蓋真正目標，限定外聯實驗可改範圍
- 一句話用途：把已運行活動的結果接回下一輪小實驗，但不讓代理自行換客群或追錯指標。
- 情境：工作

這是已運行的實驗迴圈自述，不是本庫證實寄送或轉換。本文不複製個人聯絡資料、不推薦大量未經同意的外聯。

## 可參考的離線驗收（整理者設計，未實測）

1. 使用合成活動表，每列有活動ID、版本、分組規則、時間窗、已送達數、正面回覆與實際預約數。
2. 先把最終目標和代理可改項寫成固定表；例如目標是經確認的預約，不用總回覆代替。
3. 核對共同分母、重複對象、缺漏及不相同觀察期。不能把原始筆數差異當效果差異。
4. 只對資料足夠的版本提出假說；一次改一個被允許的欄位，列出成本、停止條件和待人工批准。
5. 讀回下一批實際結果，分開提案、批准、已執行、已觀察，不把代理建議當成上線。
6. 實際寄送、客群調整及新資料收集均須另外授權，先確認平台條款與收件合法性。
