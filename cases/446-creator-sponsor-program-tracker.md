# UC-446：讓 Bot 從公開業配貼文找出品牌合作計畫，整理成有證據的追蹤表與待批提案稿

- 情境：工作
- 標籤：創作者、贊助、追蹤表、人工核准
- 網站標題：想接第一個業配卻不知道誰在付錢？讓 Bot 從同領域的 #ad 貼文反查品牌計畫，先列證據再寫提案
- 一句話用途：英文作者 @Joshua_WD 自述用 Grok Bot 建一個「Sponsor Hunter」，掃描同領域創作者的 #ad／#sponsored／「partnered with」貼文，找出有創作者或聯盟計畫的品牌，整理成含連結、契合度分數與公開報酬的追蹤表，並草擬提案；寄送、私訊、註冊都要先經他同意。
- 核心目標：把「找贊助」從憑印象亂投，變成每個品牌都有公開證據、報酬來源與狀態欄位的名單。
- 分類／標籤：工作｜創作者經營／贊助開發／名單整理
- 目標使用者：在 X 經營特定主題（作者為 AI 程式開發）、想找第一個品牌合作的創作者。
- 首次收錄／最近查證：2026-10-24 09:00–09:20（Asia/Taipei）
- 證據狀態：author-demo（作者自述實測）。只讀到公開貼文與作者回覆中的提示詞；12 個品牌名單本身未公開，本庫未核對任何一筆。
- 是否獨立重現：否。

## 輸入與預期輸出

- 輸入：自己的主題領域、X 帳號與追蹤數、公開的 X 貼文（作者讓 Bot 掃描標註業配的貼文）。
- 輸出：追蹤表欄位為品牌、計畫連結、證據（哪則業配貼文）、契合度 1–10、公開報酬（只有官方公開且附來源才填）、狀態；另附以作者口吻寫的短提案草稿。
- 作者報告結果：設定當天幾分鐘內找到 12 個會付費買 X 貼文的品牌與媒合平台，附連結、契合度與公開報酬。

## 建議操作流程（本庫依來源整理）

1. 先寫清楚領域、受眾與自己不接的品類（例如金融投機、未經驗證的健康產品）。
2. 讓 Bot 只讀公開貼文與品牌官方頁，每一列都附「業配貼文連結」與「計畫官方連結」兩個證據。
3. 報酬欄只能填官方公開數字並附來源；沒有就寫「未公開」，不得推估。
4. 契合度分數要附一句理由，人工抽查前 3 名與後 3 名，確認不是只看關鍵字。
5. 提案稿只存草稿；寄送、私訊、填申請表都由本人逐一核准。

## 可複製提示詞（本庫改寫設計／未實測）

你是我的贊助開發助理。我的領域是［領域］，帳號 @［帳號］，追蹤數［數字］，不接［排除品類］。只用公開資料：找出最近［天數］天內同領域創作者標示 #ad、#sponsored 或「與某品牌合作」的貼文，反查有創作者或聯盟計畫的品牌。建立表格：品牌、計畫官方連結、業配貼文連結、契合度1–10與一句理由、公開報酬（只填官方公開且附來源，否則寫未公開）、狀態。再為前［N］名各寫一段草稿提案。不要私訊、寄信、留言、註冊或填任何表單；不要編造報酬或數據；找不到證據的品牌不要列入。

## 所需連接、權限與限制

- 需 Bot 能讀 X 公開貼文；官方文件說明 Grok Bot 可搜尋 X 公開內容，但本庫未核對作者使用的方案或連接方式。
- 業配標記可能漏標或誤標；「有人業配過」不代表品牌仍在招募或適合你的帳號規模。
- 任何外聯、申請聯盟計畫都屬外部動作，須人工核准，並遵守平台的業配揭露規範。

## 驗收與可重現性

- 隨機抽 3 列，點開兩個證據連結，確認業配貼文確實提到該品牌、計畫頁確實存在。
- 檢查報酬欄是否每筆都有來源；沒有來源卻有數字即退回。
- 本庫未重現；作者成果僅為自述。
