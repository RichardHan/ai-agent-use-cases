# UC-450：開發用資料庫月費太高？先查清帳單、備份並試還原，再把 Supabase Pro 降回 Free

- 情境：省錢
- 標籤：訂閱、雲端費用、備份、驗收
- 網站標題：想把雲端資料庫從付費方案降回免費？先查帳單、備份、試還原，再降級
- 一句話用途：個人開發者和 dots 一起逐日盤點 Supabase 付費組織與專案，先備份並在隔離環境試還原，再由本人把方案切回 Free；部分還原失敗與未驗項目都分開記錄。
- 核心目標：在停止每月固定費前，確認「真正付了多少、哪些專案還在用、資料能還原到什麼程度」，避免只看到畫面顯示 $0 就當作安全完成。

## 輸入與預期輸出

- 輸入：已付帳單畫面、組織與專案清單、各專案的外部連結（公開 App、Webhook 等）、資料庫連線（密碼由本人在終端機隱藏欄位輸入）。

## 建議操作流程（本庫設計，依來源A改寫，未實測）

1. 只讀盤點：列出每個組織／專案、方案、已付與預估金額（分開欄位），以及每個專案的外部依賴（公開網址、OAuth 回呼、Webhook）。
2. 決策表：哪些專案可停、可移 Free 組織、需保留付費；標明「停一個專案不等於基本費消失」。
3. 備份：角色、結構、資料分檔；記錄大小、雜湊、各表筆數。密碼由本人輸入，不交給代理保存。
4. 在隔離環境試還原，分開回報「整包」與「部分」結果；失敗就停下列原因，不改原始 SQL 硬套。
5. 由本人在主控台執行移轉、暫停或降級；代理只對照畫面確認狀態，遇錯誤最多重試一次並記錄。
6. 降級後清單：下期帳單、外部 App 實際操作測試、認證／檔案儲存是否可用、無定期備份的替代做法。
