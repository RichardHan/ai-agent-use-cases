# UC-459：用聊天讓Bot做一份自己的X成效儀表板：帳號每次變動在圖上標記，另設「觀看÷前一天追蹤者」指標

- 情境：創作
- 標籤：社群、數據儀表板、Pages、每週
- 網站標題：X內建數據看不出什麼有效？讓Bot用你的貼文與匯出檔做一份自己的儀表板，標出改簡介、付費推廣等變動，並用「觀看÷前一天追蹤者」比較早晚貼文
- 一句話用途：以德語和Bot對話的作者 @alexander_jais 讓第一個 Grok Bot「Xaver」（平時起草貼文與回覆、由本人發出）用 Grok Bot 頁面功能做出仿 X Analytics 的儀表板：回撈四月以來的貼文、把八月以來每篇依主題與格式分類，每次本人不滿意就重做；帳號變動（換簡介、付費推廣）在圖表上加標記，並新增「觀看數÷前一天追蹤者數」的公平指標。分析資料 X 外掛讀不到，所以每週五本人手動匯出兩個 CSV 交給 Bot。作者自述＋英文重製版示範影片縮圖，本庫未重現。
- 核心目標：把「哪篇有效、哪個變動帶來追蹤」從看原始觀看數，改成看有標記、經帳號規模校正的圖表。
- 分類／標籤：個人社群成效分析／官方頁面功能＋每週手動匯入
- 目標使用者：自己經營 X 帳號、想知道哪些貼文或帳號調整真正有效，又覺得內建數據不夠的人
- 工具：Grok Bot（頁面／儀表板功能；X 外掛讀貼文）／X Analytics 匯出 CSV（本人手動）
- 首次收錄／最近查證：2026-10-22 20:50（台灣時間）
- 證據狀態：`author-demo`（作者 X 貼文＋自回覆說明；附影片為英文重製版、數字已隱藏，本庫只看縮圖未看完整影片）；本頁流程與提示詞為 `designed`
- 是否獨立重現：否

## 輸入與預期輸出

- 輸入：Bot 經 X 外掛讀得到的歷史貼文（作者回撈到四月）；本人每週匯出的兩個 X Analytics CSV；帳號變動紀錄（何時改簡介、何時付費推廣）。
- 輸出：仿 X Analytics 的分頁儀表板（縮圖可見 Overview／Content／Audience 三頁、本月／上月／自訂區間、成長／互動／觸及三區塊、追蹤者成長圖標「back-calculated」）；圖上的變動標記；每篇貼文的主題／格式分類；「觀看÷前一天追蹤者」指標。

## 來源版本

### S-428A：@alexander_jais（X，英文；與 Bot 實際對話為德文）

- 網址：https://x.com/alexander_jais/status/2113203881643524176 ，2026-10-22 09:40 UTC（台灣時間 17:40），英文；同串自回覆 https://x.com/alexander_jais/status/2113204952021512250 （09:44 UTC）說明：真實對話是德文，影片是隱藏數字後的英文版本。另一則 https://x.com/alexander_jais/status/2113159434578890795 （06:44 UTC）重述「第一天就做了儀表板，只缺 X Analytics 外掛」。
- 作者報告（翻譯改寫）：告訴 Xaver 想看什麼，它回撈貼文到四月、把八月以來每篇依主題與格式分類，作者每次挑剔它就重做，最後要求長得像 X Analytics：分頁、下拉選單、只放圖表。保留兩個點子：每次帳號變動（新簡介、付費推廣）在圖上標記，看出真正推動成長的是什麼；新指標「觀看÷前一天追蹤者」，因為 500 追蹤者時 500 觀看很好、10,000 追蹤者時 1,000 觀看就不是。帳號長大十倍後，想把表現最好的舊文再發一次。
- 作者看到的結果：大多數追蹤者是在單一篇（自我介紹文）發出後三天內來的；以原始觀看數看早上貼文比下午好約兩倍，換成新指標後幾乎打平——作者說這正是做這個儀表板的理由。
- 失敗點／缺口：X 外掛讀得到貼文但讀不到分析數據，所以每週五由本人匯出兩個 CSV 餵給 Bot；作者公開請官方出 X Analytics 外掛。儀表板是否每天自動更新、CSV 欄位、分類規則、追蹤者「回推」計算方法，作者沒有公開；數字在影片中隱藏。

## 建議操作流程（本庫設計，未實跑）

1. 先決定要回答的問題（例：哪類貼文帶來追蹤？早上還是下午發比較好？），再請 Bot 列出需要的欄位與資料來源。
2. 貼文文字由 Bot 讀；外掛讀不到的數據由本人定期匯出 CSV 上傳，檔名帶匯出日期。
3. 先讓 Bot 給分類規則（主題、格式）與 10 篇抽樣，本人確認後才全部套用。
4. 建「帳號變動」清單（日期＋事件），讓圖表加標記；推廣過的貼文另外標示，不與自然觸及混算。
5. 加上校正指標（觀看÷前一天追蹤者），並同時保留原始觀看數，兩者並列。
6. 每週匯入後，Bot 只更新頁面並寫三行變化摘要；任何發文、重發舊文由本人決定。

## 可複製提示詞（本庫原創設計，未實跑）

> 幫我做一頁 X 成效儀表板。資料：你讀得到的我的貼文，以及我每週上傳的 X Analytics CSV（檔名有匯出日期）。先給我分類規則（主題、格式）和 10 篇抽樣，我確認後再全部分類。圖表要有：追蹤者成長（標記我提供的帳號變動日期，例如改簡介、付費推廣）、每篇的原始觀看數，以及「觀看÷前一天追蹤者」。推廣過的貼文要另外標示。CSV 缺欄位或日期對不上就列出來，不要自己補數字。不要發文、不要重發舊文、不要回覆任何人。

## 所需連接、權限與限制

- Bot 讀貼文靠 X 外掛；分析數據（觀看、追蹤者每日數）作者是手動匯出，外掛讀不到。
- 「前一天追蹤者」若是回推而非每日實錄，會有誤差；應標明哪些點是推算。
- 儀表板頁面若要分享，應另做隱藏敏感數字的版本（作者影片即隱藏數字）。
- 小樣本下「早上 vs 下午」的差異可能只是雜訊，不宜當成定論。

## 驗收與可重現性

- 隨機抽 5 篇，儀表板上的觀看數與 CSV 原值一致。
- 每個變動標記都對得上本人提供的日期清單。
- 校正指標的分母日期正確（是發文前一天，不是當天或今天）。
- 本庫未重現；只有作者單一串貼文與重製影片縮圖。
