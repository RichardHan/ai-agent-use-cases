## 輸入與預期輸出

- 輸入：官方 X 帳號新貼文、GitHub 新 release 與安全公告、對應的版本說明。
- 輸出：高危／緊急：備份→更新→健康檢查→回報「做了什麼」；一般：連結＋短摘要＋詢問；無新項目：不通知；已處理清單（跨兩來源去重）。

## 建議操作流程（依來源整理）

1. 先只開「讀取＋通知」：跑一兩週，確認兩來源去重正確、嚴重程度判斷合理。
2. 再把「高危自動更新」開給一台有備份的機器；先手動演練一次還原，確定備份能用。
3. 健康檢查寫成具體條件（服務頁面回應、版本號、關鍵功能），檢查不過就停下通知本人、不要再嘗試。

- 自動更新等於讓 Bot 對正式服務有寫入權；涉及金流的服務（如 BTCPay）尤其要先確認備份、還原與回復步驟。
- 「嚴重程度」依版本說明判斷，可能誤判；作者用「不明就當一般」降低誤自動更新。
