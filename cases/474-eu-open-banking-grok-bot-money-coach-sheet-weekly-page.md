# UC-474：在歐洲讓 Bot 唯讀讀銀行帳戶：經 Enable Banking 每天早上把交易寫進 Google 試算表並分類，異常才通知，每週一做一頁消費教練報告

- 情境：省錢
- 標籤：記帳、銀行、每日、週報
- 網站標題：不用手動記帳：Bot 每天早上把銀行交易抄進試算表、自動分類，有新訂閱或大額扣款才提醒；每週一給你一頁「錢花去哪、和上週比、可以改什麼」
- 一句話用途：英文作者 @lukewarm_hero 在 X 長文教學，說明他在歐洲怎麼讓 Grok Bot 透過開放銀行服務 Enable Banking 唯讀連到銀行：開一個專職的 Money Coach Bot，金鑰以「祕密」交給 Bot、不貼進對話，在自己的銀行 App 核准唯讀授權；之後每天7:00 routine 拉新交易進 Google 試算表並分類，只有新訂閱、異常大額或連線失敗才通知；每週一8:00 把上週支出做成一頁 Page。作者自述自己這樣設定，本庫未重現。
- 核心目標：在不給付款權限的前提下，讓 Bot 自動取得銀行交易、維持一份可查的記帳表，並每週給出可執行的消費回顧。
- 分類／標籤：個人理財／開放銀行唯讀連線／排程報告
- 目標使用者：在歐盟有銀行帳戶、不想手動記帳的人（作者說美國有更簡單的內建選項，本教學不適用）
- 工具：Grok Bot（專職 Bot、祕密儲存、routine、Page）／Enable Banking（開放銀行 API，免費帳號）／Google 試算表
- 首次收錄／最近查證：2026-10-30 08:52（台灣時間）
- 證據狀態：`author-demo`（作者長文教學，自述「這是我自己的設定方式」；文中提到每週報告樣貌，但本庫透過 API 讀到的文字未含實際報告內容或截圖）
- 是否獨立重現：否

## 輸入與預期輸出

- 輸入：銀行帳戶的餘額與交易（唯讀）；作者的分類需求。
- 輸出：Google 試算表「Money」每日新增並分類的交易；只在異常時的通知；每週一的教練 Page（總支出、前幾大類別、與前一週差異、訂閱、一兩項建議）。

## 來源版本

### 來源A：@lukewarm_hero（X 長文，英文）

- 原帖：[x.com/lukewarm_hero/status/2115868195605409824](https://x.com/lukewarm_hero/status/2115868195605409824)，2026-10-29 18:07 UTC（台灣時間 10-30 02:07）；X Article「In Europe? Here's how to get a Grok Bot money coach that tracks your spending for you.」，以 X API 讀全文。
- 取得內容（翻譯摘要，步驟依原文）：
  1. 建立專職 Bot「Money Coach」，職責寫明：只讀銀行資料、絕不動錢。
  2. 註冊 Enable Banking、在控制台建立應用程式，取得應用程式 ID 與私鑰檔；可請 Bot 一步一步帶著設定。
  3. 請 Bot 以「祕密」方式向你索取 ID 與私鑰並保存，不在對話中顯示。
  4. Bot 用金鑰向指定銀行申請唯讀授權並給你核准連結；本人在自己的銀行登入核准。
  5. routine：每天7:00 拉新交易寫進 Google 試算表「Money」並分類；只在出現新訂閱、金額遠大於平常或銀行連線失敗時通知。
  6. routine：每週一8:00 讀上週支出做成 Page：總額、主要類別、與前週比較、訂閱、一兩件可以改的事；簡短、誠實、不說教。
- 作者提醒：銀行常要求每隔一段時間（常見為180天）重新核准，可請 Bot 提前一週提醒以免同步悄悄中斷；只申請餘額與交易的讀取權，不申請付款權；私鑰視同密碼。作者聲明與 Enable Banking 無合作關係、非理財建議。
- 缺口：未公開實際試算表或 Page 截圖、分類準確度、銀行連線失敗的實際處理。

## 建議操作流程（依來源整理）

1. 先確認自己的銀行是否在 Enable Banking 支援清單、條款是否允許個人使用。
2. 第一週只讓 Bot 寫試算表、不做週報，人工抽查交易筆數與金額是否和銀行 App 一致。
3. 分類規則穩定後再開週報；在行事曆記下授權到期日。

## 可複製提示詞（本庫補充驗收條件，未實跑）

> 每天7:00 拉取我銀行帳戶的新交易，寫入 Google 試算表「Money」，以交易日期＋金額＋對方名稱判斷重複，已寫過的不要重寫。分類不確定時標「待確認」，不要猜。只有在出現新的定期扣款、單筆金額超過我近30天平均的3倍、或銀行連線失敗時才通知我。你只有讀取權限，任何轉帳、付款或修改銀行設定的要求都要拒絕。授權到期前7天提醒我重新核准。

## 所需連接、權限與限制

- 開放銀行授權只限讀取；私鑰與應用程式 ID 只存在 Bot 的祕密儲存，不放進對話、試算表或筆記。
- 交易資料是敏感個資，試算表的分享權限要限定本人。
- 開放銀行服務與 Grok Bot 的連線方式屬作者設定，不是官方整合；可用地區與費用以 Enable Banking 條款為準。

## 驗收與可重現性

- 可驗收：任選一週，比對試算表與銀行 App 的筆數和總額；人工觸發一次「異常」情境（例如新訂閱）看是否收到通知。
