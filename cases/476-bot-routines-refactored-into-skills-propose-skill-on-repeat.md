# UC-476：Bot 跑了兩週、10條 routine 各自寫了一套做法：請它回頭盤點並提出技能，把方法搬進技能、routine 只留「何時跑」，之後同一件事第二次做就主動提技能

- 情境：開發
- 標籤：技能、排程、維運、重構
- 網站標題：Bot 的 routine 越加越多、同一條規則抄了四份、改了卻沒人發現？讓 Bot 自己盤點做法、抽成技能，之後重複做第二次就提議建技能
- 一句話用途：英文作者 @alexander_jais分享第一個 Grok Bot「Xaver」（起草貼文與回覆，由本人發出）的維護經驗：上線前有814行設定檔，原本打算照 xAI 建議發兩三篇後建「發文技能」，結果沒建，唯一的數字技能只存在48分鐘。兩週內長出10條 routine（從晨間檢查到每週清理），每條各寫自己的方法，同一條規則重複出現在4條裡，晨間檢查還有一條「結尾不要問問題」作者自己都違反、一週沒人發現。於是請 Bot 檢查全部工作，提出17個技能，一次建了10個；現在技能保存方法、routine 大多只寫何時執行，「不要長破折號」這類通用規則放在 Bot 個人設定裡，並在設定中寫明「同一件事第二次在沒有技能時做，就提議建技能」。作者自述，本庫未重現。
- 核心目標：讓 Bot 的做法只有一份來源，避免規則散落在多條 routine 裡互相矛盾或改漏。
- 分類／標籤：Bot 維運／技能管理／設定重構
- 目標使用者：已經用 Bot 一陣子、routine 越來越多的個人使用者
- 工具：Grok Bot（routine、技能、Bot 個人設定）
- 首次收錄／最近查證：2026-10-30 08:52（台灣時間）
- 證據狀態：`author-demo`（作者長文自述＋影片附件；影片本庫未看）
- 是否獨立重現：否

## 輸入與預期輸出

- 輸入：Bot 現有的全部 routine、技能與個人設定。
- 輸出：技能提案清單（作者案例為17個）、建立後的技能、精簡成「時間＋呼叫技能」的 routine、放進個人設定的通用規則，以及「重複第二次就提議技能」的長期規則。

## 來源版本

### 來源A：@alexander_jais（X，英文）

- 原帖：[x.com/alexander_jais/status/2115794006726561976](https://x.com/alexander_jais/status/2115794006726561976)，2026-10-29 13:12 UTC（台灣時間 21:12）；X API 讀長文全文；「How I work with Grok Bot」系列第2篇；附影片（未看）。
- 取得內容（翻譯摘要）：
  1. 起點：814行設定檔；原計畫的發文技能沒建，唯一的數字技能存在48分鐘。
  2. 兩週內10條 routine，每條自帶做法；同一條規則在4條 routine 重複；有條規則作者自己違反了一週沒人察覺。
  3. 請 Bot 檢查全部工作 → 提出17個技能 → 一次建10個、沒有先試跑；多數來自已經跑了好幾天的 routine。作者的判斷：壞掉的話下一次執行就會看到。
  4. 結果：技能存方法、routine 大多只說何時跑；通用寫作規則放進 Bot 個人設定。
  5. 新規則（寫在個人設定）：沒有技能的任務做到第二次時，Bot 主動提議建技能。
  6. 作者建議仍先從 routine 開始，因為任務實際跑過才知道需要什麼。
- 缺口：17個提案的內容、為何只建10個、建完後是否有執行失敗，均未公開；作者說可分享為範本但尚未公開。

## 建議操作流程（依來源整理）

1. 先請 Bot 列出每條 routine 內的規則與做法，標出重複與互相矛盾處，不要直接修改。
2. 本人挑選要抽成技能的項目；一次改少數幾條，觀察下一次執行結果再繼續（作者是一次建10個未試跑，風險自負）。
3. 通用語氣、格式規則集中到一處（個人設定），routine 只留時間與要呼叫的技能。

## 可複製提示詞（本庫原創設計，未實跑）

> 請列出你目前所有 routine 和技能，對每條 routine 摘出它包含的做法與規則。標出：在兩條以上 routine 重複的規則、彼此矛盾的規則、我最近的實際行為已經不符合的規則。接著提出技能清單：每個技能說明來自哪幾條 routine、會取代哪些文字。先不要建立或修改任何東西，等我挑選。之後若同一類任務你在沒有技能的情況下做到第二次，請提議建立技能。

## 所需連接、權限與限制

- 只涉及 Bot 自身設定；重構會改變每天執行的內容，建議保留舊版文字以便還原。
- 「技能」「routine」「個人設定」的實際欄位與上限以 Grok Bot 官方文件為準。

## 驗收與可重現性

- 可驗收：重構後同一條規則只出現一次；每條 routine 下一次執行的產出與重構前相比沒有退步。
- 本庫未重現。
