# UC-479：個人遊戲開發者在 ChatGPT 投廣告：用 Ads Manager 外掛以對話完成設定與 UTM、算損益兩平點擊價，審核被拒時交 dots 讀信回客服，最後靠「同活動另建廣告」過審

- 情境：工作
- 標籤：廣告、收件匣、試算、人工確認
- 網站標題：小預算想試 ChatGPT 廣告？日文作者讓 ChatGPT 設定廣告、算每次點擊出價要多低才回本，被拒後交 dots 跟客服往返，記下真正有用的解法
- 一句話用途：日文作者 ssknaoya 為自己在 Steam 上架、全球實售約25套的小眾遊戲申請 ChatGPT 廣告（最低整檔活動17,000日圓或每日5,000日圓，需付款資料與證件）。他用 ChatGPT Work 內的 ChatGPT Ads Manager 外掛以對話設定廣告內容與 UTM，請 ChatGPT 以「售價七成入帳」試算不同 CPC 與購買率的損益與兩平購買率，選定 CPC 上限50日圓。修改後的廣告被拒且不顯示原因，Ads Manager 也查不到；Work 讀不到客服回信，改用 dots 讀信並自動回覆，但兩週與客服機器人往返無進展。最後在同一活動另建一則廣告，立即通過並開始投放。作者自述＋截圖，本庫未重現。
- 核心目標：用對話代理完成小額廣告的設定與試算，並在審核卡住時有可行的處理路徑。
- 分類／標籤：廣告投放／成本試算／客服往返
- 目標使用者：想小額試投 ChatGPT 廣告的個人開發者或小店家
- 工具：ChatGPT Work（ChatGPT Ads Manager 外掛，@ads-manager-setup 技能）／ChatGPT dots（Gmail 讀寫）／ChatGPT 廣告（beta）
- 首次收錄／最近查證：2026-10-31 08:55（台灣時間）
- 證據狀態：`author-demo`（作者 Zenn 自述＋管理畫面與對話截圖）；費用門檻等為作者 2026-10 所見，非本庫核實
- 是否獨立重現：否

## 輸入與預期輸出

- 輸入：產品頁網址（作者為 Steam 商店頁）、預算、售價與分成比例、品牌 Logo。
- 輸出：已建立的活動與廣告（含 UTM）、CPC 與購買率對照的損益試算表、兩平購買率；被拒時的客服往來紀錄。

## 來源版本

### 來源A：ssknaoya（Zenn，日文）

- 原文：[ChatGPT 広告を dots や ChatGPT Work から設定する](https://zenn.dev/ssknaoya/articles/382667bc8fa8ca)，2026-10-31 01:23 JST（台灣時間 00:23）；本輪讀全文。作者註明為 2026 年 10 月內容、廣告後台標示 beta。
- 取得內容（翻譯摘要）：
  1. 申請：輸入網址後多數欄位自動帶入，但品牌 Logo 誤抓成 Steam 標誌，須手動換成遊戲 Logo；駕照上傳反覆失敗，改用護照一次成功。
  2. 後台橫幅引導到 ChatGPT Work，自動填入「用 @ads-manager-setup 技能協助設定 ChatGPT Ads Manager」；外掛啟用後 AI 可讀寫廣告狀態，作者以對話討論文案、完成設定並加上 UTM。
  3. 出價：預設 CPC 上限500日圓；作者請 ChatGPT 以總預算17,000日圓、每套入帳1,260日圓試算——CPC 100日圓需購買率約7.9%才回本、50日圓約4.0%、20日圓約1.6%；選50日圓（後台警告過低，未批准前即顯示，暫不理會）。
  4. 被拒：與 ChatGPT 討論改過的廣告被拒、原因不顯示；ChatGPT 依廣告政策推測可能是「自律兵器」字眼，但改前含此字的版本反而通過，只是假設。
  5. 客服：ChatGPT 起草客服信由作者按送出；Work 雖已授權卻讀不到回信；改用 dots 讀信並交由它回覆，形成機器人與客服機器人互回，兩週無進展。
  6. 解法：發現同一活動可放多則廣告，確認預算計法後新增一則，立即過審並「投放中」；原廣告仍未核准。
- 作者心得：審核看起來是機器處理，例外處理靠人力而跟不上；小額廣告主可能被排後；被拒時另建新廣告比等客服快。
- 缺口：實際曝光、點擊與銷售數字未公開；dots 自動回信的內容與授權範圍細節未公開。

## 建議操作流程（依來源整理；本庫未實測）

1. 先請代理用自己的售價與分成算「CPC × 購買率」損益表與兩平點，再決定出價上限與總預算。
2. 用 Ads Manager 外掛設定時，逐欄核對自動帶入的品牌名稱、Logo 與連結，加 UTM 以便追蹤。
3. 被拒且無原因時，保留原廣告、在同活動新增一則修改版（先確認預算是否共用）；客服往返交代理處理時，限定只回覆客服、每封先給你看。

## 可複製提示詞（本庫原創設計，未實跑）

> 我的產品售價＿＿，平台扣除後每筆入帳約＿＿。廣告總預算＿＿。請做一張表：CPC 為＿＿／＿＿／＿＿時，購買率1%、2%、5%的點擊數、預期購買數、入帳與廣告費差額，並算出每個 CPC 的兩平購買率。所有數字標明為假設，不是預測。接著列出廣告設定前我要手動核對的欄位（品牌名稱、Logo、連結、UTM）。未經我確認，不要送出或修改任何廣告、不要付款。

## 所需連接、權限與限制

- 外掛可讀寫廣告帳戶；預算、出價、送審都涉及花錢，應每次由本人確認。
- 讓 dots 讀寫 Gmail 回客服，等於授權它代你寄信；作者經驗是機器人互回無效，建議改成每封先給本人看。
- 費用門檻、證件要求與 beta 狀態隨時間變動，以官方後台為準；本案不代表 Grok Bot 或 Muse 有同樣的廣告外掛。
