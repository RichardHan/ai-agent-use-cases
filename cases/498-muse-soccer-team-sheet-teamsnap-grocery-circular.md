## 建議操作流程（依來源整理）

1. 先決定哪些網站真的沒有 API，才用瀏覽器登入；能 API 的不要改走點擊。
2. 憑證用產品允許的安全方式交給代理，並限制只能讀指定頁面、不能改家長聯絡或付款。
3. 排程：比賽週才抓隊表；無比賽回報「本週無賽」即可，避免空跑。
4. 隊表／週刊先寄本人核對再列印或採買；TeamSnap 漏登只出提醒，不由代理逕行改家長通訊。

## 所需連接、權限與限制

- 作者把聯盟與 TeamSnap 憑證交給 Muse；照做前需接受代理可讀家長通訊與球員名單的風險，並設定對外寄信／改設定的核准。
- 無 API 的網站改版會讓流程失效；隊表開放時窗只有賽前兩天，排程要對準。
- 本庫不推定 Grok Bot 或 ChatGPT dots 有相同的 Muse 瀏覽器排程能力。

## 驗收與可重現性

- 可驗收：連續兩週有賽時 PDF 與官網一致；TeamSnap 對照無誤報；週刊郵件附檔可開、優惠標註可核對原傳單。
- 本庫未重現。
