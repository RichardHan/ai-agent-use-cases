# UC-516：Muse 一天四次的郵件摘要改成「全文存進 Spaces、聊天只留一行有無要處理」，再加一個每小時記錄的雲端電腦狀態畫面

- 標籤：收件匣、摘要、儀表板、每日
- 網站標題：每天好幾次的郵件摘要把聊天洗版？讓 Muse 把全文存進可搜尋的 Spaces 畫面，聊天只告訴你「這次有沒有要處理」

- 核心目標：把「會被沖走的定期摘要」與「需要馬上知道的提醒」分開：要回頭查的放進畫面，要即時察覺的留在聊天。

## 輸入與預期輸出

- 輸入：既有的定期郵件摘要工作（每天四次、只摘要上次檢查後的新信）；「重要信件沒有時也要短短通知」的既有約定。
- 輸出：Spaces「郵件摘要」畫面（最新一則置頂放大、過去依新到舊排列、「要處理」標記、異常回次篩選、關鍵字搜尋、立即檢查按鈕）；聊天每回一行「要處理：有／無」；異常照常在聊天通知。另有「VM 狀態監看」畫面：磁碟／記憶體／CPU 量表、運行時間、定期工作狀態、工具版本與歷史趨勢，每小時記錄、可按鈕重取。

### 來源A：Sonop（@sonop1）／note（日文）

- 取得內容（翻譯摘要）：
  - 作者平日讓 Muse 早上確認行程、每天四次摘要郵件、每天三次送新聞摘要。問 Muse「Spaces 是什麼」後，一晚內重新檢視兩個定期工作、做了兩個小工具。
  - 新聞摘要：搬進 Spaces 雖方便回看，但 Muse 建議不要搬，理由是新聞的價值在新鮮；聊天是「送到你面前」，Spaces 要自己去開，忘了開就漏看。維持原樣。
  - 郵件摘要（四次／天，只摘要上次檢查之後的新信）：出發點是「沒有重要信的回次也一定要短短通知」，因為曾發生檢查跑了但沒送摘要，分不清是沒事還是失敗。改成併用：全文存 Spaces，聊天每次一行「要處理：有／無」。畫面最新一則置頂、過去依新到舊；有「要處理」標記可只篩這些，也能篩異常回次、關鍵字搜尋，並加了定時以外的「立即檢查」按鈕。檢查失敗、摘要為空等異常仍照舊在聊天通知。從提問到切換約 15 分鐘：建 Space、設定排序、改定期工作的送出規則。常用的放側欄（圖示自動選）。
  - 工具 1：Markdown 檢視器（貼上或讀入 .md，顯示標題、清單、表格，自動目錄、字數與閱讀時間，可直接修改後存回）。
  - 工具 2：VM 狀態監看：Muse 在雲端虛擬電腦工作，作者做了一個畫面顯示磁碟、記憶體、CPU 負載、運行時間、定期工作狀態、已安裝工具版本與歷史趨勢。Space 本身無法直接看進 VM，所以改成每小時量測一次記錄到 Space，另有按鈕可即時重取（作者觀察 VM 為 Linux）。
  - 判斷軸：新鮮度是價值的放「送達型」（聊天）；回看、篩選、紀錄是價值的放「開啟型」（Spaces）。郵件摘要中不放金額、帳號等資訊。
- 作者報告結果：聊天每天只剩一行，沒事就結束，有事才開畫面讀全文；回看「那封信何時來的」可用日期與關鍵字查。作者自述，未提供量化數據。

## 建議操作流程（依來源整理）

1. 先列出自己的定期摘要，逐一判斷：讀完就丟（留聊天）還是之後會查（搬 Spaces）。
2. 對要搬的那個摘要，請 Muse 建一個 Space：最新置頂、過去依新到舊、可依「要處理」與異常篩選、可關鍵字搜尋、加「立即檢查」按鈕。
3. 修改定期工作的送出規則：全文寫入 Space；聊天只送一行「要處理：有／無」；失敗或空摘要一定在聊天報異常。
4. 摘要內容不放金額、帳號、密碼等敏感資訊。
5. 試跑一兩天，確認每回都有那一行通知、Space 有新增對應紀錄。
6. （可選）做一個每小時記錄的 VM 狀態畫面，確認定期工作的底層是否健康。

## 可複製提示詞（本庫依來源改寫，未實跑）

> 請建一個 Space 叫「郵件摘要」：每次定期檢查的摘要全文存成一筆，最新的置頂放大，過去依新到舊排列；每筆標示「要處理」或「無」，可只篩「要處理」、可篩出檢查失敗的回次、可用關鍵字搜尋，並加一個「立即檢查」按鈕。然後把每天四次的郵件摘要改成：全文只寫進這個 Space，聊天每次只送一行「要處理：有 N 封／無」。檢查失敗或沒有產生摘要時，一定要在聊天說明異常。摘要中不要寫入金額、帳號或任何密碼。先用今天的信跑一次給我看。

## 所需連接、權限與限制

- 需要 Muse 已連接郵件並有定期工作；Spaces 依地區提供。
- Spaces 是「要自己打開」的形式；需要即時察覺的事仍要留在聊天通知。
- VM 監看是每小時量測後寫入的紀錄，不是即時；Space 無法直接讀 VM（作者說明）。
- 不推定 Grok Bot 或 ChatGPT dots 有 Spaces 同名功能。

## 驗收與可重現性

- 可驗收：每回定期檢查都在聊天留一行；Space 筆數與檢查次數一致；「要處理」篩選結果與聊天那一行一致；刻意製造失敗時聊天會報異常。
- 本庫未重現；作者未提供量化結果。
