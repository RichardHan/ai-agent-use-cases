# UC-525：在 Grok Bot 群組放三個分工 Bot：丟一個 X 影片連結，總管派下載、剪輯師接 ChatCut 加中英字幕與動態圖像

- 情境：創作
- 標籤：影片、多代理、群組派工、字幕
- 網站標題：不想在幾個 Bot 之間來回複製交代？把總管、下載、剪輯三個 Bot 放進同一個群組，丟連結就自動分工剪片
- 一句話用途：簡中作者 @cnyzgkc 分享：在 Grok Bot 建三個 Bot——「大總管」負責調度、「Twitter 小助手」負責下載 X 影片、「影片剪輯師」連接 ChatCut 雲端剪輯；剪輯師用一句「讀某網址以連接 ChatCut App」完成安裝與授權。把三個 Bot 拉進同一個 Grok 群組、寫清職責後，貼上 X 影片連結說「幫我下這個影片」，總管轉給小助手下載；再說「剪成對話影片、加中英雙語字幕和 MG 動畫」，任務轉給剪輯師，它先分析素材、反問字幕樣式再出片。另一位作者 @cheery9998 自述照做跑完一次。作者自述，本庫未重現。
- 核心目標：用群組與明確職責取代人工在多個 Bot 私聊之間轉述任務，把「找素材→下載→剪輯加字幕」串成一句話的流程。
- 分類／標籤：多 Bot 群組分工／雲端剪輯串接
- 目標使用者：做短影音二次創作、已用或願意試 ChatCut 的創作者
- 實作門檻：工具串接
- 工具：Grok Bot（多 Bot、群組）／ChatCut（雲端剪輯，連接方式為作者提供的連結指令）
- 首次收錄／最近查證：2026-11-13 09:00（台灣時間）
- 證據狀態：`author-demo`（作者 X 貼文附示範影片，本庫未看影片）；跟做者文字自述跑通一次；ChatCut 連接頁為廠商頁面，本庫未登入、未核實際功能
- 是否獨立重現：否

## 輸入與預期輸出

- 輸入：一則公開 X 影片連結；口頭剪輯需求（例如對話影片、中英雙語字幕、MG 動態圖像）。
- 輸出：下載好的影片素材；ChatCut 專案中完成剪輯、字幕與動畫的成片（剪輯前 Bot 會反問字幕樣式）。

## 建議操作流程（依來源整理；本庫未實測）

1. 先確認素材的使用權：只用自己的影片、已獲授權或明確允許再利用的內容。
2. 建三個 Bot，各寫一段職責：總管只分派不動手；下載 Bot 只下載並回報檔名與長度；剪輯 Bot 只在剪輯工具內操作。
3. 剪輯 Bot 連接剪輯工具時，確認授權範圍（能讀哪些專案、能否刪除）；先用測試專案試跑。
4. 把三個 Bot 放進同一群組，用一則連結測試整條流程；剪輯前讓剪輯 Bot 先問你字幕樣式、長度與輸出比例。
5. 成片由你檢查字幕翻譯與畫面，再自行決定是否發布。

## 可複製提示詞（本庫依來源改寫，未實跑）

> 這個群組有三個 Bot：總管（只負責分派與回報進度，不自己下載或剪輯）、下載助手（只下載我給的連結，完成後回報檔名、長度與來源網址）、剪輯師（只在 ChatCut 內工作）。我丟連結時，先問我這段影片我是否有權使用；我確認後才下載。剪輯前，剪輯師要先列出剪輯計畫與字幕樣式讓我選。任何發布、上傳到其他平台或刪除專案的動作都不要做。

## 所需連接、權限與限制

- 下載他人影片再剪輯發布，可能侵犯著作權或違反平台條款；「二創」不等於合法授權，請自行確認權利與引用規範。本庫不建議用於搬運他人作品。
- ChatCut 連接授權後可讀取帳號內全部專案（作者自述）；連接方式與功能以 ChatCut 官方說明為準，本庫未核。
- 多 Bot 群組協作會增加用量；本案只涉及 Grok Bot，不推定 Meta Muse 或 ChatGPT dots 有相同的群組或 ChatCut 連接。
