## 建議操作流程（依來源整理；本庫未實測）

1. 先讀倉庫 README 與 manifest，確認網路白名單與排程是否可接受。
2. 在 Muse 新開對話貼入安裝提示詞；核准網址權限前看清 Muse 說明的用途。
3. 跑完驗收：先新增一筆測試交易、重新載入確認還在，再刪掉測試交易。
4. 定期用「Settings → Data & Backup」下載備份；要更新時在該空間內貼更新提示詞，更新後核對持股與交易筆數。
