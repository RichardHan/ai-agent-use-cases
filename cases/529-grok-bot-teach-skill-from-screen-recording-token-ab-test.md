# UC-529：每週重複的網購查詢，先錄一次示範影片讓 Grok Bot 做成技能，再用同一題比較用量

- 情境：省錢
- 標籤：技能、用量稽核、瀏覽器、對照實驗
- 網站標題：同一個查詢任務，「口頭交代」和「錄影教一次做成技能」各跑一次：作者自述技能版少用約四成 token

- 分類／標籤：技能建立／用量對照實驗
- 目標使用者：已經有固定上網查詢類例行工作、在意每週用量上限的 Grok Bot 使用者

## 輸入與預期輸出

- 輸入：一個可重複的網頁任務（固定網站、固定欄位）、Grok Bot 的雲端電腦、你親自操作一次的螢幕錄影。
- 輸出：一個依示範步驟寫成的技能；兩次執行的結果與用量對照（文字指示版 vs 技能版），以及「這個任務值不值得做成技能」的判斷。

## 建議操作流程（依來源整理；本庫未實測）

1. 從自己的例行工作挑一個「每週都跑、網站與欄位固定」的任務，寫下固定輸入（例如商品型號、郵遞區號）。
2. 用一般文字指示跑一次，記下結果與當次用量。
3. 在 Bot 的雲端電腦上親自操作一遍並錄影；不要在錄影中輸入密碼或個資。
4. 請 Bot 看錄影，寫成技能：步驟、需要的輸入、何時算完成、找不到時要回報什麼。
5. 用同一組輸入跑技能版，比較結果正確性與用量；把建技能的用量也算進去，估計跑幾次才回本。
6. 只有回本次數合理、結果一樣正確的任務才保留技能；網站改版時重錄一次。

## 可複製提示詞（本庫依來源改寫，未實跑）

> 我剛在你的電腦上錄了一段示範影片，內容是查［網站］上［商品／條件］能否配送到［郵遞區號］。請看完錄影，把我的操作整理成一個可重用技能：列出步驟、需要我提供的輸入、完成條件、找不到商品或缺貨時的回報格式。不要登入任何帳號、不要加入購物車或付款。建好後，用同一組輸入執行一次，回報結果，並列出這次與上次（只給文字指示那次）的用量，讓我判斷值不值得保留這個技能。

## 所需連接、權限與限制

- 只需 Grok Bot 的雲端電腦與瀏覽；不需要付款或登入。錄影中避免出現帳號、地址、卡號等個資。
- 用量數字以 Grok Bot 介面顯示為準；不同任務、不同網站改版後效果可能完全不同。
- 「錄影建技能」是作者在 Grok Bot 上的做法；不推定 Meta Muse 或 ChatGPT dots 有相同的看錄影建技能功能。

## 驗收與可重現性

- 可驗收：兩次執行結果一致且正確；技能版用量低於文字指示版，且「建技能用量 ÷ 每次節省」得出的回本次數可接受。
