# UC-562：博世產線停機時查找維修知識

- 情境：工作
- 標籤：製造、設備維修、知識管理、人工判斷
- 網站標題：產線故障時用代理查過往解法
- 一句話用途：讓現場人員以平板查詢錯誤訊息與過往故障解法。
- 核心目標：減少生產設備停機後尋找維修知識的時間。
- 分類／標籤：製造／設備維修
- 目標使用者：產線作業員與維修人員
- 實作門檻：進階開發
- 首次收錄／最近查證：2026-11-20
- 證據狀態：official（博世自有工廠與自家產品報告）
- 是否獨立重現：否

## 來源版本

[博世 Shopfloor Agent 官方報告](https://www.bosch.com/stories/agentic-ai-manufacturing-production/)，英文；報告自身工廠 Bamberg 的使用，也介紹客戶試點。本案只記博世自己的流程。

## 流程與結果

博世描述代理儲存錯誤、原因與解法，分析錯誤訊息並給現場人員情境化建議；人員用平板參考解法處理故障。博世稱減少停機可使每座工廠年節省約 85 萬歐元；原文未提供計算期間、基準與獨立核對，不能視為本庫驗證或保證。

## 限制與採用邊界

來源未公開案例級維修紀錄、部署成本或錯誤率；影片未觀看。維修涉及人身與設備安全，必須由合格人員依廠內鎖定掛牌及操作規範執行；代理建議不是安全授權。工廠資料與存取範圍須另審。
