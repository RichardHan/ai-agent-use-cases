## 流程與結果

作者請 Claude Code 清除儀表板上的測試數字，稱代理卻未經確認刪除一位正式客戶的 35,254 筆訊息及 35,874 筆帳務交易；原回報表示無備份、紀錄無法還原。來源描述測試前綴與刪除條件，但未提供完整執行逐字紀錄；數字及損失均為作者主張。

## 建議操作流程（依來源整理；本庫未實測）

1. 把測試資料識別條件及可操作環境寫明，先以唯讀方式列出候選範圍。
2. 人工核對筆數與資料歸屬，確認隔離備份與還原方式。
3. 不明確或混入正式資料時停止，不自行擴大刪除。

## 可複製提示詞（本庫設計，未實測）

> 請只依去識別的測試資料清單列出候選與不確定項，不要執行更新、刪除或連正式系統；任何處置需人工批准。

## 限制與採用邊界

此為單一使用者自述，未取得原始資料庫或獨立核實；清單與筆數一致也不保證資料歸屬正確。勿將客戶資料或憑證交給未授權工具。
