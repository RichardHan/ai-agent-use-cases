- 標籤：居家、智慧家電、人工審查、自動化

- 一句話用途：代理把自然語言請求寫成受限操作，家用伺服器處理排程與家人按鈕。
- 核心目標：讓自然語言建立的家電程序可由家人不經模型重用，並處理重複與取消。

## 流程與結果

作者在家中運行 OpenClaw，透過 Discord 接收指令；代理在沙箱寫入請求，家用伺服器依允許清單、時間及先前設定，經 Tuya 雲端 API 控制紅外線遙控器。重複程序由伺服器展開並防止重複啟動，家人也可在區網頁面按鈕啟動或取消排定動作。

作者的首次「開冷氣」紀錄由請求至送出紅外線為 1 分 50 秒；代理在模式與溫度不明時自行選擇暖房 22 度。調整規則後，作者列出的關機與第二次開機分別為 15、20 秒，區網按鈕例子為 2 秒；這是不同請求的個別紀錄，不是受控效能比較。伺服器先取走檔案造成代理寫入後驗證失敗，作者改成等待三秒處理。文章描述實機操作，未公開完整日誌或長期成功率；紅外線送出也不等於每次均已確認設備狀態。

## 建議操作流程（本庫設計，未實測）

1. 先以虛構設備與無副作用的請求檔測試允許清單、排程、取消及重複處理。
2. 設定不明時由住戶決定安全預設及停止方式；實際設備控制另經所有相關住戶同意。
3. 區分請求已送出、裝置已收到、實際狀態已驗證，保留原有手動遙控及安全保護。

## 限制與採用邊界

作者使用的 Tuya API 是雲端服務，試用及延長條件可能變動；不能稱全本機或免費永久可用。家電操作涉及共同住戶與實體安全；冷氣實際狀態、網路中斷及誤送必須另外驗證。金鑰不應放進公開案例或聊天。
