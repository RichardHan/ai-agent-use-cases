## 流程與結果

作者讓 Claude Code 維護 Home Assistant 設定，並加入三個 ESP32 室內感測器。冷氣設定與室溫讀值不符時，代理先懷疑紅外線命令未到，再依讀值推測變頻冷氣過度降溫。作者到現場觀察設備後排除第一種解釋；隔天發現感測器正對出風口，移開後作者報告溫度差從約 4–5°C 降至約 1°C，取消擬議的自動關機規則並訂正紀錄。三台冷氣不可同時運轉的互鎖由既有確定性規則處理；曾因舊狀態觸發，作者修正狀態而非停用互鎖。

## 建議操作流程（依來源整理；本庫未實測）

1. 保留原始讀值、代理假設與修正紀錄，先核對感測器位置和設備現場狀態。
2. 新控制規則先由人審閱；將電力等安全互鎖與模型決策分離。
3. 只有補足安全權限與設備文件後才考慮變更，不能只依文字推論控制設備。

## 可複製提示詞（本庫設計，未實測）

## 限制與採用邊界

這是單一家庭作者自述，沒有獨立核驗；作者沒有該冷氣的功率計，文中節能比例是估算，不作實測成果。紅外線發送不代表設備已收到。交付長期 token 或 SSH 會帶來權限風險，實際環境需審核與撤銷機制。
