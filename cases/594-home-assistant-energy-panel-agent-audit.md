# UC-594：代理核對智慧家庭儀表板單位，找出能源數據誤標

- 情境：生活
- 標籤：智慧家庭、物聯網、能源、人工確認
- 網站標題：能源面板看似正常，代理比對感測器單位找出誤標
- 一句話用途：比對儀表板與感測器中繼資料，發現住宅能源數值被錯誤解讀。
- 核心目標：避免把電量、百分比和連線容量混作即時能源指標。
- 分類／標籤：智慧家庭／能源觀測
- 目標使用者：智慧家庭與能源看板維護者
- 實作門檻：進階開發
- 首次收錄／最近查證：2026-11-20
- 證據狀態：author-demo（設備主人公開紀錄與截圖）
- 是否獨立重現：否

## 來源版本

[Marcus Pichler：Claude in My Home Assistant](https://pichler.dev/blog/home-assistant-claude/)，2026-08-17，2026-09-21 更新，英文。作者稱截圖來自其系統；本庫未核驗系統。

## 流程與結果

作者以 Claude Code 透過 Home Assistant 設定檔及 API 協助維護住宅系統。Grafana 能源面板看似有資料，卻把 4.5 kWh 電量標成 4.5% 自給率，並將 4.00 kW 契約容量顯示為即時電網功率。作者報告代理比對面板宣告單位與感測器中繼資料，找到四個不一致面板；修正後畫面顯示同日自給率 30.0%，並將逆變器即時讀值與計費電量分開。作者稱另有 29 個查詢依賴可變顯示名稱，其中三個已改寫。

## 建議操作流程（依來源整理；本庫未實測）

1. 列出面板的單位、資料來源及更新時間，對照感測器的單位與型別。
2. 對比來源數據與人工計算，釐清即時值、累計值和靜態設定。
3. 修正前備份並由人審閱變更；不要因面板有數字就視為正確。

## 可複製提示詞（本庫設計，未實測）

> 請只讀比對這份去識別化儀表板設定與感測器中繼資料，標示單位、時間範圍及資料型別不一致之處；不修改設定。

## 限制與採用邊界

成果及截圖均為作者自述，未由本庫重現；同日數值不是跨家庭的節能效果。作者另用雲端模型產生報告與門鈴描述，提供資料或影像前應檢查隱私、權限與服務條款；鎖及高風險設備應保留人工控制。

## 去重與關聯

本案只計能源面板查核一次，不把同篇的語音及自動化拆成多案；可與 UC-593 的感測器現場誤診及 UC-595 的能源控制建置對照。
