## 流程與結果

作者使用 Gemini CLI、Claude Code 與 Tsumiki 協助規格、設計、任務與實作；本人審閱並修正。系統收集 SwitchBot、Nature Remo 與天氣資料至 BigQuery，利用 Nature Remo API 調整冷氣，並以 Looker Studio 顯示溫濕度與用電。作者稱約兩週建成運行、雲端月費約 100 日圓；Gemini CLI 開發初期 2–3 天超過 3,000 日圓，後轉用 Claude Code 付費方案。這些是作者在當時條件下的成本，不保證可重現。

## 建議操作流程（依來源整理；本庫未實測）

1. 明確指定裝置、資料與人工接管條件，審閱代理產生的外部 API 規格。
2. 在部署前測試實際裝置 API，核查輸入與輸出，而非只看測試通過。
3. 小範圍觀察並監控費用，保留手動控制及安全停止方式。

## 可複製提示詞（本庫設計，未實測）

## 限制與採用邊界

作者自述回憶可能有誤，未公開原始代理對話；僅支援冷房，預測控制仍有室溫上下波動及排程不足。未經獨立重現，圖表不足以證明節能或長期可靠；雲端帳號與設備操作均需授權。
