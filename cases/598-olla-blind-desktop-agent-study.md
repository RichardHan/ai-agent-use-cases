# UC-598：盲人使用讀屏介面操作桌面代理

- 情境：工作
- 標籤：無障礙、視障、人工確認
- 網站標題：讀屏使用者委託桌面代理操作應用程式
- 一句話用途：以可供讀屏使用的介面向桌面代理下指令，並檢視執行狀態。
- 核心目標：降低盲人使用者操作桌面應用程式的障礙，同時保留非視覺監督。
- 分類／標籤：無障礙／桌面操作
- 目標使用者：無障礙工具設計者與讀屏使用者
- 實作門檻：進階開發
- 首次收錄／最近查證：2026-11-20
- 證據狀態：author-demo（研究團隊報告使用者研究）
- 是否獨立重現：否

## 來源版本

[OLLA 桌面代理研究論文](https://aclanthology.org/2026.emnlp-main.1763.pdf)，2026 年，研究團隊第一手報告；[作者公開的 OLLA 專案](https://github.com/Satwikram/OLLA)。本庫未重現研究或核實私有操作紀錄。

## 流程與結果

研究團隊讓 8 名盲人讀屏使用者在三週研究期間，以 OLLA 的讀屏介面用自然語言委託 Windows 桌面代理執行日常任務。介面讓參與者非視覺地監看與回顧操作，代理則根據畫面與介面樹選擇動作；研究紀錄共 12 個應用程式、1,258 條使用者指令。研究中使用 GPT-5，人工標註完全成功率為 52.5%；其餘四個模型的數字是研究者事後在新的應用程式實例重跑同一批指令，並非參與者當時使用的結果。

例如代理有時找不到 Word 自訂邊界選項，也曾在 Excel 重複新增工作表而未停止。受訪者希望重要動作前先確認，而非單純追求全自動。成功率只涵蓋參與者選擇委託的任務；有些人避開銀行、密碼或私人文件等敏感任務，不能推廣為所有桌面工作的可靠率。

## 建議操作流程（依來源整理；本庫未實測）

1. 先確認讀屏介面能讀出代理狀態與操作紀錄，在可還原的測試文件試用。
2. 一次交付低風險任務，核對結果與使用者要求；涉及刪除或提交時由人確認。
3. 對重複操作、未完成的確認步驟與錯誤回報保留停止及復原方式。

## 可複製提示詞（本庫設計，未實測）

> 在測試文件中先說明你打算操作的步驟；遇到不明選項或需要刪除、儲存覆寫時先停下並詢問，不要自行猜測。

## 限制與採用邊界

這是研究者報告的八人研究，不是本庫的獨立實測；原型僅涵蓋 Windows、英語及桌面應用，沒有評估網頁或低視力族群。成功率是人工對指令與軌跡的標註，不代表每名使用者或所有任務皆有相同表現。論文指出研究設定使用 LangSmith 記錄指令、模型理由、動作、截圖、介面樹與互動歷史，並透過 OpenAI API 將截圖及文字上下文交給 GPT-5；這些資料可能包含個資，不能推定公開版本必然沿用同一設定。試用前應確認資料流向、授權與保存方式；勿把帳密或敏感文件交給代理。

## 去重與關聯

研究者的 1,258 條指令屬同一項 OLLA 部署研究，記為一案，不依應用或模型拆案；可與 UC-599 的低視力網頁代理研究對照。
