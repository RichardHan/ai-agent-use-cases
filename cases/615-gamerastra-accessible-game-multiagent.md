# UC-615：多代理協助視障玩家理解遊戲畫面

- 情境：生活
- 標籤：無障礙、遊戲、多代理
- 網站標題：以聲音與位置提示輔助遊戲
- 一句話用途：結合畫面辨識、文字讀取與音訊提示，協助視障玩家操作遊戲。
- 核心目標：降低缺少原生無障礙支援的遊戲操作門檻。
- 分類／標籤：無障礙／遊戲
- 目標使用者：遊戲無障礙與輔具研究者
- 實作門檻：進階開發
- 首次收錄／最近查證：2026-11-21
- 證據狀態：author-demo（研究團隊報告使用者研究）
- 是否獨立重現：否

## 來源版本

[研究團隊：GamerAstra](https://arxiv.org/html/2506.22937v1)，2025 年預印本，英文；研究團隊報告原型測試，本庫未獨立重現。

## 流程與結果

GamerAstra 以多個功能代理結合狀態偵測、影像辨識、OCR 與視覺語言模型，按遊戲設定提供語音、位置提示及鍵盤操作。研究者讓八名視障參與者遠端操作研究電腦，比較 NVDA 加 OCR 與原型在 Uno、SenrenBanka、MySuika 三款遊戲的體驗；順序交錯，模型透過阿里雲 API 使用。參與者報告原型可直接播報 Uno 出牌、提供 MySuika 位置資訊，減少自行解讀零碎 OCR 的負擔。

## 建議操作流程（依來源整理；本庫未實測）

1. 邀請目標玩家共同決定所需提示與控制方式，先以低風險遊戲測試。
2. 為遊戲準備辨識與操作設定；分別測試畫面變化、語音延遲與錯誤辨識。
3. 讓玩家控制提示密度與手動操作，並與原有輔具比較而非預設取代。

## 可複製提示詞（本庫設計，未實測）

> 在已獲同意的測試畫面中，簡短描述可辨識的遊戲物件、相對位置與不確定之處；不要代替玩家作出操作。

## 限制與採用邊界

這是八人、三款遊戲的短期研究，不證明所有遊戲均可直接使用；遊戲需配置，視覺模型可能延遲或誤判。截圖送往雲端模型時可能包含帳號、聊天或其他玩家資訊；原型另用 Tencent ASR 處理語音輸入。使用畫面與語音前須確認音訊是否傳送至該服務、取得同意，並分別確認服務的資料傳送、保存和使用政策。本庫未測試原型或費用。

## 去重與關聯

本案著重既有遊戲畫面的辨識與操作；與 UC-616 修改研究用 3D 場景的做法不同。同一研究的多款遊戲不拆成多案。
