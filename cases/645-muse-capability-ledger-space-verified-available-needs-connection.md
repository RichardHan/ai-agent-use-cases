- 情境：工作

- 網站標題：交給 AI 代理的事越來越多，卻記不得哪些真的試過？做一本能力台帳：每項能力標「已驗證／可用／需連接」並寫出處，沒驗過的就不要當成會
- 一句話用途：日文作者 eternal（悠暉）在 Zenn 自述，把個人接案（網站製作、廣告投放準備）用的 Meta Muse 能力整理進一個名為「精神と時の部屋」的 Space：8 類 26 項基本能力各有狀態（verified／available／needs_connection），新學到的能力逐筆記成長紀錄（日期、類別、內容、驗證狀態、出處）；作法類寫成自訂技能，長資料移到私人 GitHub repo，記憶只留現況與參照。

- 目標使用者：把多種實務交給個人 AI 代理、需要知道哪些能力可放心委派的個人工作者
- 實作門檻：入門對話

## 輸入與預期輸出

- 輸入：代理目前被交辦的工作類型；每次新學會的作法與驗證時用的實際檔案或貼文。
- 輸出：一個 Space 台帳：8 類 26 項基本能力（會話·記憶·安排／調查·閱讀／檔案·文件·Space／郵件·行程／社群·廣告／生成媒體／瀏覽器·實務代辦／其他連接），每項有狀態；成長紀錄逐筆附出處；未驗證項目明確列在「限制」。

- 取得內容（翻譯摘要）：
  1. **問題**：新作法只留在聊天流裡，事後記不得是「驗證過」還是「只聽過步驟」；把未驗證當成會，實務會中途停下。
  2. **設計**：2026-11-17 把一個子聊天命名為「精神と時の部屋」並建同名 Space；狀態三種：verified／available／needs_connection；沒有根據的項目保持 needs_connection。
  3. **存放分層**：能力清單與成長紀錄放 Space；作法放自訂技能；長期資料放 GitHub 私人 repo；記憶只放偏好、判斷標準、現況與一行技能參照。
  4. **成長紀錄**：截至 2026-11-18 共 6 筆，2 筆已驗證——X 貼文調查（FxTwitter／vxTwitter／官方 oEmbed 分工，只限公開貼文、不需認證）與 YouTube 調查（oEmbed／RSS／Transcript API／yt-dlp，用實際影片走過四種工具）；分析 79 則 X 書籤後新增 3 個「部分驗證」技能（ffmpeg 剪輯、NotebookLM／Google Workspace 連接、影片開場與運鏡）。
  5. **台帳外的對應運作**：11-16 起每天早上 8 點左右收到前一天廣告支出、曝光、點擊、成效的唯讀摘要；用 Space 做把 Messenger、Instagram、Gmail 待回覆集中的「返信ボックス」；15 秒直式影片廣告以 Remotion 算圖並目視確認 4 個鏡頭。
  6. **限制照寫**：Grok Build 的 X 搜尋只學了步驟未驗證（需本人登入與 API 金鑰）；LINE 只驗到官方帳號權杖、送出程式未測、Webhook 未建；Meshy 3D 未接 API 金鑰；廣告尚未投放（11-18 新帳戶餘額 ¥0、無活動），所以台帳裡沒有任何「廣告有成效」的紀錄。
- 作者報告結果：能力狀態可一眼查到；未驗證項目與已驗證項目分開。

## 建議操作流程（依來源整理；本庫未實測）

1. 開一個專用子聊天與同名 Space 當能力台帳。
2. 先盤點基本能力（分類＋項目），每項給狀態：已驗證／可用（未實測）／需連接；沒有根據的一律先標需連接。
3. 每學到新作法就追加一筆：日期、類別、內容、狀態、出處（原貼文或驗證用的實際檔案）。
4. 驗證要用真實素材走完一遍才升級為已驗證；部分走通標「部分驗證」。
5. 作法寫進技能、長資料移到外部 repo，記憶只留參照，避免記憶膨脹。
6. 定期檢視「限制」區，委派前先查台帳狀態。

## 可複製提示詞（本庫原創，未實跑；改寫自來源流程）

> 幫我建一個「能力台帳」Space。先把你目前的基本能力分類列出，每項標狀態：已驗證（有用真實素材完整跑過，寫出日期與用了哪個檔案或連結）、可用（理論上能做但沒跑過）、需連接（缺帳號、金鑰或授權）。沒有根據的一律標需連接。之後每次我們學會新作法，就新增一筆成長紀錄：日期、類別、內容、狀態、出處。我請你做事前，先查台帳；如果該能力不是已驗證，先告訴我並提議用一個小樣本驗證，不要直接當成會做。

## 所需連接、權限與限制

- 台帳只記錄作者環境的狀態；能力會隨版本與連接變動，需定期重驗。
- 「已驗證」由作者自評，非第三方測試；外部服務（FxTwitter、yt-dlp 等）的可用性與條款需自行確認。
- 不推定 Grok Bot 或 ChatGPT dots 有相同的 Space 或技能存放方式。

## 驗收與可重現性

- 可驗收：台帳每項都有狀態與出處；新能力只有附真實驗證紀錄才標已驗證；委派未驗證能力時代理會先提醒。
- 本庫未重現。
