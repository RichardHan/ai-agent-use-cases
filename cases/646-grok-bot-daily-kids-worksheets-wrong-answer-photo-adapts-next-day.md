# UC-646：旅行中照樣每天早上做練習：Grok Bot 依每個孩子程度出學習單，答錯的題目拍照回傳，隔天多練沒學會的地方

- 情境：學習
- 標籤：學習單、親子、錯題、每日
- 網站標題：帶小孩長途旅行怕課業中斷？每天早上讓 Bot 依每個孩子程度出數學、閱讀、拼字練習，答錯的拍照傳給 Bot，隔天的學習單就多練那些
- 一句話用途：英文作者 @Teslaconomics 在 X 自述，全家在夏威夷旅行期間，每天早上出門前讓孩子做 Grok Bot 依各自程度與弱點出的學習單（數學、閱讀、拼字、語文）；孩子答錯時，家長把作答照片傳給 Bot，那些題目會影響下一份學習單，讓每天接續前一天，家長也更清楚哪裡已懂、哪裡還需要幫忙。
- 核心目標：在沒有學校課程的期間，用最少的家長備課時間維持每個孩子量身的每日練習，並以錯題持續調整。

- 目標使用者：有多個孩子、需要在旅行或停課期間維持練習的家長

## 輸入與預期輸出

- 輸入：每個孩子的年級、程度與需要加強的地方；前一天答錯題目的照片。
- 輸出：每天早上每個孩子各一份學習單（數學、閱讀、拼字、語文）；下一份會加入前一天錯題相關的練習；家長對各科掌握情況更清楚。

## 建議操作流程（依來源整理並由本庫補成步驟；未實測）

1. 先給 Bot 每個孩子的年級、目前單元與弱點，並請它為每個孩子各建一份「錯題紀錄」。
2. 每天早上（可排程）為每個孩子各出一份短學習單，分科標示，附另頁解答給家長。
3. 孩子做完後，家長拍下答錯的題目傳給 Bot，註明是哪個孩子。
4. Bot 把錯題的類型記進該孩子的紀錄，下一份學習單多出同類型題目；連續答對就減少。
5. 每週請 Bot 摘要每個孩子哪些類型已穩定、哪些還要練。
