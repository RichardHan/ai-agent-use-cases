# UC-682：加航客服代理虛構退票政策：加拿大仲裁法庭裁定企業對 AI 疏忽虛偽陳述負完全賠償責任（Moffatt v. Air Canada）

- 情境：工作
- 標籤：法律、客服、責任判定、退票風控
- 網站標題：加航客服代理虛構退票政策：加拿大仲裁法庭裁定企業對 AI 疏忽虛偽陳述負完全賠償責任（Moffatt v. Air Canada）
- 一句話用途：加拿大旅客 Jake Moffatt 詢問加拿大航空官方網站客服 Agent 喪親機票優惠，Agent 明確答覆「可先買全額票並於 90 天內申請差額退款」；但加航官方書面政策規定喪親票絕不可事後退款。加航以「Agent 是獨立實體、應自行負責，網站另有正確連結」為由拒賠；卑詩省民事審裁處（CRT）裁決加航敗訴，認定客服 Agent 為企業網站延伸，企業對 AI Agent 的疏忽虛偽陳述負有注意義務與完全賠償責任（判賠 812.02 加幣）。
- 核心目標：記錄首例司法確立企業不得以 AI Agent 為獨立實體推卸虛假資訊法律責任的里程碑判決，規範客服 Agent 的法律邊界。
- 分類／標籤：司法判決／客服 Agent 幻覺／企業法律責任／消保合規
- 目標使用者：設計企業對外客服、退款與合約政策 AI Agent 的產品經理、法務與開發團隊
- 實作門檻：入門對話
- 首次收錄／最近查證：2026-11-23 09:25（台灣時間）
- 證據狀態：`official`（加拿大卑詩省民事爭端仲裁庭公開裁判書 2024 BCCRT 149；未由本庫獨立重現）
- 是否獨立重現：否

## 輸入與預期輸出

- 輸入：旅客向客服對話框詢問祖母過世喪親機票（bereavement fare）退款申請規則。
- 輸出：客服 Agent 回覆旅客可先全額購票並於 90 天內補件退差額（與官方條款完全衝突），導致後續法庭判決航空公司敗訴賠償。

## 來源版本

### 來源A：加拿大卑詩省民事審裁處（CRT）判決書 2024 BCCRT 149

- 原始網址：[https://www.canlii.org/en/bc/bccrt/doc/2024/2024bccrt149/2024bccrt149.html](https://www.canlii.org/en/bc/bccrt/doc/2024/2024bccrt149/2024bccrt149.html)
- 發布日期：2024-02-14（判決日期）；原文語言：英文。本庫讀取判決書全文。
- 取得內容：
  1. 案情事實：原告 Jake Moffatt 於 2022 年 11 月透過加航網站 Chatbot 查詢喪親票。Chatbot 明確指出旅客可在完成旅程後 90 天內填寫線上退款表單申請退費。原告依指示購票並於事後申請，遭加航拒絕，理由是官方正式網頁載明「行程完成後恕不接受喪親票退款申請」。
  2. 航空公司抗辯：加航主張 Chatbot 是一個「獨立的法律實體（separate legal entity），對其自身行為負責」，且 Chatbot 回覆中附有官方政策的超連結，旅客有責任查閱正確條款。
  3. 審裁官裁決：審裁官 Christopher C. Rivers 嚴厲駁回加航論點，指出 Chatbot 是加航官網不可分割的一部分，加航對其網站上提供之所有資訊負有注意義務（duty of care）；不能要求消費者自行區分官網哪一部分是正確的、哪一部分是 Chatbot 捏造的。法庭裁定加航構成疏忽虛偽陳述（negligent misrepresentation），判令賠償差額與利息共 812.02 加幣。
- 判例啟示：企業不能藉由宣稱 AI 具自主性來卸除民事賠償責任；AI Agent 的承諾在法律上等同於企業授權代表之陳述。
- 缺口：本案屬於加拿大卑詩省小額民事審裁處之判例，不同法域對 AI 代理權與要約承諾之認定細節可能有所差異。

## 建議操作流程（本庫依來源判決整理之防護步驟；本庫未實測）

1. 財務與退款政策嚴禁開放式自由生成：涉及退款條件、合約金額、賠償責任的業務，嚴禁讓 LLM 自行依常識推論，必須採嚴格確定性檢索（Exact Match RAG）。
2. 對話附帶不可覆寫之硬性阻斷詞：當使用者問及例外條款時，若檢索信賴度不足，必須強制回退「本規則涉及財務退款，請直接聯繫人工專線核對」。
3. 法律合規性驗證管線：在客服 Agent 上線前，法務團隊必須針對核心政策建立包含反事實測試集的評測套件，確保模型不會為了禮貌回覆而捏造優惠條件。
4. 明確提示詞與免責聲明的法律邊界認識：認清單純在網頁角落放置免責聲明無法免除虛偽陳述的法律責任。

## 可複製提示詞

以下為高風險政策問答防幻覺約束範例，未實跑：

> 你是官方政策客服助理。回答退款、改票或財務政策時，你只能引用下方檢索知識庫中的原始條款逐字說明。如果知識庫中未明確記載「允許事後申請退款」，你必須明確回答「根據目前條款，未載明允許事後申請退款，請在付款前向人工客服確認」。嚴禁根據常理推測或給予任何政策例外承諾。

## 所需連接、權限與限制

- 客服對話系統直接面向公眾，其輸出可能被視為企業要約或具法律拘束力之陳述。
- 企業需承擔客服 Agent 輸出的所有法律與商譽後果，不可將錯誤責任轉嫁給模型供應商或終端用戶。
- 須設定即時人工介入與監聽機制。

## 驗收與可重現性

- 可驗收：對話測試集中所有退款與法規爭議提問，Agent 均輸出符合官方條款之答案或安全回退至人工客服。
- 本庫未重現。
