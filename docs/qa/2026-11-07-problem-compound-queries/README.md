# 2026-11-07 自然問題導向複合詞檢索、任務意圖切分與核心案例召回排序優化

## 1. 背景與問題證據

初次造訪訪客在不熟悉特定工具名稱（如 Grok Bot、dots、ChatGPT、Claude）時，通常從自己想解決的日常任務出發進行檢索。
然而在修改前，常見中文任務複合詞高達 18 個直接回傳 **0 筆空結果**，即使庫內收錄大量高度對應的案例（如 198 篇測試驗收案例、16 篇發票報帳案例、61 篇日報整理案例）：

- `自動化測試`、`測試自動化`：0 筆（因被視為單一 token，而案例文字為分開詞彙或標籤）
- `出差報銷`、`差旅報銷`、`出差報帳`：0 筆（差旅未納入旅遊同義詞，連綴詞未切分）
- `發票報帳`、`發票核銷`、`發票對帳`：0 筆
- `合約審核`、`合約審查`：0 筆
- `日報整理`、`日報摘要`：0 筆
- `自動客服`：0 筆
- `信箱清理`：0 筆
- `行程規劃`、`出差行程`、`旅遊行程`：0 筆
- `比價省錢`：0 筆
- `履歷修改`、`面試準備`：0 筆
- 自然問句如「我想做自動化測試」、「有沒有自動化測試的案例」、「請問如何做發票報帳」因連鎖問句前綴與問句後綴未過濾而回傳 0 筆。

## 2. 解決方案

在 `assets/app.js` 實作：
1. **意圖前綴與後綴無損清洗**：
   - 擴充連鎖問句前綴過濾（`請問`、`請教`、`有沒有`、`想知道`、`想了解`、`想問`、`推薦`、`如何做` 等）。
   - 過濾常見尾綴填充詞（`的案例`、`的例子`、`的工具`、`的做法`、`的經驗`、`的方法` 等）。
2. **核心任務複合詞無損切分**：
   - 覆蓋自動化測試、出差報銷、差旅報帳、發票報帳、合約審查、日報整理、自動客服、信箱清理、行程規劃、比價省錢、履歷修改、面試準備。
3. **同義詞對齊**：
   - 將「出差」、「差旅」納入旅遊旅行同義詞群組。
