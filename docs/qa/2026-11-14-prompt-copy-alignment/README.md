## 問題證據與目標使用者

目標使用者是**開啟案例詳情、點擊「前往方法與步驟 ↓」查看操作步驟，並複製提示詞或驗收指令去試用的訪客**。

全庫 524 個來源檔掃描與正式站實測（1440×900、390×844、320×740）確認 `assets/reader.js` 存在兩處「導覽承諾與段落操作不一致」的缺陷：

1. **`selectCopySections()`（`assets/reader.js:143-147`）只認 `/^(?:可複製提示詞|可貼指令)(?:[（(：:\s]|$)/` 字首，漏掉 28 個來源檔、43 個真實提示詞／可貼指令段落**：
   - **整頁 0 個複製按鈕（12 篇案例）**：
     - `UC-010`、`UC-012` 標題為 `## 可貼提示詞（自設未測，非作者原文）`／`## 可貼提示詞（自設未測，非論文原始提示）`，因寫作「可貼提示詞」而非「可貼指令／可複製提示詞」，整頁完全沒有「複製本段（含標題）」按鈕。
     - `UC-024` 標題為 `### 原創提示詞｜UNTESTED`，整頁 0 個複製按鈕。
     - `UC-027`、`UC-028`、`UC-029`、`UC-030`（含 2 段）、`UC-031`、`UC-032`、`UC-033`、`UC-034` 標題為 `### 原創提示詞（未實測，可修改後貼上）`，整頁 0 個複製按鈕。
     - `UC-237` 標題為 `## 自設練習與可貼指令（未執行）`，整頁 0 個複製按鈕。
   - **同頁兩個提示詞／指令段落「一個有複製按鈕、一個沒有」（16 篇案例＋1 篇 `evidence/009`）**：
     - 如 `UC-016` 的 `## 可複製提示詞` 有按鈕，但下方的 `### 原創提示詞（未實測，可修改後貼上）` 無按鈕；`UC-011` 的 `## 可貼提示詞` 無按鈕，只有補充的 `### 可貼指令` 有按鈕；以及 `UC-002`、`004`、`005`、`006`、`015`、`022`、`023`、`025`、`026`、`037`、`039`、`042`、`067`、`073`、`116`、`117`、`143`、`214`、`227`、`319`、`351`、`362`、`evidence/009` 的 `建議試法與可貼指令`、`可直接貼用的指令`、`可貼的只讀驗收指令`、`可貼指令與驗收`、`合成資料驗收指令` 等段落皆無複製按鈕。
2. **`methodHeading`（`assets/reader.js:28`）未含 `可嘗試的流程|小範圍試法|建議試法`，且 `promptHeading` 未排除來源引文標題**：
   - 在 `UC-026`～`034`（9 篇）與 `UC-073`、`UC-225`～`227`、`UC-299`、`UC-300`（6 篇）共 **15 篇案例**中，頁面明明有 `### 可嘗試的流程（本文設計、未實測）` 或 `## 小範圍試法（整理者設計，未實測）` 等步驟段落，但「前往方法與步驟 ↓」捷徑卻跳過它們，直接落到後方的提示詞標題（而在修改前，如 `UC-026`～`034` 落到的 `原創提示詞` 段落甚至沒有複製按鈕）。
   - 此外，`promptHeading` 原為寬鬆的 `/提示詞|可貼指令/`，未排除 `S-046A`、`S-061A`、`S-068A`、`S-408A` 等「來源引文提到作者提示詞」的標題。

## 兩個可行方案與取捨

- **方案 A（採用）：在 `assets/reader.js` 新增 `isCopyablePromptHeading()` 統一識別提示詞與可貼指令標題（並排除 `S-xxx`／`來源X` 引文、日期補充與 `…的限制／注意事項` 說明標題），同時供 `selectCopySections()` 與 `promptHeading` 共用；並將 `可嘗試的流程|小範圍試法|建議試法` 納入 `methodHeading`。**
  - 價值：
    - 全庫 524 個來源檔的可複製段落由 **529 段增至 572 段（+43 段）**，原本整頁無複製按鈕的 12 篇案例全數獲得複製控制；其餘 **8 個**含「提示詞／指令」字樣的來源引文或日期補充標題（`S-046A`、`S-061A`、`S-068A`、`S-408A`、`來源D` 與 3 個日期補充）100% 維持排除。
    - 15 篇含 `可嘗試的流程`／`小範圍試法` 的案例，「前往方法與步驟 ↓」捷徑正確指向流程步驟段落，不再跳過步驟落到提示詞。
    - 當某案例沒有獨立步驟標題而以提示詞作為「方法與步驟」fallback 時（因 `promptHeading = isCopyablePromptHeading`），該落點 100% 保證具備「複製本段（含標題）」按鈕。
  - 成本：僅修改 `assets/reader.js`（+10/−4 行）與測試，不影響 `assets/app.js` 或任何原始案例 Markdown。
- **方案 B（不採用）：將 `selectCopySections()` 放寬為 `/提示詞|指令/` 子字串匹配。**
  - 風險：會把 `UC-046` 的 `S-046A：Grok Bot — Tw93 的每晚精選提示詞（主要來源）`、`UC-351` 的 `來源D：…以非互動指令呼叫 Claude Code`、`UC-087` 的 `2026-10-21補充：長通話仍在進行，不代表指令已完整保存` 等來源敘述或失敗復盤誤加上「複製本段」按鈕，違反產品誠實標示原則。

本輪不處理範圍：段落內文以粗體或列表行內寫出的 `可貼指令：…`（非獨立 `##`/`###` 標題，共 87 篇），留待下一輪評估是否提升為子標題。
