# 2026-11-26 實體零售補貨與鮮度案例稽核

以具名實際執行、可公開核對的原始來源、明確的工作行動或人工交接、觀察結果與限制為條件。保留第一手實作方自報。各案例按一項實際部署或實證核對。四筆合格，一筆待定。本庫核讀來源，未獨立重現。

| 案例 | 判定依據與限制 |
| --- | --- |
| [UC-713](../cases/713-target-inventory-ledger-replenishment.md) | 機器學習推斷後寫回庫存帳本，再觸發既有補貨；銷量改善未公布幅度。 |
| [UC-714](../cases/714-shizutetsu-order-exception-review.md) | 按品項提出訂貨量，低信心則派回人工；廠方回報查核及訂貨工時約減 60%。 |
| [UC-715](../cases/715-takahashi-omron-shelf-fill-pilot.md) | 按總部陳列基準排列欠量貨架；單一比較圖中的生活雜貨類高 53%，非整店成效。 |
| [UC-716](../cases/716-balls-foods-tally-supplier-shelf-tasks.md) | 自主巡架後向門市提供補貨優先級和直送查核證據；供應商回報 24 小時內補架品項增加 30%。 |
| [UC-717](../cases/717-valor-deli-order-markdown-explainer.md) | 待定。實證報告只確認生成式代理依門市實績與預測解釋建議，缺少代理下單、改價或派工證據。20 店的廢棄和工時數字僅反映整體效果。 |

本輪先比對既有缺貨稽核及電商補貨案例，也比對開放 PR #478 的選址、供應品管、門市問答及購物流程。Sam's Club 的巡架案例與本批自主巡架主題接近，本輪保留較能核對任務交接與試驗範圍的案例。Afresh 的 CUB 試點有成效資料，原文主要說明人工依推薦下單，沒有描述同一案例的自主寫入或例外分派，留待補證。BCG 的 AVA 有具體流程，但原文未具名試點零售商，未列入本批。

部署門檻依跟做所需環境標示。使用既有訂貨服務並接上門市資料屬工具串接，其餘需要建置、整合或部署自走設備的案例屬進階開發。
